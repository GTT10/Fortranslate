# PeleF 0.156.0 validation record

## Scope

The arbitrary-depth reactive 2D EB patch tree now advances molecular
transport recursively. One Euler tree evaluates each runtime node, subcycles
every ordered child by the relation refinement ratio, interpolates child
exteriors from parent start/end fields, and owns one diffusive EB flux register
per child. Reflux, average-down, subtree conservation closure, and
deepest-first synchronization precede commit.

The public second-order operation applies two complete recursive Euler trees,
blends every node with its accepted stage-zero state, recovers active
temperatures through the EOS, and synchronizes deepest first. State,
temperature, minimum limiter theta, and optional per-level node counts remain
private until the final candidate validates.

## Automated evidence

A runtime three-level chain requires SSPRK2 counts `[2, 4, 8]`, positive
limiter theta, and state/temperature agreement with the established fixed
three-level transport path. Its existing composite conservation, conduction
smoothing, and covered-cell invariance gates remain active.

A separate four-level topology with one middle patch, two separated children,
and one deeper child requires the actual branching schedule
`[2, 4, 16, 16]`, changed state, positive limiter theta, complete
composite-vector conservation, and valid thermodynamics. A negative interval
preserves every node exactly, returns theta one, and publishes zero counts.

## Qualification boundary

This milestone advances standalone recursive SSPRK2 molecular transport. It
does not compose chemistry, transport, and hydrodynamics into one
`R-T-H-T-R` transaction and does not add a public time loop, dynamic tagging,
checkpoint I/O, or MPI ownership for the numerical tree.
