# PeleF 0.198.0 validation record

## Scope

Arbitrary-depth serial and sparse-MPI checkpoints preserve cumulative
per-level chemistry, transport, and hydro patch advances across independent,
changed-rank, and changing-topology restart lifecycles.

## Automated evidence

The direct serial round trip stores synthetic six-slot vectors with a
four-level topology and requires exact recovery. Invalid partial or negative
vectors, insufficient restart capacity, and incompatible inputs are rejected;
failed reads leave every optional vector unallocated.

The selected-root sparse gate repeats the round trip at one, two, four, and
eight ranks. Multi-rank runs reject a one-rank counter mismatch collectively.
Owner-local full-physics deltas are summed before the public application adds
them to its fixed-capacity global vectors.

The public serial and sparse reacting restart chains capture application logs.
The checker requires exact chemistry, transport, and hydro vectors between an
uninterrupted reference and serial continuation or two-rank checkpoint
continuation on four and eight ranks. Existing topology, field, limiter, and
conservation comparisons remain active. GNU Fortran Debug and Release CI run
identifiers are recorded in the pull request before merge.

## Qualification boundary

These are patch-advance diagnostics, not wall-clock cost or cell-update
counts. Default Fortran integer capacity remains the checkpoint limit, and
older strict-schema checkpoint files are intentionally incompatible.
