# PeleF 0.239.0 validation record

## Scope

This milestone qualifies context-bound checkpoint/stop/restart for the
configure-time selected sparse MPI reactive EB patch-tree 2D lifecycle. Fixed
schema 8 remains byte-frozen. Selected calls exclusively use schema 9 and may
restart with a different MPI rank count because distribution is not persistent
state.

## Execution and persistence contract

Schema 9 records the full-H2/O2 bundle SHA-256, generated `implicit`
integrator, ten-species bundle-order composition, complete numerical and EB
fingerprint, original composite conserved-integral baseline, committed clock,
operator counters, regrid history, rank-neutral four-level topology, and all
state and recovered-temperature fields. The I/O boundary validates exact
context consensus before gather or read. Root parses a private candidate
through the terminal marker and strict end-of-stream before topology is
redistributed and fields are scattered to current owners.

The public 8-by-8 planar-EB case writes its first checkpoint after one coarse
step at `5.1166209105049765e-13 s` and resumes to two coarse steps at
`1.0e-12 s`. Its cumulative counters change from chemistry `2 2 2 2` and
hydro `1 2 4 8` at the checkpoint to chemistry `4 4 4 4` and hydro
`2 4 8 16` at completion.

## Focused qualification

Final-source GNU Debug and Release focused sets each pass 14/14 tests. Each
set contains the selected schema-9 unit coverage, a direct two-rank gate for
rank-dependent read/write metadata presence, frozen fixed schema-8 checkpoint
stop/check, fixed and selected uninterrupted references, selected one-rank
checkpoint-stop, independent two- and four-rank restart, exact artifact
validation, 16 corruption gates, and six lexical alias gates.

The fixed one-rank, selected one-/two-/four-rank, and restarted two-/four-rank
final CSV files are byte-identical:

The corruption gate independently rejects schema, species-order, bundle,
integrator, composition, fingerprint, geometry, baseline, density, raw
species, near-floor negative species, species closure, temperature, terminal
marker, truncation, and trailing-content changes. Each failure preserves its
input checkpoint and publishes no output. Alias gates cover input/output,
input/checkpoint, output/checkpoint, input/restart, output/restart, and
checkpoint/restart before mechanism loading.

## Qualification boundary

This evidence establishes deterministic, context-bound, rank-neutral selected
sparse MPI reactive EB patch-tree 2D restart. It does not establish payload
authentication, crash-atomic or scalable I/O, schema migration, fixed-depth
MPI execution, runtime mechanism loading, CFD CVODE, thread safety,
performance, detailed-fuel physical validity, or external PeleC field parity.
