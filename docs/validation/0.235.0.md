# PeleF 0.235.0 validation record

## Scope

This milestone qualifies configure-time selected checkpoint creation,
intentional stop, and transactional restart for the established serial,
dynamic, exactly-three-level reactive EB AMR 2D hierarchy with one patch per
level, including dynamic-parent regridding. Fixed dynamic three-level magic/
schema 4 remains byte-for-byte. A selected dynamic call uses schema 5 under
the same dynamic magic.

Selected multipatch and MPI EB AMR persistence are not included.

## Persistence contract

The selected writer requires the canonical bundle SHA-256, generated
`explicit` or `implicit` integrator, mechanism species count, finite
nonnegative normalized bundle-order composition, and finite initial composite
integrals whose species components close to density. It writes
`SELECTED_CONTEXT` and `COMPOSITE_BASELINE` records before the established
dynamic three-level body.

The reader derives the expected schema from the fixed/selected call contract.
It validates context, baseline, species, geometry, wall and numerical policy,
dynamic controls, committed middle and finest patches, clock and regrid
diagnostics, all root/middle/finest state and temperature fields, EOS
consistency, the terminal marker, and end-of-stream in private candidates. No
caller-owned restart target is published until the complete file validates.
Restart restores both committed patches and the original composite baseline.

## Focused compatibility and failure gates

The driver unit gate covers selected schema-5 context/baseline round trip,
baseline closure write rejection, fixed/selected cross-schema rejection,
static/dynamic cross-magic rejection, corrupt marker/numeric baseline,
dynamic controls, middle patch, first field, terminal marker, and trailing
content, plus empty/default failed-read outputs and non-destructive invalid
writes. The post-hardening focused Debug and Release sets each pass 11/11;
failed reads publish no caller-owned restart target.

The six-test separate-process chain passes in Debug and Release. The frozen
fixed static and dynamic three-level restart chains pass unchanged; the fixed
dynamic checker independently pins the schema-4 checkpoint SHA-256. The
repurposed negative cases reject finest-patch removal and dynamic-parent
regridding without dynamic three-level mode. The final focused Release set
passes 17/17 tests.

## Qualification boundary

This evidence establishes deterministic serial selected dynamic three-level
continuation, including one dynamic-parent lifecycle, and generated-context
provenance. The bundle SHA-256 does not authenticate the checkpoint body. It
does not establish selected multipatch or MPI EB AMR persistence; runtime
mechanism loading; CFD CVODE dispatch; crash-atomic or scalable I/O; payload
authentication; thread safety; performance; detailed-fuel physical validity;
or external PeleC field parity.
