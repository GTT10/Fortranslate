# PeleF 0.180.0 validation record

## Scope

The shared 2D boundary set carries an embedded-wall record. EB molecular
transport applies first-order isothermal heat transfer and no-slip viscous
momentum/work only on cut faces while preserving adiabatic-slip and
species-impermeable defaults.

## Automated evidence

Pre-rebase implementation commits `4b04450` and `1e58fd7`, content-equivalent
to main-parent commits `4d05348` and `138d659`, are exercised by ordinary CI
run `33052371768` and MPI CI run `33052371774`. GNU Fortran Debug and Release
retain all 215 serial tests. MPI Debug and Release retain the complete one-,

The focused EB transport test requires a hotter isothermal wall to heat the
fluid without mass, momentum, or species leakage. A moving no-slip wall must
produce signed three-component momentum transfer and positive wall work; slip
must suppress viscous transfer exactly, and an invalid normal distance must
reject transactionally. Full right-hand-side comparison requires thermal and
viscous differences only in cut cells. Version consistency and
`git diff --check` pass.

## Qualification boundary

This milestone qualifies nondefault embedded-wall values through the library
boundary-set API. It uses a first-order centroid-normal gradient and keeps
species impermeable. Public namelist controls, checkpoint fingerprints for
nondefault walls, higher-order PeleC EB gradient-stencil parity, and catalytic
surface kinetics are not claimed.
