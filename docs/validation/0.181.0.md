# PeleF 0.181.0 validation record

## Scope

The public single-level reactive EB application accepts validated isothermal
and no-slip wall values from `&embedded_boundary`. Checkpoint-capable AMR
applications reject active nondefault values until restart formats include
them.

## Automated evidence

Implementation commit `cefab0a` is exercised by ordinary CI run `33053928075`
and MPI CI run `33054128730`. GNU Fortran Debug and Release retain all 215
serial tests. MPI Debug and Release retain the complete one-, two-, four-, and
eight-rank gate chain.

The public transport case selects a 1500 K embedded wall moving tangentially at
5 m/s with thermal conduction and viscosity enabled. Its checker requires
finite positive active thermodynamics, species closure, bulk temperature-span
reduction, measurable cut-cell heating, and nonzero cut-cell tangential
velocity. The direct driver gate requires isothermal mode without transport to
reject with a neutral clock. Version consistency, Python syntax, and
`git diff --check` pass.

## Qualification boundary

Only the checkpoint-free single-level application activates nondefault
namelist values. Low-level AMR/MPI APIs remain qualified through explicit
boundary sets, while public AMR namelist/checkpoint activation, catalytic
species transfer, and higher-order wall stencils are not claimed.
