# PeleF 0.82.0 validation record

## Scope

This milestone adds active-cell chemistry to the runnable first-order reactive
EB application. It also makes the shared 2D chemistry operation transactional
and composes reaction--EB hydro--reaction with whole-step rollback.

## Automated evidence

The unit gate applies two reference chemistry half-steps to a uniform field and
compares every active EB cell after the same two half-steps surrounding hydro.
Covered state and temperature must remain bitwise identical to their inputs.
Supplying an unknown Riemann solver after the first chemistry half-step must
return the original full arrays. Direct requests for unsupported molecular
transport must fail before time advancement.

Three executable regressions run the same 4 by 4 uniform case: regular 2D with
chemistry, EB 2D with chemistry, and EB 2D without chemistry. The plane creates
regular, cut, and covered cells. Every active EB primitive/species field must
match the regular result, every covered field must exactly match the inert EB
result, chemistry must measurably change the active solution, and
volume-weighted mass and total energy must remain conserved.

Implementation commit `5f1f0c2` is qualified by branch CI run `32763872404`
in GNU Fortran Debug and Release configurations. The full suite contains 150
tests.

## Qualification boundary

This covers cell-local elementary or full H2/O2 chemistry around stationary
adiabatic impermeable slip walls in the serial single-level PCM EB path. It does
not include EB molecular transport, thermal/viscous/catalytic or moving walls,
higher-order reconstruction, AMR coupling, or MPI distribution.
