# PeleF 0.124.0 validation record

## Scope

This milestone replaces complete-root broadcasts in direct sparse MPI reactive
EB AMR SSPRK2 transport with targeted root tile, child-owner bundle,
reflux-correction, and final-blend transfers. EB-cut conservation applies its
correction directly to distributed root tiles.

## Automated evidence

The qualified 14 by 14 plane-EB root is split into one row tile per available
rank and has two separated ratio-two 10 by 10 children. For each of two Euler
stages, the independently computed payload count is one gather and one scatter
per non-root-owner tile, one bundle per distinct remote child owner, and two
correction messages per remote child. The final SSPRK2 blend adds two gathers
and one scatter per non-root-owner tile. Each rank's send count and the
communicator sum must match at one, two, four, and eight ranks; the single-rank
count must be zero.

The direct sparse transport transaction must retain each rank's exact stored
value count and match serial multipatch root and child state and temperature
within `2e-11` field scale. Its limiter minimum must match within `2e-13`. The
rollback case places finite negative density on the final child owner; root and
earlier-child candidates may execute, but every local sparse field must remain
bitwise unchanged and published Euler and transfer counts must remain zero.

Implementation head `d8bfe39` was qualified by ordinary CI run `32920565554`
and MPI CI run `32920565545`. GNU Fortran Release and bounds/FPE-checked Debug
both passed the complete 208-test serial regression. The MPI workflow also
passed the targeted transport root-traffic gate and all established MPI gates
with OpenMPI at one, two, four, and eight ranks in both configurations.

## Qualification boundary

Transport root traffic is targeted, but root physics remains a level-wide
single-owner operation. The EB-cut closure still broadcasts one small `nvar`
boundary-change vector; it does not broadcast a root field. Root physics
decomposition, public time-loop control, dynamic sparse topology,
checkpointing, and output remain outside this milestone.
