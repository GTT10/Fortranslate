# PeleF 0.26.0 validation record

## Scope

This milestone adds solution-driven tagging and conservative dynamic
regridding to the serial one-dimensional two-level AMR foundation.

## Automated evidence

`unit_amr_regrid_1d` verifies:

- selected-component normalized-gradient tagging at a discontinuity;
- no tags for a flat selected component;
- invalid component and physical-boundary tag rejection;
- deterministic buffering and minimum-width patch expansion;
- average-down of fine cells that leave a moving patch;
- exact retention of fine values on same-ratio overlap;
- conservative initialization of newly refined cells;
- component-wise composite conservation during patch movement;
- conservative fine-level removal and recreation.

The pre-existing hierarchy, serial solver, chemistry, transport, and optional
MPI regression suites remain active in Debug and Release CI configurations.

## Qualification boundary

This record qualifies one strictly interior patch on a two-level 1D hierarchy.
It does not qualify physical-boundary refinement, disjoint-patch clustering,
arbitrary multilevel recursion, reactive-flow AMR time advancement, load
balancing, or MPI patch ownership.
