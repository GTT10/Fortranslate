# PeleF 0.187.0 validation record

## Scope

The conservative reactive 2D EB AMR initializer fits cut-parent gradients
multidimensionally over connected active coarse fluid-volume centroids.

## Automated evidence

The diagonal-plane unit geometry carries an EOS-consistent
interface-tangential affine conserved field evaluated at every coarse fluid
centroid. Every active child of every cut parent must reproduce the same
analytic field at its fine fluid centroid within roundoff. Existing gates
retain regular-parent exactness, nonconstant cut-parent children, component
bounds, complete-patch average-down conservation, EOS recovery, nonfinite
rollback, and PCM retry.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. The complete MPI chain is retained because the
shared dispatcher serves fixed-depth, arbitrary-depth, serial, and sparse-MPI
lifecycles. Version consistency, Fortran line length, and `git diff --check`
are also required.

## Qualification boundary

PCM remains the public default. Exact AMReX interpolation, quadratic
cut-parent reconstruction, geometry coarsening, and higher-order EB ghost
interpolation are not claimed.
