# PeleF 0.127.0 validation record

## Scope

This milestone adds transactional explicit topology rebuilding for sparse MPI
reactive EB AMR storage.

## Automated evidence

The test starts with two separated ratio-two children carrying distinct
thermodynamically consistent conserved-state scales. A new explicit plan
replaces them with one shifted and resized child. An independent serial EB
regrid supplies the averaged-root, retained-overlap, prolonged-cell,
temperature, and topology reference; the materialized sparse result must match
it exactly.

The rebuilt distribution must retain the configured subcycle exponent, contain
one child, and account for every root and fine cell once. Each rank's sparse
value count must equal `nvar+1` times its assigned cell count, with the exact
one-copy total across the communicator. An invalid refinement ratio must leave
the original child owners, template, root and child fields, and `changed=false`
result unchanged.

Implementation head `47ee63d` was qualified by ordinary CI run `32927138784`
and MPI CI run `32927138771`. GNU Fortran Release and bounds/FPE-checked Debug
both passed the complete 208-test serial regression. The MPI workflow also
passed the sparse regrid topology, ownership, storage, serial parity, rollback,
and all established MPI gates at one, two, four, and eight ranks in both
configurations.

## Qualification boundary

The explicit regrid uses a replicated compatibility window on every rank.
Owner-local tagging, direct replica-free overlap transfer, automatic regrid
cadence inside the public clock, sparse checkpoint/restart, parallel output,
and production-scale performance qualification remain outside this milestone.
