# PeleF 0.228.0 validation record

## Scope

This milestone adds `pelef_mpi_reactive_1d_selected`, a configure-time
selected-mechanism front end for the established regular MPI 1D coupled
reactive verification application. Fixed and selected front ends call one
mechanism-independent driver over 19 periodic cells. The selected MPI runtime
has a private module directory and links only the selected regular-1D runtime,
`MPI::MPI_Fortran`, and the generated mechanism; it does not link
`pelef_core` or a committed generated mechanism.

The interface remains deliberately bounded: zero or one output filename,
deterministic bundle-order composition-wave initialization, native
explicit/implicit chemistry, molecular transport, and 1/2/4-rank ordered
gather. This is not the general serial 1D namelist interface.

## Policy and transaction evidence

The generated chemistry-integrator constant is threaded through the MPI
adaptive Strang call and both distributed chemistry half-steps. Fixed callers
omit it and retain their established policy. Each call reduces the local
policy code with communicator-wide minimum and maximum operations. A dedicated
1/2/4-rank unit first completes a nonzero implicit adaptive-Strang control,
then passes an invalid singleton policy or valid explicit/implicit policies
that disagree across ranks and requires collective failure plus exact
conserved-state and temperature rollback on every rank.

The selected front end validates bundle size, thermodynamics, reaction mass
balance, transport order, and the common NASA7 interval covering 975--1025 K
before the shared driver creates output. Generator tests reserve all new MPI
module/program namespaces and render the selected template with maximum-length
legal identifiers without unresolved placeholders or lines above 100 columns.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in
the existing regular MPI 1D verification driver for the exact ordered H2/H
two-species and pinned full-H2/O2 ten-species initialization profiles on 1/2/4
ranks. It does not qualify other bundle orders, a general input-driven MPI
application, physical boundaries, selected MPI AMR/EB, checkpoint/restart,
runtime YAML/JSON loading, CVODE-backed CFD chemistry, mechanisms above 32
species, thread safety, performance/scaling, detailed fuels, external PeleC
field parity, or experiment validation. The repository license remains an
explicit owner decision and release blocker.
