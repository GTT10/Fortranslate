# PeleF 0.158.0 validation record

## Scope

The arbitrary-depth reactive 2D EB patch tree now exposes a public adaptive
target-time loop. A read-only selector evaluates active-cell hyperbolic and
enabled explicit transport limits on every runtime node, scales each interval
by its cumulative ancestor refinement product, and returns one stable root
interval. The loop recomputes that limit after every accepted state and clips
the final interval exactly to the requested target.

Each interval executes the qualified `R-T-H-T-R` operation on a private tree
candidate. Tree state, caller-owned time and step count, minimum accepted
interval, minimum transport limiter theta, and per-level chemistry, transport,
and hydro counts publish only after the candidate succeeds. A rejected first
step leaves the complete input unchanged; a later failure or exhausted step
budget retains only the accepted prefix.

## Automated evidence

On the fixed three-level chain, the combined selector equals the independently
computed minimum of the all-node hyperbolic limit and the root-time-scaled
transport limits. A target requiring two clipped steps matches an independently
repeated sequence of timestep selection and full-physics transactions exactly.
It also requires exact final time, two total/new steps, chemistry counts
`[4, 4, 4]`, transport Euler counts `[8, 16, 32]`, hydro counts `[2, 4, 8]`,
and matching minimum interval and limiter theta.

A one-step budget returns failure after retaining the first accepted state,
time, counts, and limiter outputs. An invalid first-step solver preserves every
tree value and the input clock exactly while returning zero counts, zero
minimum interval, and theta one.

## Qualification boundary

This milestone advances a static arbitrary-depth numerical tree with a public
clock. Dynamic tagging and topology rebuild scheduling, checkpoint I/O, and
distributed arbitrary-depth ownership and migration remain separate.
