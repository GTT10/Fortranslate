# PeleF 0.34.0 validation record

## Scope

This milestone adds primitive and time-traced characteristic PPM to the
arbitrary-depth one-dimensional reactive AMR engine. Fine subcycles receive
four layers of conservative parent-interpolated ghost data, and reflux uses the
same SSPRK3 effective interface flux that advances each level.

## Automated evidence

`regression_amr_multilevel_reactive_1d` advances a fixed three-level
`24/36/56`-cell hierarchy with characteristic PPM. It requires composite
conservation within `3e-10`, covered parent/child synchronization within
`5e-13`, positive thermodynamic recovery, nonnegative species, and
mass-fraction closure within `3e-10`.

`regression_amr_multilevel_characteristic_ppm_hotspot_run` exercises the public
namelist-driven application with solution-driven regridding, three active
levels, optional PPM contact steepening, and composite CSV output. Its paired
checker requires ordered exact domain coverage, three ratio-two spacings,
finite positive density, pressure, and temperature, and species closure within
`3e-10`.

Both gates run in the GitHub Actions Debug and Release builds. Main integration
also retains the MPI-enabled Debug and Release suites for the existing
distributed uniform-grid paths.

## Qualification boundary

The parent state is interpolated to the fine-substep midpoint and held fixed
through that substep's three SSPRK stages. The coarse/fine spatial fill is
conservative and MC-limited; it is not a full multilevel space-time PPM
interpolant. WENO, multiple patches, physical-boundary refinement, MPI patch
ownership, load balancing, embedded boundaries, and accelerators remain future
work.
