# PeleF 0.154.0 validation record

## Scope

The reactive 2D EB patch tree now advances hydrodynamics across arbitrary depth
and branching. Each recursive node advances over its own physical interval,
subcycles every ordered child by the relation refinement ratio, interpolates
the child exterior from the parent start and uncorrected end states, and owns
one EB flux register per child.

Reflux and average-down are applied to each actual parent/child relation.
Every refined subtree closes density, total energy, and species against flux
through its outer EB boundary before the hierarchy is synchronized deepest
first. The operation advances a private candidate and publishes the hierarchy
and optional per-level advance counts only after complete success.

## Qualification boundary

This milestone advances arbitrary-depth hyperbolic EB hydrodynamics only. It
does not add tree-wide chemistry, molecular transport, a public lifecycle or
time loop, dynamic tagging, checkpoint I/O, or MPI ownership for the numerical
tree. Those remain separate transactions.
