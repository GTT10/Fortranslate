## Implemented law and scope

The implementation follows logarithmic rate/pressure interpolation described in
[Cantera 3.2 rate parameterizations](https://cantera.org/3.2/reference/kinetics/rate-constants.html#pressure-dependent-arrhenius-rate-expressions-p-log).
At each temperature, rates sharing a pressure are summed before interpolation.
Signed pre-exponentials are allowed; scaled signed exponentials reduce overflow
risk in the sum. Every pressure-group total must be positive. Outside the table,
the nearest endpoint rate is held constant. Pressure is R*T*sum(C), so the
analytic derivative with respect to each concentration is k*slope/sum(C), where
slope is the local logarithmic interpolation slope. Endpoint derivatives are
zero; internal knot derivatives use the right interval and need not be unique.

Reaction kind 9 stores up to 64 rate entries, including repeated pressures.
The importer sorts entries stably; the generator requires ordered, finite,
positive pressures and finite Arrhenius coefficients. PLOG metadata participates
in MPI dense/sparse mechanism comparison. AMR/EB checkpoint contexts add count
and active rows only for PLOG reactions. Existing non-PLOG record layouts remain.
The fixed table adds 256 real values per reaction and MPI comparison record;
large-mechanism metadata memory/scaling has not been benchmarked.
