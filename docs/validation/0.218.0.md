# PeleF 0.218.0 validation record

## Scope

This milestone adds deterministic build-time ingestion of the repository-
pinned Cantera H2/O2 YAML `ohmech` phase. The resulting normalized bundle is
the single source for the existing ten-species NASA7 thermodynamics,
29-reaction pressure-dependent kinetics, and gas-transport runtime path.

complete Lennard-Jones gas-transport records, and 29 ordered reactions. The
reaction classification is 17 elementary, 11 three-body, and one Troe

the Cantera duplicate flag. Named colliders remain third bodies with zero
default efficiency and one collider efficiency; they are not inferred from or
folded into the displayed equation.

- helper tests reject PLOG, Chebyshev, SRI, Tsang, Lindemann, chemically
  activated rates, explicit reverse rates, custom orders, NASA9, charged
  species, missing or unsupported transport, element-unbalanced input, and

- the existing full-H2/O2 0D trajectory and regular 1D/2D parity gates pass

The initial focused Cantera run passed all 16 selected ingestion, generation,

After review hardening, the dependency-free generator suite passed all five

## Qualification boundary

This is a build-time pipeline for one pinned, explicitly selected ideal-gas
phase. It accepts NASA7 at 101325 Pa, gas Lennard-Jones transport, elementary
and three-body Arrhenius reactions, and Troe falloff. The Fortran generator is
bounded to 32 species and canonicalizes real literals with twelve digits after
the decimal in exponential notation.

This record does not qualify runtime YAML loading, arbitrary application-level
mechanism dispatch, CHEMKIN, NASA9, PLOG, Chebyshev, SRI, Lindemann-only
falloff, chemically activated rates, explicit reverse rates, custom reaction
orders, detailed hydrocarbon mechanisms, CVODE parity, external PeleC field
parity, or physical validation.
