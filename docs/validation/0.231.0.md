# PeleF 0.231.0 validation record

## Scope

This milestone qualifies checkpoint creation, intentional stop, and
transactional restart for the established configure-time selected serial,
single-level, exact planar reactive EB 3D application. It retains fixed
checkpoint schema 1 byte-for-byte and adds an exclusive schema 2 whose
selected context binds the restart to the normalized mechanism bundle,
generated chemistry policy, and bundle-order initial composition.

## Persistence contract

A fixed caller supplies no selected metadata and can read or write only schema
1. A selected caller must supply all of a canonical 64-digit lowercase bundle
SHA-256, `explicit` or `implicit` chemistry integrator, and finite nonnegative
normalized mole-fraction vector with one value per mechanism species; it can
read or write only schema 2. Partial context and either cross-schema direction
are rejected rather than downgraded.

Schema 2 places these records immediately after the common header:

```text
SELECTED_CONTEXT
<bundle SHA-256>
<chemistry integrator>
<species count>
<normalized bundle-order mole fractions>
```

The existing complete NASA7, reaction, transport, immutable configuration,
geometry, diagnostics, state, temperature, terminal-marker, and EOF checks
remain active. A reader publishes no caller target until every record passes.

## Unit and startup gates

The checkpoint unit test covers fixed schema-1 and selected schema-2 round
trips; fixed-reader/schema-2 and selected-reader/schema-1 rejection; incomplete
write context; changed bundle SHA, integrator, and normalized composition;
malformed context marker, SHA, integrator, and species count; negative and NaN
composition; selected-context truncation; and all earlier changed model,
configuration, transport, geometry, temperature, state-shape, and file
truncation cases. Every failed read retains geometry, state, temperature,
integrals, clock, steps, and cumulative diagnostics exactly.

Selected startup rejects lexical input/checkpoint and input/restart aliases and
preserves the input without an output artifact. The existing output alias
checks remain active.

## Qualification boundary

This evidence establishes selected-mechanism provenance, compatibility
rejection, transactional rollback, and deterministic serial continuation for
the bounded planar EB 3D path. The bundle SHA-256 is not a digest of the
checkpoint body. A finite, physically consistent payload alteration is not
cryptographically detected. Crash-atomic file replacement, schema conversion,
general or moving EB geometry, AMR/MPI EB 3D, distributed/scalable I/O, runtime
mechanism loading, CVODE inside CFD, mechanisms above 32 species, detailed
fuels, thread safety, performance/scaling, external PeleC field parity,
experiment validation, and the repository license remain open.
