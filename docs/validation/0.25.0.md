# PeleF 0.25.0 validation record

Base: verified PeleF 0.24.0 distributed reactive one-dimensional milestone.

## New subsystem

- typed level-0 and level-1 one-dimensional boxes;
- a strictly nested static fine patch with arbitrary state width;
- conservative MC-limited piecewise-linear prolongation;
- volume-average restriction and average-down synchronization;
- refinement-ratio fine-level subcycling;
- time-integrated coarse/fine interface flux registers;
- two-interface reflux and composite-integral diagnostics.

## Acceptance gates

- exact prolongation of a linear profile to fine-cell centers;
- prolongation/restriction identity on covered coarse averages;
- no average-down modification outside the covered coarse range;
- fine timestep sum equal to the coarse interval;
- manufactured pre-reflux composite conservation mismatch;
- roundoff-scale composite conservation after reflux;
- flux-register reset after application;
- preservation of the complete existing Debug and Release suites.

This milestone completes AMR implementation-order items 1 through 5. Tagging,
dynamic regridding, arbitrary multiple levels, and reactive-flow integration are
not yet claimed.
