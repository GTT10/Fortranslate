# PeleF 0.191.0 validation record

## Scope

The public serial and sparse-MPI arbitrary-depth EB AMR applications qualify
recursively tagged children that meet an outflow physical boundary.

## Automated evidence

The x-upper hotspot case must build four populated levels. Its composite CSV
must contain at least one cell on the exact x-upper physical boundary at every
level, refinement-ratio-consistent spacing, regular/cut/covered EB classes,
finite positive thermodynamics, and closed species mass fractions.

The sparse-MPI workflow runs the same case at one, two, four, and eight ranks.
The one-rank output must pass the topology checker, and every ordered identity
and numeric field must match across rank counts.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. Python syntax, CMake configuration, version
consistency, and `git diff --check` are also required.

## Qualification boundary

The physical child side uses zero-gradient outflow from the current fine
boundary state. Non-outflow refined boundaries, periodic-seam children, and
checkpoint continuation of this topology are not claimed.
