# PeleF 0.189.0 validation record

## Scope

The fixed three-level EB AMR library can transactionally relocate or resize
the root-to-middle patch and rebuild a valid finest patch beneath it.

## Automated evidence

The focused reactive EB AMR driver gate initializes an offset hotspot in a
static three-level hierarchy, enables dynamic tagging, and requires the parent
patch bounds to change and reach both upper physical boundaries. This also
qualifies bounds-safe limited-linear neighbor selection at a domain edge.
Both rebuilt patch descriptors must validate, the finest patch must retain its
two-cell middle-level margin, and the complete three-level composite conserved
integral must agree before and after the transaction. An invalid prolongation
selection must reject the operation with all three state/temperature fields
and both patch descriptors unchanged.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. The complete MPI chain is retained because the
changed driver module also serves arbitrary-depth serial and sparse-MPI
lifecycles. Version consistency, Fortran line length, and `git diff --check`
are also required.

## Qualification boundary

This milestone exposes the atomic fixed-depth library operation. The public
time-loop schedule and fixed-depth checkpoint topology still retain a fixed
root-to-middle patch. Cross-parent finest overlap preservation is represented
through conservative restriction rather than direct subcell migration.
