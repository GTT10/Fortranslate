# PeleF 0.70.0 validation record

## Scope

This milestone replaces cell-only sparse MPI AMR owner balancing with a
selectable deterministic work model. Patch work is stored in 64-bit integers
and weights each cell by cumulative refinement-ratio subcycling: exponent 0
for storage, exponent 1 for hyperbolic work, or exponent 2 for parabolic work.

## Automated evidence

`pelef_mpi_amr_patch_1d` verifies exact patch and rank work totals for all three
models, collective rejection of invalid or rank-inconsistent exponents, and
rejection of corrupted rank-work metadata.

The four-level reactive hierarchy verifies that parabolic weighting never
increases the maximum estimated rank work for 1, 2, 4, or 8 ranks and strictly
reduces it for 2 and 4 ranks relative to the original cell-only owner map.
Explicit unchanged/changed regrids retain exponent 2, and owner-local tagged
planning retains exponent 1 through candidate and committed distributions.

Implementation commit `2381182` passed the complete GNU Fortran Debug and
Release suites in branch run 32729279995. MPI branch run 32729280149 passed the
complete Debug and Release suites, including the 1/2/4/8-rank sparse AMR gates.

## Qualification boundary

The weights are static deterministic estimates derived from hierarchy
subcycling. They do not use measured runtime, heterogeneous CPU/GPU costs,
communication-volume weights, dynamic work stealing, or topology reordering.
