# PeleF 0.36.0 validation record

## Scope

This milestone completes the hybrid-WENO scheme set currently selected by
PeleC `PPM.cpp`: WENO7-Z uses a seven-value primitive stencil and WENO3-Z uses
a three-value stencil. Scheme numbers 2 and 3 match the upstream runtime
selection, while WENO5-JS/Z remain schemes 0 and 1.

## Automated evidence

`unit_weno_reconstruction` now checks all four schemes. WENO7-Z and WENO3-Z
must reproduce constant and linear data to roundoff and match fixed
nonsymmetric `Source/WENO.H` formula values within `2e-13` and `3e-14`,
respectively.

`regression_amr_multilevel_reactive_1d` advances every scheme for two steps on
the fixed three-level hierarchy. Each must conserve the composite state within
`3e-10`, synchronize covered parent/child states within `5e-13`, retain
positive thermodynamics, and close species within `3e-10`.

The public `hotspot_weno7z.nml` and `hotspot_weno3z.nml` cases exercise scheme
selection, recursive advancement, solution-driven regridding, and composite
output. Their paired checks require three ordered levels, ratio-two spacings,
coverage within `3e-13`, positive finite thermodynamics, and species closure
within `3e-10`.

All gates run in the GitHub Actions Debug and Release builds. Main integration
also retains the MPI-enabled Debug and Release suite.

## Qualification boundary

All four schemes are edge-reconstruction alternatives inside the
one-dimensional multilevel reactive characteristic-PPM path. This remains one
Cartesian patch per level rather than a general distributed AMReX hierarchy.
Regular-grid two-dimensional WENO, physical-boundary refinement, multiple
patches, MPI patch ownership, load balancing, embedded boundaries, and
accelerators remain future work.
