# PeleF 0.184.0 validation record

## Scope

The public fixed-depth reactive 2D EB AMR configuration selects PCM or
conservative limited-linear coarse-to-fine initialization for fresh
two-level, sibling-patch, and three-level lifecycles. Checkpoint/restart and
arbitrary-depth paths remain explicitly PCM-only.

## Automated evidence

The installed hot-wall AMR transport case selects linear prolongation and
retains its active-cell, temperature-span, tangential-momentum, and
conservation gates. Direct-driver tests exercise linear two-level,
multipatch, and three-level construction, invalid-method rollback, and early
rejection at every untracked restart/fingerprint boundary.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. Version consistency and `git diff --check` are
also required.

## Qualification boundary

The method is not stored in fixed-depth checkpoint schemas or the shared
arbitrary-depth fingerprint. Linear checkpoint/restart, serial or sparse-MPI
arbitrary-depth linear regridding, EB-aware slopes on cut parents, and exact
AMReX interpolation parity are not claimed.
