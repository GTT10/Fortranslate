# PeleF 0.242.0 validation record

## Scope

This milestone qualifies configure-time selected mechanisms for the existing
static, strictly interior, periodic, two-level 3D reactive AMR hierarchy in
serial and rank-local sparse MPI execution. It preserves the `0.241.0` fixed
mechanism path and does not add AMR transport, selected checkpoint/restart,
dynamic topology, physical coarse boundaries, or 3D EB AMR.

## Dispatch and provenance contract

The serial and MPI executables now use shared mechanism-independent lifecycle
drivers. Generated frontends supply validated NASA7 species, ordered
reactions, transport provenance, exact species-name composition, bundle
SHA-256, and the generated explicit or implicit chemistry integrator.

Before root state allocation or initialization, the MPI path compares the
complete selected context across the communicator. Floating-point records are
compared by representation, not tolerance. Rank-dependent valid changes to
the SHA, integrator, composition, NASA7 coefficients, reaction equation or
rate, and transport data return collective rejection. A rank owning no fine
planes remains in this and all later collectives.

Selected molecular transport, checkpoint intervals, checkpoint stops,
restart paths, and lexical input/output aliases are rejected before output.
The fixed executable continues to reject `thermo_model='selected'`.

## Qualification boundary

This is deterministic dispatch, provenance-consensus, rollback, structural,
and short-time conservation evidence. It is not ignition evidence, detailed-
fuel physical validation, AMR molecular-transport qualification, selected
restart support, performance or scaling evidence, distributed I/O, or
external PeleC field parity.
