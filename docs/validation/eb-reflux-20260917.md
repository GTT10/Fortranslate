## Source and implemented scope

Implementation `b44bf99ccccfa5c786d8361cb836baf02c97d8d7`, based on
`1c2632a` on local `main`.

`eb_reactive_reflux_3d_mod` adds `eb_integrated_flux_3d` with x/y/z arrays of
**time-integrated flux per open face area**. Normal indices are 0:n;
component and tangential indices start at one. Arrays must be finite, including
closed faces. No timestep multiplication is performed inside these APIs.

`restrict_eb_integrated_flux_3d` restricts a full-domain fine flux using open-area
weights on coincident faces. Closed coarse faces receive zero. The companion
coarse geometry is obtained with `coarsen_eb_geometry_3d`; multiplying the result
by its coarse open area recovers the sum of fine open-area-integrated fluxes.
The destination flux object is published only after validation.

`reflux_reactive_eb_state_3d` accepts coarse geometry, a refined-coarse-cell mask,
original coarse flux and fine-restricted flux on the same coarse grid. Only
unrefined fluid cells adjacent to refined cells across an open interior face are
corrected. The fine-minus-coarse flux difference is multiplied by physical open
area, signed inward, and divided by coarse fluid volume. Temperature is recovered
from the corrected conserved state. Both fields roll back together if any
corrected cell is nonphysical. Refined, covered and noninterface storage remains
unchanged.

These are library operations, not yet a hierarchy integrator. Callers must use
the coarse geometry consistent with the fine flux restriction. Fine-cell updates,
averaging down, outer-boundary budgets, periodic seam synchronization and EB
wall-source integration remain separate responsibilities. Arbitrary patch-tree,
subcycled and MPI EB stepping are not connected. Small-cell reflux stabilization
is not provided; an invalid corrected state is rejected rather than clipped.
