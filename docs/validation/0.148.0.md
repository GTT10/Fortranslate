# PeleF 0.148.0 validation record

## Scope

This milestone retains stage-start, uncorrected stage-end, and cumulative
corrected state and temperature on every root transport tile owner. Each child
owner assembles globally indexed patch-plus-two fragments directly from the
intersecting tiles, extracts the established four-edge exterior context, and
uses the corrected view as its local reflux support.

After child-local ratio subcycling and reflux, corrected support fragments
return directly to the intersecting tile owners before the next child begins.
Final corrected root tiles commit locally, removing the former root-physics-
owner context/correction round trip and corrected-row scatter.

## Automated evidence

For every qualification child, the MPI application requires the direct
start/end/corrected state support plus interface-flux value count to be positive
and strictly smaller than the former complete root state, temperature, and
x/y-flux bundle. Exact traffic is derived from three routes for every remote
tile/child intersection across both SSPRK2 Euler stages: state support to the
child, coarse flux support to the child, and corrected support back to the
tile. Remote tile-result traffic no longer includes a final corrected-row
scatter.

The application retains exact owner work, limiter minima, serial root/child
field parity, periodic-edge finite bands, cut-interface conservation, public-
clock accounting, scheduled regridding, and late-failure rollback.
Qualification head `c314e66` is covered by ordinary CI run `32994857548` and
MPI CI run `32994857424`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

Distributed transport tiles still send their complete owned result and flux
rows to the root physics owner, which assembles a temporary complete bundle for
compatibility validation and cut-boundary flux closure. Child routing and final
corrected-root publication no longer depend on that bundle. Removing the
post-compute complete-root assembly is the next milestone. Hydro is unchanged.
This milestone qualifies ownership, numerical parity, exact traffic, and
rollback behavior; it does not claim a measured speedup.
