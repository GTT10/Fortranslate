# PeleF 0.78.0 validation record

## Scope

This milestone adds conservative first-order EB FluxRedist and an EOS-validated
transactional reactive state update on one Cartesian level.

## Automated evidence

A vertical embedded wall produces a cut cell with volume fraction `0.05`, two
covered cells, and one connected regular neighbor. Five independent conserved
components must match the analytical neighborhood blend and neighbor excess,
retain their volume-weighted integrals, leave covered and distant cells exactly
zero, and reduce the cut-cell right-hand side below `0.11` of its raw value.

A full seven-species state is then advanced with a raw cut-cell right-hand side
that would produce negative density. Redistribution must keep both the cut cell
and receiving neighbor positive, recover the original temperature after the
proportional update, and conserve every state component to `4e-13` relative.
A stronger nonphysical update must fail with unchanged state and temperature;
a nonfinite input must return an all-zero redistributed right-hand side.

Implementation commit `14dcdb0` is qualified by branch CI run 32751894648 in
GNU Fortran Debug and Release configurations.

## Qualification boundary

This is first-order FluxRedist on in-domain face-connected neighborhoods. It is
not weighted StateRedist and does not yet support periodic/physical-boundary
redistribution, higher-order slopes, flux construction beside covered cells,
AMR, or MPI coupling.
