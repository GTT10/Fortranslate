# PeleF 0.182.0 validation record

## Scope

Public fixed-depth, arbitrary-depth, serial, and sparse-MPI EB AMR applications
apply the embedded-wall values from `&embedded_boundary`. Their checkpoint and
restart contracts identify the wall and all molecular-transport controls.

## Automated evidence

Implementation commits through `950ac6a` are submitted to ordinary CI run
`33056186291` and MPI CI run `33056186255`. Final conclusions are recorded only
after both GNU Fortran Debug and Release matrices complete.

The focused two-level gate advances an active 1500 K isothermal wall, writes a
transport checkpoint, restarts it at the recorded final state, and rejects a
10 K wall-temperature mismatch with a neutral clock. The arbitrary-depth
fingerprint gate verifies that the same temperature change fails matching.
Version consistency and `git diff --check` pass.

## Qualification boundary

Schema-1 fixed-depth and schema-2 fingerprinted arbitrary-depth checkpoints are
not migrated; the new readers reject them. Wall species remain impermeable.
Catalytic conversion, higher-order wall-normal stencils, and external PeleC
checkpoint compatibility are not claimed.
