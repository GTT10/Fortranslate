# Periodic nonreacting SDC application input — 2026-09-26

Implementation `6c768cce`, parent `e34490a9`, local main, version 0.246.0.

Regular fixed/selected gas applications accept `time_integrator='sdc'` and
positive `sdc_iterations` (default 2). Existing default `split` is unchanged.
SDC currently requires periodic PPM/PeleC without chemistry or transport. Reader
capability gates reject it in unconnected application families. The library
SDC driver accepts either a custom evaluator or built-in external force,
exclusively, and publishes a time-integrated source ledger after success.
The shared application uses this ledger in existing conservation diagnostics.
An example is `cases/reactive_boundaries_3d/external_forcing_sdc.nml`.
