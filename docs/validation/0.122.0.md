# PeleF 0.122.0 validation record

## Scope

This milestone replaces all-rank child restriction broadcasts in direct sparse
MPI reactive EB AMR average-down with point-to-point messages only to
intersecting root tile owners.

## Automated evidence

The qualified 14 by 14 plane-EB root is split into one row tile per available
rank and has two separated ratio-two 10 by 10 children. For every child, the
gate independently derives the unique remote root owners intersecting its
coarse footprint. Each child owner must report exactly that many transfers and
the communicator sum must match at one, two, four, and eight ranks; the
single-rank case must report zero.

The direct sparse chemistry transaction using the targeted average-down must
retain each rank's exact stored-value count and match serial root and child
state and temperature bitwise. The rollback case gives the final child finite
negative density and invokes average-down directly. Candidate messages may be
sent, but every local sparse field and the published transfer count must remain
bitwise unchanged and zero, respectively.

Implementation head `dd8609c` was qualified by ordinary CI run `32916238098`
and MPI CI run `32916238120`. GNU Fortran Release and bounds/FPE-checked Debug
both passed the complete 208-test serial regression. The MPI workflow also
passed the targeted restriction accounting gate and all established MPI gates
with OpenMPI at one, two, four, and eight ranks in both configurations.

## Qualification boundary

Average-down restriction traffic is targeted, but root physics fields,
coarse-time exterior state, fluxes, and reflux corrections are still
level-wide synchronized temporaries. Root decomposition, remaining targeted
physics traffic, public time-loop control, dynamic topology, checkpointing,
and output remain outside this milestone.
