# PeleF 0.23.0 validation record

Base: verified PeleF 0.22.0 distributed implicit chemistry scheduling.

## New subsystem

- distributed general-EOS molecular transport on a 33-cell periodic full-H2/O2
  mixture;
- state and temperature halo exchange at SSPRK2 stages;
- viscosity, Fourier conduction, mixture-averaged diffusion, barodiffusion,
  correction velocity, and species-enthalpy transport;
- global parabolic timestep control and synchronized adaptive rejection.

## Acceptance gates

- finite positive density and temperature with closed species state;
- periodic conservation and a nontrivial transport response;
- complete-field parity for 1, 2, 4, and 8 ranks;
- preservation of all serial and earlier MPI gates.
