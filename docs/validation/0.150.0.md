# PeleF 0.150.0 validation record

## Scope

Sparse hydro no longer sends complete root start/end state, temperature, and
x/y flux arrays to remote child owners. For each child, the root physics owner
packs the established four-edge start/end interpolation context, current
patch-plus-two corrected state and temperature, and child-intersecting coarse
x/y flux rectangles into one compact message.

The child owner reconstructs the fine exterior from that context, accumulates
the coarse register through the globally indexed flux-support API, performs
ratio subcycling, and refluxes through the globally indexed state-support API.
Only corrected patch-plus-two state and temperature return to the root owner,
which merges them before advancing the next child.

## Automated evidence

For every qualification child, the MPI application requires the combined
context, correction support, and flux support value count to be positive and
strictly smaller than the former complete root bundle. Exact traffic removes
the former one-bundle-per-distinct-child-owner allowance and requires one
compact outbound message plus one corrected-support return for every remote
child.

Qualification head `c6231a4` is covered by ordinary CI run `32999369704` and
MPI CI run `32999369715`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

Root hydro tiles still send their complete owned results to the root physics
owner. That owner assembles the complete root hydro result, merges ordered
child corrections, and scatters final corrected rows to tile owners. Direct
tile-to-child routing and tile-owner correction remain later milestones.
Transport is unchanged. This milestone does not claim a measured speedup.
