# PeleF 0.111.0 validation record

## Scope

This milestone executes reactive source integration directly on the exclusive
MPI owner of every two-dimensional EB AMR root tile and fine sibling patch.
It retains the correctness-first replicated field bridge while adding
collective chemistry-control validation, per-entity commit, owner broadcasts,
fine-to-root synchronization, call accounting, and exact rollback.

## Automated evidence

The MPI executable constructs a 14 by 14 plane-EB root and two separated
ratio-two 10 by 10 children. A serial active-cell chemistry reference advances
the complete patch set. The distributed path advances each full-width root
y-tile and each child only on its recorded owner, then broadcasts the accepted
state and EOS-recovered temperature and averages the children into the root.

Every rank's committed chemistry count must equal its owner-map entity count,
and the communicator sum must equal the number of root tiles plus children.
Root and child fields must match the serial reference within `5e-13` of their
field scales, with a measurable reactive-species change. A deliberately
invalid density on the owner of the last root tile must fail after earlier
candidate work and leave the original rank-local root and child payloads
bitwise unchanged.

Implementation head `5524421` is qualified by ordinary CI run 32895834188 and
MPI CI run 32895834225. The MPI workflow used Ubuntu 24.04 with OpenMPI and ran
the executable at one, two, four, and eight ranks in GNU Fortran Release and
bounds-, backtrace-, and floating-point-exception-checked Debug
configurations. All established MPI gates and the complete 208-test serial
regression passed in both MPI configurations. The ordinary Release and Debug
CI configurations independently passed all 208 tests.

## Qualification boundary

Chemistry now runs on owners, but EB geometry, patch topology, and complete
field payloads remain replicated. Owner-only EB hydrodynamics and molecular
transport; sparse rank-local storage; point-to-point halo and coarse/fine
traffic; distributed flux registers; topology migration; parallel checkpoint
I/O; and a public distributed EB AMR time loop remain outside this milestone.
