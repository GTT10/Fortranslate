# Isentropic vortex

A smooth two-dimensional isentropic vortex is superimposed on the uniform
velocity `(u, v) = (1, 1)` in the periodic domain `[0, 10] x [0, 10]`.
The exact solution is the initial vortex translated by the base velocity.

./build/debug/pelef2d cases/isentropic_vortex/vortex.nml
