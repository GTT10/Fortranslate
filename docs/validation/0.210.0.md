# PeleF 0.210.0 validation record

## Scope

This milestone adds selectable frozen-composition characteristic PLM with MC
or minmod limiting to the periodic general-EOS 3D solver and to both levels of
the serial static two-level hierarchy. Fine coarse/fine faces use two ghost
layers filled by time-interpolated, limited-linear coarse primitive states.
Checkpoint schema 2 fingerprints reconstruction and limiter controls.

## Automated evidence

- the reactive 3D dimensional-reduction unit rotates a nonuniform line through
  x, y, and z and checks the complete PLM SSPRK2 state and temperature;
- invalid reconstruction, limiter, or Riemann controls must preserve caller
  state and return zero face fluxes;
- an elementary-H2/O2 diagonal entropy wave measures three-grid convergence,
  conservation, physicality, and species closure;
- a public full-H2O2 regular-grid input is checked independently from its CSV;
- the static-AMR regression runs PCM and characteristic PLM, checks refluxed
  composite conservation, exact average-down synchronization, physicality,
  MC/minmod uniform invariance, rollback, and PLM accuracy improvement;
- a public full-H2O2 PLM hierarchy is checked independently, stopped at coarse
  step four, restarted, and compared byte for byte with its uninterrupted
  coarse and fine CSV streams;
- the checkpoint unit rejects a changed reconstruction fingerprint without
  modifying any target field or continuation metadata;
- the existing 15-test MPI Release gate retains exact PCM serial versus
  1/2/4/8-rank arithmetic and changed-rank restart parity under schema 2.

## Qualification boundary

This record qualifies method-of-lines characteristic PLM for serial periodic
regular-grid and static, strictly interior, single-patch, hydro-only 3D AMR.
PCM remains the default. The replicated-state MPI AMR implementation remains
PCM-only. This milestone does not qualify CTU transverse prediction, PPM,
physical boundaries, AMR chemistry or molecular transport, dynamic or
multipatch topology, sparse storage, scalable I/O, 3D EB, cross-schema
migration, cross-toolchain bit identity, or whole-application PeleC parity.

## Local qualification results

The focused GNU Fortran 13.3.0 Release gate passes all 13 new or directly
affected unit, convergence, application, checkpoint, and restart tests. The
corresponding Debug gates, including the public PLM checkpoint/restart chain,
pass with bounds checking and floating-point traps. A wider 14-test Release
recheck also retains the preceding PCM public restart chain. The existing
OpenMPI 4.1.6 Release gate passes all 15 distributed static-AMR tests after
the schema update.
