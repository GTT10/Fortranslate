# PeleF 0.229.0 validation record

## Scope

This milestone adds `pelef_reactive_eb_amr_2d_selected`, a configure-time
selected-mechanism front end for the established serial static two-level
reactive EB AMR 2D application. Fixed and selected front ends call one
mechanism-independent application driver for configured boundary assembly,
hierarchy initialization, fine subcycling, EB reflux, conservative
average-down, deterministic coarse/fine CSV, invariants, and diagnostics.

The selected runtime has a private module directory and links the selected
single-level EB runtime plus only the generic AMR hierarchy, flux-register,
regrid, transport, driver, and application modules. It does not link
`pelef_core`, a fixed database loader, or either committed generated
mechanism.

## Dispatch and startup contract

Bundle-order mole fractions are threaded through coarse, fine, and configured
physical-boundary initialization. The generated `explicit` or `implicit`
chemistry policy is threaded through both chemistry half-steps on both levels;
fixed callers omit both optional arguments and retain their prior policy.

The selected front end admits only static two-level serial execution. It
rejects dynamic regridding, three-level and multipatch modes, checkpoint or
restart requests, lexical aliases among input/coarse/fine paths, unknown or
duplicate composition names, and requested initial, hotspot, isothermal-wall,
or reflected-wall temperatures outside the bundle's common NASA7 interval
before output creation. Checkpoint/restart remains excluded because the
existing schema does not record the selected bundle fingerprint and generated
integrator policy.

## Two-species fixture

The independently ordered H2/H fixture declares the explicit integrator and
loads the input composition in H/H2 order. A plane at `x=0.00337 m` cuts an
8-by-8 coarse grid and the static ratio-two 12-by-12 fine patch. The run
completes three coarse steps to `1.0e-7 s` with minimum accepted coarse step
`2.1511461342977052e-8 s`.

The coarse output has 32 regular, eight cut, and 24 covered cells. The fine
output has 84 regular, 12 cut, and 48 covered cells. Both levels contain
finite positive density, pressure, and temperature and have mass-fraction
closure error at most `1.1102230246251565e-16`. Maximum H2 change is
`1.3160688855251568e-4`. The fine-grid volume fractions average exactly to
their coarse parents and the largest relative conserved-state average-down
error is `1.3847059065308495e-16`. Independent repeated outputs are
byte-identical. Debug and Release produce the same fixture hashes. Coarse
SHA-256 is
`40758bed925456948aa694ee130e766b8b942a2bdfef104c268323a981119c0e`;
fine SHA-256 is
`30728d746ccdbbec2b238e4c738f6e0e54ba9550ec5d9ea609c5d7972551fbfe`.

## Focused regression evidence

The Debug focused suite passes 31/31 tests: selected configuration, fixture
coarse/fine physicality, activity, hierarchy mapping, average-down, frozen
hashes, and repeat identity; full-H2/O2 coarse/fine activity, hierarchy

directory. The independent generator suite passes 12/12 and renders and
compiles the selected EB AMR template with maximum-length legal Fortran
identifiers and no line above 100 columns.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in
the existing static two-level serial 2D EB AMR path for the exact H2/H fixture
and pinned full-H2/O2 case. It does not qualify other bundles physically,
dynamic/three-level/multipatch selected EB AMR, checkpoint/restart, selected
EB 3D, MPI EB AMR, runtime YAML/JSON loading, CVODE-backed CFD chemistry,
mechanisms above 32 species, thread safety, performance/scaling, detailed
fuels, external PeleC field parity, or experiment validation. The repository
license remains an explicit owner decision and release blocker.
