# PeleF 0.217.0 validation record

## Scope

This milestone adds transactional checkpoint/restart to the serial,
single-level, exact-axis-plane `pelef_reactive_eb_3d` application. The public
qualification keeps elementary chemistry and StateRedist molecular transport
enabled, stops after one committed `R-T-H-T-R` step, and resumes in a separate
process.

## Automated evidence

- the schema-1 formatted checkpoint has a distinct magic and terminal marker;
- full NASA7 species, elementary reaction, and gas-transport records are
  stored and compared, together with immutable mesh, EB, physics, numerical,
  and initial-condition controls;
- state, recovered temperature, initial conserved/L1/H-O-N inventories, time,
  step, minimum accepted timestep, maximum transport diffusivity, and minimum
  transport flux factor round-trip;
- bad magic/schema, changed configuration/mechanism/transport, truncation, and
  an EOS-inconsistent stored temperature reject without changing caller-owned
  state or metadata;
- empty, magic-only, and species-header-only files exercise early EOF at
  distinct records; every read status is accepted before its record is
  inspected, so rejection does not rely on Fortran logical short-circuiting;
- the public stopped output is earlier than the final output and restart
  performs at least one additional coupled step;
- every public CSV row independently matches the frozen Cartesian center,
  planar cell type, volume fraction, and fluid centroid;
- lexical `./`, repeated-separator, and reducible-parent path aliases cannot
  make output overwrite a configured checkpoint or restart file;
- uninterrupted and restarted final CSV files are compared byte-for-byte, and
  their cumulative execution diagnostics must match.

## Numerical signatures

The frozen public case uses a `24 x 8 x 6` domain with the same `1.0e-5 m`
x spacing and `kappa=0.05` cut sheet as the `0.216.0` transport case. It writes
after the first stable step and resumes through one short, strictly positive
final-time remainder. This exercises a second committed process step without
weakening the existing gate that rejects longer zero-gradient-boundary
exchange. The checker reads 1,152 x-fastest rows and finds 960 regular, 48 cut,
and 144 covered cells.

The checkpoint is written at step 1 and
`2.7268814571340862e-9 s`. Both the uninterrupted and restarted processes end
at step 2 and `2.7280000000000001e-9 s`. Their cumulative diagnostics agree
exactly within each build:

- minimum accepted timestep: `1.1185428659138522e-12 s`;
- maximum transport diffusivity: `9.7180462151561149e-4`;
- minimum transport flux factor: `1.0`;
- maximum invariant conservation error: `8.2592220605513923e-12`;
- maximum elemental conservation error: `5.5627787859492504e-12`.

The uninterrupted and restarted final CSV files are byte-identical within
each build. Floating optimization changes final printed digits, so the two
qualified hashes are:

- Debug: `5fefb15a8af2fa30a59e8e82a3d326a89b0fe923e7857d2d80517d8094cf6ec5`;
- Release: `54c39674f207ba3604479cc2244ebdab13965ee534d9c662841ad0b06054e1bd`.

## Qualification boundary

The restart format is deterministic formatted validation I/O for the existing
serial planar application. Checkpoint cadence, stop policy, paths, output path,
and extended final step/time limits may change across restart. Thermodynamics,
kinetics, transport, geometry, initial condition, solver, redistribution, and
coupled-physics controls may not.

This record does not qualify MPI/distributed checkpoint I/O, AMR topology or
reflux history, general or curved EB geometry, scalable storage, checkpoint
schema conversion, crash-atomic replacement of an existing checkpoint,
configurable external mechanisms, external PeleC field parity, or physical
validation. The portable configuration check does not
resolve symlink, hardlink, bind-mount, case-folding, or cwd/absolute filesystem
identity aliases.

and `/usr/bin` Open MPI 4.1.6. All five rebuilt configurations passed:

- serial Debug: 277/277 tests in 399.52 s;
- serial Release: 277/277 tests in 128.33 s;
- serial Debug with live Cantera references: 280/280 tests in 398.67 s;
- MPI Debug: 292/292 tests in 415.83 s;

smoke test passed with `LD_LIBRARY_PATH` removed. The final Debug and Release
public restart checkers reproduced the row counts, clock, diagnostics, and
build-mode hashes listed above.

Fresh Release installs were made in
`/tmp/pelef-0217-final-serial-D7N2QC` and
`/tmp/pelef-0217-final-mpi-CKqKaP`.
They contain 17 and 28 executables; every installed file is byte-identical to
its build-tree artifact. The executable-stack audit passed all 45 inspected
ELFs. All 11 MPI executables have no embedded RPATH/RUNPATH or Intel/oneAPI
reference, and clean-environment `ldd` resolved every dependency.

The project contract passed at version `0.217.0` against upstream PeleC
`bf0e1fd15040`. Python compilation, diff whitespace checks, focused Fortran
line-width and trailing-whitespace checks, and final source rebuilds also
passed. The Cantera Debug rebuild repeated three pre-existing GNU warnings for
REAL equality comparisons outside the `0.217.0` change; the new checkpoint,
configuration, application, tests, and checker produced no warnings.

After the checkpoint reader's explicit I/O-status sequencing and the public
geometry checker were hardened, all five configurations' focused checkpoint
unit plus four public restart tests passed (5/5 per configuration, 25/25
