# PeleF 0.39.0 validation record

## Scope

This milestone extends the fixed two-level separated multipatch reactive path
from hydro-only advancement to chemistry and molecular transport. It adds the
combined hyperbolic/parabolic timestep gate, `r^2` fine diffusion subcycling,
per-patch diffusive reflux, hierarchy-wide chemistry average-down, and a
transactional `R-T-H-T-R` interval.

## Automated evidence

`regression_amr_multipatch_reactive_physics_1d` initializes a periodic reacting
hotspot on a 24-cell parent and two separated ratio-two patches. It enables the
elementary H2/O2 mechanism, viscosity, Fourier conduction, mixture-averaged
species diffusion, barodiffusion, characteristic PPM, and hybrid WENO7-Z.

The gate verifies that transport timestep and advance requests reject a missing
transport database, then advances one coupled interval. It requires the fine
state to change, density through total-energy composite integrals to remain
conservative within `2e-9`, both covered regions to synchronize within
`8e-13`, thermodynamics to remain positive, species to remain nonnegative and
close within `3e-10`, and a rejected step to leave the solution unchanged.

The pre-existing `regression_amr_multipatch_reactive_1d` remains the longer
two-step hydro-only WENO7-Z conservation gate. All serial gates run with array
bounds checking in GitHub Actions Debug and again in Release. Main integration
also runs the MPI-enabled Debug and Release suite.

## Qualification boundary

The new operator path is fixed at two levels and receives explicit separated
patch bounds. The primary tag-driven application still owns one patch per
level. Dynamic multipatch regridding inside the reactive driver, arbitrary
depth, adjacent independent boxes, same-level ghost exchange, output, load
balancing, and MPI patch ownership remain future work.
