# PeleF 0.68.0 validation record

## Scope

This milestone extends the qualified PeleC acoustic Riemann algorithm from the
constant-`gamma` state to the reactive NASA7 ideal-gas-mixture state. The
reference algorithm is `Source/Riemann.H` at PeleC development commit
`bf0e1fd15040f0f5609cd9042b9f1b868e0e95f8`.

## Automated evidence

`unit_reactive_pelec_riemann` verifies:

- a stationary heterogeneous-composition contact with exact zero mass and
  energy flux, common pressure, and averaged interface density;
- a moving contact and an equal state against independently assembled physical
  fluxes, including transverse momentum and all species;
- a nonuniform pressure/temperature/velocity/composition pair with finite,
  positive interface density and pressure;
- exact species-flux closure, dispatcher selection, y-direction rotation, and
  invalid-state rejection.

`regression_reactive_composition_wave` now runs the `pelec` path on 40, 80, and
160 cells. Both refinement intervals must exceed order 1.70, the finest H2
mass-fraction L1 error must remain below `4e-6`, and all five conserved
integrals must remain within `5e-12` relative error.

Branch run 32724497906 passed all 137 GNU Fortran tests in Debug and Release
for implementation commit `563b658`.

## Qualification boundary

The port uses the repository's NASA7 ideal-gas-mixture EOS and matches the
PeleC acoustic algorithm structure. It does not include rotating-frame energy,
auxiliary or linear advected variables, embedded-boundary coupling, or every
EOS model supported by PelePhysics.
