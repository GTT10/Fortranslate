# PeleF 0.145.0 validation record

## Scope

This milestone lets the coarse EB flux register consume compact, globally
indexed x- and y-face rectangles. The support must contain every active
coarse/fine interface face for the patch. The complete-root accumulation API
remains a wrapper over the same support kernel.

Sparse MPI transport uses the support entrypoint with each child's interface
rectangles sliced from the temporary root flux bundle. Register layout,
correction arithmetic, child ordering, and the child-local reflux transaction
remain unchanged.

## Automated evidence

The EB flux-register unit gate accumulates the same coarse fluxes through the
complete-root wrapper and through a strictly smaller interface support. It
requires bitwise-identical correction arrays. Separate missing-x-face and
missing-y-face calls must fail while leaving the established register
bitwise unchanged. Existing subcycled cancellation, conservation,
temperature, nonfinite-input, and reset gates remain active.

The sparse MPI application retains exact owner work and transfer accounting,
root/child field and limiter parity, public-clock accounting, scheduled
regridding, and late-failure rollback. The child context remains smaller than
the former complete root state, temperature, and x/y-flux bundle.

Qualification head `a1b17f2` is covered by ordinary CI run `32989778280` and
MPI CI run `32989777576`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

The root physics owner still assembles and owns the complete temporary root
x/y flux bundle, then passes interface slices to the compact accumulator.
Direct root-tile-to-child flux-fragment routing is the next milestone. Hydro
is unchanged. This milestone qualifies storage, numerical parity, validation,
traffic accounting, and rollback behavior; it does not claim a measured
speedup.
