## Implemented model

The implementation follows the five-parameter SRI expression in
[Cantera 3.2 rate parameterizations](https://cantera.org/3.2/reference/kinetics/rate-constants.html#the-sri-falloff-function):
F = D T^E [A exp(-B/T) + exp(-T/C)]^X, X = 1/(1+log10(Pr)^2).
The runtime evaluates the bracket in log space and supplies the analytic
logarithmic derivative with respect to reduced pressure. This enters the
existing concentration Jacobian, including the collider efficiencies.
Three-parameter input defaults D=1 and E=0. The current coefficient domain
requires A>=0, C>=0, D>0 and at least one of A/C positive, with finite values.
C=0 omits its exponential term. Numerically unrepresentable factors reject.

SRI uses reaction kind 4 and its own five-value record. It is never represented
as Troe or silently downgraded to Lindemann. The generator accepts normalized
`sri-falloff`, emits low/high rates, efficiencies and SRI data. Existing
non-SRI generated output remains unchanged in the generator regression suite.
AMR and EB 3D checkpoint mechanism records write/read SRI values conditionally;
MPI dense/sparse mechanism comparisons include them in packed metadata.
