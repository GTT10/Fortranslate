# PeleF 0.129.0 validation record

## Scope

This milestone removes the all-rank numerical-field materialization window
from explicit, tagged, and scheduled two-level sparse MPI reactive EB AMR
regrids.

## Automated evidence

The explicit gate starts with two separated ratio-two children whose conserved
states differ, then replaces them with one shifted and resized child. An
independent serial regrid supplies the averaged-root, PCM, retained-overlap,
temperature, and topology reference. The sparse result must match it while the
communicator stores exactly one copy of the new hierarchy.

Restriction sends are counted from each old child to its distinct intersecting
root owners. PCM assembly sends are counted once per remote root tile and
distinct new child owner. Overlap sends are counted once per nonempty
same-ratio old/new rectangle whose owner changes. The scheduled hotspot case
checks the same traffic through the tagged public clock. Invalid controls and a
valid fine geometry with a deliberately inconsistent retained-overlap volume
fraction must publish zero direct-regrid traffic and preserve the
pre-transaction distribution, fields, and template. A rejected scheduled
geometry callback must also preserve the clock and counters.

Implementation head `3baaaa4` is qualified by ordinary CI run `32934711305`
and MPI CI run `32934711274`. GNU Fortran Release and bounds/FPE-checked Debug
passed the complete 208-test serial regression. The MPI workflow also passed
all established gates at one, two, four, and eight ranks in both
configurations.

## Qualification boundary

Numerical root and child fields remain globally single-copy during regrid, but
geometry and compact topology metadata are replicated. Sparse checkpoint and
parallel output paths still materialize at explicit run boundaries.
Arbitrary-depth dynamic EB topology and decomposition of the level-wide root
physics kernel remain outside this milestone.
