# PeleF 0.203.0 validation record

## Scope

This milestone adds a serial, single-level, uniform-grid, periodic,
constant-`gamma` three-dimensional Euler application. It uses PCM face states,
Rusanov or PeleC-style directional fluxes, a summed multidimensional CFL
limit, and transactional SSPRK2 integration.

## Automated evidence

- `unit_euler_3d_dimensional_reduction` requires exact x/y/z whole-step
  agreement with the established 1D periodic PCM/SSPRK2 update for both
  Rusanov and PeleC-style solvers, and verifies invalid-solver rollback;
- `regression_entropy_wave_3d` advances a diagonal wave on 16^3, 32^3, and
  64^3 grids and checks convergence plus every Euler conserved integral;
- `regression_entropy_wave_3d_run` exercises the public `pelef3d` namelist;
- `regression_entropy_wave_3d_check` independently checks the 4096-row CSV,
  exact density wave, primitive/conserved consistency, and analytical totals;
- `quality_no_executable_stack` includes the new shipped application.

## Numerical signatures

With GNU Fortran 13.3.0 Debug checks enabled, density L1 errors were
`1.5484516258163321e-2`, `8.3350342118757685e-3`, and
`4.3218625190539874e-3` on 16^3, 32^3, and 64^3. The observed orders were
`0.8935662874022505` and `0.9475349409278204`. The largest relative conserved
integral error in those runs was `8.0160507193152161e-16`.

The public 16^3 case completed ten steps at `t=0.05`, with density L1 error
`1.5484516258163321e-2`. Its largest absolute reported conserved-integral
change was `3.3306690738754696e-16`; the independent CSV calculation found a
maximum relative analytical-total error of `1.110e-16`.

## Qualification boundary

This record does not qualify reactive thermodynamics or chemistry, molecular
transport, high-order 3D reconstruction, AMR, restart, MPI decomposition, EB,
LES, particles/spray, scalable output, accelerators, or a full PeleC
application comparison.

The OpenMPI checks retain the established distributed subsystem boundary; the
new `pelef3d` application itself is serial and makes no MPI qualification
