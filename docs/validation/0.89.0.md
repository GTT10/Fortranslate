# PeleF 0.89.0 validation record

## Scope

This milestone adds temperature-gradient tagging, strictly internal rectangular
patch planning, conservative two-level reactive EB topology replacement,
same-resolution fine overlap retention, periodic regrid cadence, and a public
moving-hotspot application regression.

## Automated evidence

The direct regrid gate builds old and new ratio-two rectangles on one diagonal
embedded boundary. It verifies the exact five-point hotspot tag set, covered and
root-boundary exclusion, buffered patch bounds, an inactive uniform plan,
composite conservation, exact retained overlap, PCM initialization of newly
refined active cells, average-down of retired fine regions, malformed
temperature-shape rejection, nonfinite rollback, and active-cell EOS recovery.

The driver gate starts a hotspot outside the configured static rectangle,
requires a committed initial regrid, advances the resulting hierarchy, and
checks final patch validity and composite conservation. The application
regression reads the dynamic namelist and writes coarse/fine CSV files. Its
checker proves that the aligned fine rectangle moved away from the static
bounds, encloses the hotspot, retains finite positive thermodynamics, and
preserves species closure.

Implementation head `c5a5eb3` is qualified by
[branch CI run 32822924175](https://github.com/GTT10/Fortranslate/actions/runs/32822924175)
in GNU Fortran Debug and Release configurations. All 159 tests passed in both;
Release completed in 163 seconds and Debug in 339 seconds. The Debug test phase
completed in 309 seconds with bounds, backtrace, and floating-point exception
checks enabled.

## Qualification boundary

This remains one serial, ratio-aligned, strictly internal fine rectangle over
one root level. Empty tags retain the current fine patch rather than removing
it. Chemistry and molecular transport are not yet composed on the EB hierarchy,
and the application does not create multiple patches or deeper levels,
checkpoint dynamic EB state, or distribute EB ownership with MPI.
