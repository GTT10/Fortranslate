# PeleF 0.143.0 validation record

## Scope

This milestone removes the complete root transport bundle from remote sparse
fine-child owners. A compact context stores raw coarse start/end conserved
state and temperature only on the four fine-patch edges. At each fine
substep, the established interpolation and EOS recovery reconstruct the same
exterior state from this context.

The root physics owner initializes the patch-plus-one-cell flux register and
accumulates coarse interface fluxes before sending the context. The child
owner advances only its fine state, accumulates fine interface fluxes, and
returns the evolved fine field, temperature, and compact register correction.
The root owner applies reactive reflux in deterministic child order and sends
back only the corrected fine field and temperature.

## Automated evidence

The reactive EB AMR unit gate extracts a compact context and requires every
reconstructed exterior state and temperature array to match the complete-root
builder exactly. The MPI qualification application independently computes the
context-plus-register value count for every child and requires it to be
strictly smaller than the former complete root start/end state, temperature,
and x/y-flux bundle.

For each remote child, the sparse transport gate requires exactly three
messages per Euler stage: context from root to child, evolved fine state and
register from child to root, and corrected fine state from root to child. It
retains exact owner work counts, limiter parity, root/child field parity,
public time-loop accounting, scheduled regridding, and late-failure rollback
at one, two, four, and eight ranks.

Qualification head `e1f19f9` is covered by ordinary CI run `32983578481` and
MPI CI run `32983578680`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

The owner-tiled root Euler stages still assemble one complete temporary root
start/end/temperature/x-y-flux result on the root physics owner. Fine fields
also make a result/correction round trip because the established complete-root
reactive reflux kernel remains there. Hydro keeps its existing child bundle
and correction route. This milestone qualifies reduced transport child
storage and context payload; it does not claim a measured speedup.
