# PeleF 0.147.0 validation record

## Scope

This milestone lets reactive child exterior-context extraction consume coarse
start/end conserved state and temperature arrays with explicit global lower
bounds. A rectangle containing the child patch expanded by one coarse cell,
clipped to the root domain, supplies every nonphysical coarse/fine edge sample.
The complete-root entrypoint validates its compatibility arrays and delegates
to the same support kernel.

## Automated evidence

The reactive EB unit gate extracts one exterior context from complete root
arrays and another from a strictly smaller patch-plus-one support. It
reconstructs both contexts at an interior coarse-time fraction and requires
bitwise-identical state and temperature on all four fine edges. Separate gates
reject a missing support row, an out-of-root lower bound, and nonfinite support.

All established serial and sparse MPI transport gates remain active, including
exact owner work and transfer counts, root/child numerical parity, limiter
minima, periodic-edge finite bands, public-clock accounting, scheduled
regridding, and late-failure rollback. Qualification head `dc231ac` is covered
by ordinary CI run `32994371321` and MPI CI run `32994371341`. GNU Fortran
Debug and Release builds pass. OpenMPI one-, two-, four-, and eight-rank gates
pass in Release and bounds/FPE-checked Debug configurations, and both workflows
pass the complete 208-test serial regression.

## Qualification boundary

Sparse MPI transport still assembles complete temporary root start/end state
and temperature arrays on the root physics owner and calls the complete-root
wrapper there. Direct root-tile-to-child state/support routing is the next
milestone. This milestone qualifies the support API, exact context parity,
validation, and unchanged regressions; it does not claim a measured speedup.
