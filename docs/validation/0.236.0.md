# PeleF 0.236.0 validation record

## Scope

This milestone qualifies configure-time selected checkpoint creation,
intentional stop, and transactional restart for the established serial,
dynamic, exactly-two-level reactive EB AMR 2D patch-set lifecycle. Fixed
patch-set magic/schema 3 remains byte-for-byte. A selected patch-set call uses
schema 4 under the same magic.

Selected MPI EB AMR persistence is not included.

## Persistence contract

The selected writer requires the canonical bundle SHA-256, generated
`explicit` or `implicit` integrator, mechanism species count, finite
nonnegative normalized bundle-order composition, and finite initial composite
integrals whose species components close to density. It writes
`SELECTED_CONTEXT` and `COMPOSITE_BASELINE` records before the established
patch-set body.

The reader derives the expected schema from the fixed/selected call contract.
It validates context, baseline, species, geometry, wall and numerical policy,
dynamic controls, every committed child patch, clock and regrid diagnostics,
all root and child state/temperature fields, EOS consistency, the terminal
marker, and end-of-stream in private candidates. No caller-owned restart
target is published until the complete file validates. Restart restores the
committed patch set and original composite baseline.

## Focused compatibility and failure gates

The driver unit gate covers selected schema-4 context/baseline round trip,
baseline closure write rejection, fixed/selected cross-schema rejection,
composition mismatch, corrupt marker/numeric baseline, terminal marker, and
trailing content, plus empty/default failed-read outputs, non-destructive
invalid writes, and direct selected-integrator propagation. Failed reads
publish no caller-owned restart target.

The six-test separate-process selected chain, derived child-output alias gate,
and frozen fixed patch-set restart chain pass together in final-source Debug
and Release focused sets: 12/12 in 110.63 s and 12/12 in 34.40 s. The fixed
checker independently pins the schema-3 checkpoint SHA-256. An independent
Luna Max read-only audit reports `blocking=0`.

## Qualification boundary

This evidence establishes deterministic serial selected dynamic multipatch
continuation and generated-context provenance. The bundle SHA-256 does not
authenticate the checkpoint body. It does not establish selected MPI EB AMR
persistence; runtime mechanism loading; CFD CVODE dispatch; crash-atomic or
scalable I/O; payload authentication; thread safety; performance; detailed-
fuel physical validity; or external PeleC field parity.
