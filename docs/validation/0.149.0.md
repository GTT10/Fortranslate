# PeleF 0.149.0 validation record

## Scope

Sparse transport Euler stages now retain stage-start, uncorrected stage-end,
cumulative corrected state and temperature, and uniquely owned x/y fluxes only
on each root tile owner. Remote tiles no longer send a complete owned result to
the root physics owner, and that owner no longer allocates complete root
transport state, temperature, or flux arrays.

For cut-interface conservation, every local tile accumulates its left and
right physical x-boundary flux contribution. Only the first and final y tiles
add the lower and upper physical faces. One communicator sum produces the
finite conserved `nvar` boundary-change vector used by the established
distributed closure.

## Automated evidence

The sparse MPI application derives exact point-to-point traffic from finite-
band halo exchanges and direct state, coarse-flux, and corrected-support
fragments for every remote tile/child intersection across both SSPRK2 Euler
stages. It contains no tile-result allowance. The root-only cyclic gate
requires halo traffic only, while the cut-interface hierarchy retains serial
root/child field parity and composite conservation.

Qualification head `bc61ec2` is covered by ordinary CI run `32996748534` and
MPI CI run `32996748553`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

Hydro retains its existing temporary complete-root result and child route.
Checkpoint, output, restart, and legacy compatibility APIs may still
materialize a complete hierarchy explicitly. This milestone removes the
post-compute complete-root assembly only from sparse molecular transport and
does not claim a measured speedup.
