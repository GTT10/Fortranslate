# PeleF 0.95.0 validation record

## Scope

This milestone adds transactional formatted checkpoint/restart for the public
serial reactive EB patch-set lifecycle. A dedicated schema preserves the root,
zero or more ordered children, accepted topology, state, and regrid cadence
without changing the established single-patch checkpoint format.

## Automated evidence

The direct gate writes and reads a two-child reacting plane-EB hierarchy. It
requires exact root and child conserved states, child count and coarse bounds,
time, accepted-step and regrid counters, minimum timestep, and base density.
Every active temperature recovered through the EOS must match within `3e-12`
scaled tolerance. A file truncated immediately after the valid patch-set magic
must leave root arrays, geometry, and the child collection unpublished.

The public split-run gate evolves the two-hotspot case to `3e-6`. A scheduled
checkpoint after the first committed step and periodic regrid must retain two
separated children and stop early. Restart rebuilds both children and continues
from the stored counters. The final root and two child CSVs are compared field
by field with an uninterrupted reacting reference within `3e-10` scaled
tolerance, while also checking finite positive state, species closure, complete
root EB classes, requested final time, and deterministic child separation.

Implementation head `f26e777` is qualified by
[branch CI run 32849129836](https://github.com/GTT10/Fortranslate/actions/runs/32849129836)
in GNU Fortran Debug and Release configurations. The focused seven-test public
application/checkpoint gate passed before the complete regression in each
configuration. All 175 tests passed in Release and in bounds-, backtrace-, and
floating-point-exception-checked Debug builds.

## Qualification boundary

The schema covers one serial EB root and an ordered set of separated,
ratio-aligned fine rectangles at one finer level. Existing single-patch files
retain their original magic and schema. Cross-format conversion, EB molecular
transport, deeper levels, physical-side fine patches, distributed ownership,
and parallel checkpoint I/O remain outside this milestone.
