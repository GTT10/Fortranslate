# PeleF 0.173.0 validation record

## Scope

The arbitrary-depth serial reactive 2D EB tree is now available through the
installed `pelef_reactive_eb_patch_tree_2d` executable. It consumes the
established input namelists, constructs child EB geometry from recursive
temperature tags, advances the qualified full-physics clock, and writes one
composite CSV.

## Automated evidence

The runnable case starts from a 12-by-12 plane-EB hotspot and configures a
four-level ceiling with ratio two. Initial recursive tagging must populate
levels zero, one, two, and three. The application advances to `1e-9` seconds
and reports four levels.

The output checker requires unique level/patch/local-index identities, exact
level-scaled x/y spacing, the requested final time, finite output, bounded EB
volume fractions, positive density, pressure, and temperature, all regular,
cut, and covered EB classes, seven species columns, and mass-fraction closure
within `8e-12`.

Qualification commit `c8088be` is covered by CI run `33041268915`. GNU Fortran
Debug and Release build the new executable and pass the complete 210-test
suite. Local `fparser2` parsing passes the three touched Fortran sources,
Python syntax parsing passes the checker, and `git diff --check` is clean.

## Qualification boundary

This milestone qualifies a fresh input-driven serial application run through
arbitrary-depth regridding, physics, and output. Application-level checkpoint/
restart round-trip comparison and a public sparse MPI application remain later
lifecycle work.
