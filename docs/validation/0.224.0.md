# PeleF 0.224.0 validation record

## Scope

This milestone adds `pelef_reactive_3d_selected`, a configure-time selected
mechanism front end for the existing serial periodic regular-grid 3D reacting
flow. It loads a normalized schema-1 bundle's NASA7, elementary/third-body/Troe
reaction, and primitive gas-transport arrays, resolves the input composition by
exact species name, and calls the same mechanism-independent application driver
as the fixed full-H2/O2 front end.

The private selected 3D link graph contains generic thermochemistry, kinetics,
transport, mesh, regular-face hydro, and 3D orchestration modules but neither
committed generated mechanism. The selected and fixed front ends therefore
share evolution and publication logic without permitting a generated-module
collision.

## Configuration and startup evidence

Shared selected startup modules validate 2--32 ordered NASA7 species, unique
names, reaction structure and molecular-mass balance, complete transport order,
a finite common thermo interval, and the requested temperature range before
output creation. Composition validation rejects duplicate or unknown names,
nonfinite or negative active fractions, nonblank/nonzero unused tails, and a
zero total, while safely normalizing finite near-maximum fractions.

The fixed application rejects `thermo_model = "selected"` unless the configured
selected front end opts in. An unknown-species selected case and selected input
sent to the fixed application both terminate during startup without publishing
a CSV artifact.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in one
serial periodic single-level regular-grid 3D application. It is not runtime
YAML/JSON loading, CVODE-backed CFD chemistry, physical-boundary or selected
2D/AMR/EB/MPI dispatch, mechanisms above 32 species, a thread-safety or
performance result, detailed-fuel validation, external PeleC field parity, or
experiment validation. The repository license remains an explicit owner
decision and release blocker.
