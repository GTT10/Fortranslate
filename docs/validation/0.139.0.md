# PeleF 0.139.0 validation record

## Scope

This milestone removes the final SSPRK2 root-blend materialization from direct
sparse MPI 2D EB AMR molecular transport. Every root tile owner now averages
its local interval-start and second-Euler conserved states and performs EOS
temperature recovery against its exact EB geometry row band.

## Automated evidence

The direct sparse transport gate requires exact owner storage counts and
matches the serial multipatch root and child state and temperature fields at
one, two, four, and eight ranks. State and temperature retain their established
`2e-11` scaled tolerances and the transport limiter minimum retains its
`2e-13` scaled tolerance. A late child failure must leave every sparse field
bitwise unchanged and publish zero Euler advances, root transfers, and limiter
change.

For every remote root tile, the transfer gate now requires exactly four root
payloads across one complete SSPRK2 transport call: one gather and one scatter
in each Euler stage. The former final-blend start gather, second-Euler gather,
and blended-row scatter are absent. Child-owner bundles, reflux-correction
round trips, direct cut-interface closure, and final sparse average-down retain
their established accounting and parity gates.

Qualification head `2fd1ae5` is covered by ordinary CI run `32961884579` and
MPI CI run `32961884654`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.
