# PeleF 0.130.0 validation record

## Scope

This milestone adds a targeted root-only materialization boundary for sparse
MPI reactive EB AMR fields. Complete coarse and child arrays are allocated only
on the selected writer rank instead of on every rank.

## Automated evidence

The gate scatters a two-child hierarchy into exclusive owner-local root tiles
and children, then gathers it to the deterministic root writer. The complete
root state, root temperature, and every child field must exactly equal the
established all-rank materialization result, while all non-root complete arrays
remain unallocated and their returned patch sets remain empty.

Sender-local and communicator-summed traffic are checked against an independent
owner-map formula: one packed state/temperature send per root tile or child
whose owner differs from the writer. An invalid local sparse root payload and
both invalid and rank-inconsistent writer selections must reject collectively,
leave all complete arrays unallocated, return empty patch sets, and publish
zero traffic.

Qualification head `659f6d9` is covered by ordinary CI run `32936785704` and
MPI CI run `32936785717`. GNU Fortran Release and bounds/FPE-checked Debug passed
the complete 208-test serial regression. The MPI workflow also passed all
established gates at one, two, four, and eight ranks in both configurations.

## Qualification boundary

The materialization boundary is field-sparse on non-root ranks, but geometry
and compact topology metadata remain replicated. The existing formatted
checkpoint and CSV writers are not yet connected to this gather. Distributed
restart reconstruction, parallel file formats, arbitrary-depth dynamic EB
topology, and decomposition of the level-wide root physics kernel remain
separate work.
