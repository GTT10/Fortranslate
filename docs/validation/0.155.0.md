# PeleF 0.155.0 validation record

## Scope

The arbitrary-depth reactive 2D EB patch tree now advances active-cell
chemistry on every runtime node. Each patch derives an active mask from its own
EB geometry and invokes the established constant-volume 2D reaction integrator
for the same physical interval. The standalone chemistry operation
synchronizes deepest first and commits only a complete candidate.

The tree also owns one transactional `R-H-R` Strang operation. It applies a
reaction half-step to every patch, invokes the qualified recursive tree
hydrodynamics interval, applies the second reaction half-step, and synchronizes
deepest first. State, temperature, chemistry counts, and hydro counts remain
private until final validation succeeds.

## Automated evidence

The four-level, two-branch gate verifies standalone chemistry counts
`[1, 2, 2, 1]`, Strang chemistry counts `[2, 4, 4, 2]`, and hydro counts
`[1, 4, 8, 8]`. It preserves composite density and total energy, retains
density/species closure, produces measurable species activity, and leaves
finite positive thermodynamics. An invalid solver after the first chemistry
half-step preserves every accepted node exactly and publishes zero counts.

A runtime three-level chain requires chemistry counts `[2, 2, 2]`, hydro
counts `[1, 2, 4]`, and state/temperature agreement with the established fixed
three-level Strang path.

## Qualification boundary

This milestone composes chemistry and hydrodynamics only. It does not add
arbitrary-depth molecular transport, `R-T-H-T-R` full physics, a public time
loop, dynamic tagging, checkpoint I/O, or MPI ownership for the numerical
tree. Those remain separate transactions.
