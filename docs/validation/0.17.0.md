# PeleF 0.17.0 validation record

Base: PeleF 0.16.0 qualified one-dimensional molecular transport.

## New subsystem

- full x/y Newtonian stress tensor and viscous work;
- x/y Fourier heat conduction;
- x/y mixture-averaged species diffusion and optional barodiffusion;
- correction velocity and species-enthalpy energy transport;
- shared trace-species positivity limiter preserving species-flux closure;
- explicit SSPRK2 transport and a two-dimensional parabolic timestep gate;
- symmetric reaction/transport/CTU-hydro operator composition;
- x/y dimensional-reduction, shear-wave, species-wave, thermal-wave, and
  reacting-hotspot regressions.

## Local validation

- GNU Fortran Debug suite with bounds/FPE checks: `90/90` passed;
- GNU Fortran Release suite: `90/90` passed;
- x- and y-normal dimensional reduction agrees with the qualified 1D
  transport operator to roundoff;
- the trace-species limiter activates under an intentionally oversized
  explicit interval while preserving zero net species flux.

## Qualification boundary

This is a periodic, uniform-grid, dilute ideal-gas, mixture-averaged subset.
Soret/Dufour effects, bulk viscosity, multicomponent diffusion, polar and
high-pressure corrections, physical wall fluxes, AMR, EB, and parallel
execution remain outside this milestone.
