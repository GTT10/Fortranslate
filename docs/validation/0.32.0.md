# PeleF 0.32.0 validation record

## Scope

This milestone connects tag-driven arbitrary-depth hierarchy construction,
periodic conservative regridding, simulation control, diagnostics, and ordered
composite output to the runnable one-dimensional reactive AMR application.

## Automated evidence

`regression_amr_multilevel_regrid_1d` initializes a three-level hierarchy from
hotspot density gradients with `amr_max_levels = 3`. It perturbs a valid
uncovered root cell to force a hierarchy change, then requires deepest-to-root
average-down and reconstruction to preserve every composite conserved component
within `5e-13`.

The same test runs a dynamic periodic three-level PLM simulation with regrid
evaluation every coarse step. It requires at least two evaluations, three
active levels, and five-component conservation within `3e-10`. It also invokes
the recursive composite writer.

`regression_amr_multilevel_hotspot_run` executes
`pelef_amr_reactive_1d` through the new `amr_max_levels = 3` branch.
`regression_amr_multilevel_hotspot_check` requires levels `0/1/2`, three
successive ratio-two spacings, ordered positions, exact domain coverage within
`3e-13`, finite positive thermodynamic states, and species closure within
`3e-10`.

The complete Debug and Release serial suites remain active. Main integration
also runs the MPI-enabled Debug and Release suites for the existing distributed
uniform-grid paths.

## Qualification boundary

This milestone qualifies one strictly nested patch per level and conservative
reconstruction through the synchronized root. Fine values in geometric overlap
are retained only by the unchanged-plan fast path; changed multilevel plans do
not yet have general overlap-preserving transfer. Multiple patches,
physical-boundary refinement, MPI patch ownership, load balancing, embedded
boundaries, and characteristic PPM/WENO AMR reconstruction remain future work.
