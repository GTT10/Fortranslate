# PeleF 0.74.0 validation record

## Scope

This milestone starts the embedded-boundary subsystem with a standalone 2D
Cartesian geometry builder. Nodal level-set values produce bounded cell-volume
fractions, x/y face open-area fractions, and regular/cut/covered cell types.

## Automated evidence

The unit gate requires exact all-fluid and all-solid fields. An off-grid
vertical plane must recover analytical domain area, a single cut-cell column,
and exact `0.30` cell and horizontal-face fractions. A diagonal plane must
recover its analytical area within `3e-13` absolute.

A circular signed-distance field is built on `20x20` and `40x40` meshes. Both
must contain nontrivial cut-cell sets, the refined set must grow, and the fine
integrated-area error must be less than `0.28` of the coarse error. Geometry
validity also checks extents, spacing, allocation bounds, finite fractions,
range bounds, and cell-type consistency.

Implementation commit `ea909d5` is qualified by branch CI run 32742486504 in
GNU Fortran Debug and Release configurations.

## Qualification boundary

The geometry is a fixed-diagonal piecewise-affine level-set reconstruction.
It does not claim AMReX EB2 topology parity. Cut-face centroids and normals,
cut-cell flux divergence, redistribution, small-cell stabilization, embedded
wall conditions, AMR refinement, and distributed ownership are not
implemented.
