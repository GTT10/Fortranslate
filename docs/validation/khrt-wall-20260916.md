# KH children with stationary wall impact — 2026-09-16

## Source and implementation

Tested parent: `050e097939e0da1d2300dc11b8688d6a5a07feac` plus this change.
Exact modified source/test hashes and logs are in `build/khrt-wall-checks/`.
Existing KH and wall correlations remain pinned by `references/spray_khrt.json`
and `references/spray_wall_impact.json`; this change connects their event handling.

For KH child mode, an accepted flight segment that crosses an enabled wall
undergoes impact before aerodynamic breakup. A hit skips KH release for that
substep, preventing duplicate ownership of incident mass. Otherwise, KH children
are generated normally and can impact during subsequent flight. The default
representative-breakup path preserves its preceding event order.

Splash children start with empty KH accumulators. Deposition clears the consumed
parent's accumulators, thermal breakup resets them, and rebound preserves them.
Film patches, children, gas exchange and wall budgets participate in the existing
whole-step transaction. The wall property preflight no longer substitutes ETAB
for an already selected KHRT model. Existing checkpoint fields support the combined
film/lineage/KH state without another format version.


The application test uses 1000 m/s, 20-micron droplets, 1e-14 kg initial liquid
and an initial wall distance of 0.35 mm. At the step-3 checkpoint KH children
already exist and film mass is zero; by 1 microsecond film mass is positive.
Mass, momentum and total energy close with wall budgets. Continuous and resumed
runs produce byte-identical final gas, parcel, film CSVs and checkpoints.
The kernel checks fresh/retained KH inventories across all six impact regimes;
the integration test checks their rollback after a late chemistry failure.

Development first exposed the ETAB-only wall property preflight, which was fixed.
A 1e-10 kg trial then reached the existing wet-splash rejection at approximately
KV=2201.37 and h/d=0.10033: the azimuthal correlation produces an inadmissible
mass partition for this nearly normal incidence. No correlation guard was relaxed.
The final lower-dose case avoids overlapping thick film and checks the supported
combined path. The initial four-entry test run therefore had three passes and a
CLI failure. The final run passed all four CTest entries in 48.74 s, including
34 Python CLI tests (48.01 s) without skips. Provenance, Python syntax, project
contract and whitespace checks passed. Final results are in `final-tests.log`.

## Boundary

Events still occur at the accepted substep's end, rather than exact continuous
impact/breakup times. Wet-splash correlation limits, moving-wall impact, lateral
film transport, mixture droplets and particle MPI/AMR/EB remain open. The check
establishes conservative coupled behavior and deterministic restart within this
scope; no external trajectory parity, full matrix or physical validation was run.
