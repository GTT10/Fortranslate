# PeleF 0.126.0 validation record

## Scope

This milestone adds a public multi-step full-physics time loop for static
sparse MPI reactive EB AMR storage.

## Automated evidence

The target time is `1.25` times the initial qualified hydro/transport stable
interval. An independent serial patch-set loop recomputes its timestep after
every accepted `R-T-H-T-R` transaction, forcing at least two steps and an exact
final-interval clip. The sparse loop must match the serial target time, step
count, minimum dt, transport limiter minimum, root state and temperature, and
both child fields within the stated regression tolerances.

Expected chemistry, hydro, transport, and timestep-root-gather counts are
formed independently for each rank and multiplied by the committed step count.
A second run with a total-step limit of one must report failure before a second
advance while preserving the first committed state, clock, minimum dt, all
operator counts, root-transfer count, and sparse-container validity.

Implementation head `45b3732` was qualified by ordinary CI run `32925166634`
and MPI CI run `32925166632`. GNU Fortran Release and bounds/FPE-checked Debug
both passed the complete 208-test serial regression. The MPI workflow also
passed the public sparse time-loop parity, exact clipping, committed-prefix
accounting, and all established MPI gates at one, two, four, and eight ranks in
both configurations.

## Qualification boundary

The public loop keeps the sparse hierarchy topology fixed. Dynamic sparse
regridding, checkpoint/restart, parallel output, locally decomposed root
physics, and production-scale load/performance qualification remain outside
this milestone.
