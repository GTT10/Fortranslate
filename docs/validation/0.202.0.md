# PeleF 0.202.0 validation record

## Scope

This milestone starts the regular three-dimensional workstream with a uniform
mesh API and z-normal inviscid flux semantics for ideal-gas,
passive-multispecies, and general-EOS reacting states.

## Automated evidence

- `unit_mesh_3d` checks independent x/y/z spacing and endpoint cell centers;
- `unit_directional_flux_3d` checks conserved and primitive rotation round
  trips, analytic physical flux placement, equal-state Rusanov/PeleC-style
  consistency, and invalid-solver rejection;
- `unit_multispecies_flux` checks z-normal donor flux and exact species-flux
  closure beside the retained x/y gates;
- `unit_reactive_directional_flux_3d` checks equal-state H2/O2 HLLC mass,
  momentum, energy, and species flux placement;
- the complete Debug, Release, Cantera, and OpenMPI regression boundaries from
  `0.201.0` remain required.

## Qualification boundary

This is a coordinate and face-flux foundation. It does not contain or claim a
3D conservative update, CFL calculation, boundary fill, transport divergence,
AMR/restart path, MPI decomposition, EB geometry, convergence result, or
application executable.
