# PeleF 0.132.0 validation record

## Scope

This milestone adds root-only formatted checkpoint read and direct
root-to-owner sparse MPI reactive EB AMR restart scatter without an all-rank
numerical-field broadcast.

## Automated evidence

The direct gate gathers the exclusively owned two-child hierarchy to one root,
then scatters those root-only fields back to the current owners. Every local
root tile and child must match the original sparse payload bitwise, retain the
same stored-value count, and allocate complete input fields only on the root.
The root reports one send per remotely owned entity; every other rank reports
zero and the communicator sum matches the independent owner map.

The checkpoint gate writes the formatted serial-compatible file, reads it only
on the selected root, and directly scatters the reconstructed hierarchy. It
requires the same owner-local field parity and exact time, step, regrid,
minimum-timestep, and base-density metadata. A missing file must return an
empty sparse set, zero metadata, and zero traffic collectively.

Qualification head `5841be7` is covered by ordinary CI run `32942294790` and
MPI CI run `32942294850`. GNU Fortran Release and bounds/FPE-checked Debug passed
the complete 208-test serial regression. The MPI workflow also passed all
established gates at one, two, four, and eight ranks in both configurations.

## Qualification boundary

The caller still supplies a replicated coarse geometry and full patch-set
template matching the checkpoint topology. Geometry-only topology metadata,
checkpoint-driven dynamic topology reconstruction, a dedicated cross-run
rank-count redistribution application, arbitrary-depth dynamic EB topology,
and decomposition of the level-wide root physics kernel remain separate work.
