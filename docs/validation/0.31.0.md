# PeleF 0.31.0 validation record

## Scope

This milestone connects the arbitrary-depth one-dimensional hierarchy to
general-EOS reactive conserved states, temperature recovery, ghost filling,
recursive hydro, recursive molecular transport, chemistry, reflux,
average-down, composite integration, and transactional split advancement.

## Automated evidence

`regression_amr_multilevel_reactive_1d` constructs a three-level hotspot with
`24`, `36`, and `56` cells and ratios `2/2`. The root has periodic physical
ghosts; both children use time-interpolated coarse/fine ghosts. Limited PLM
hydro recursively takes `2` and `4` root-relative substeps, while molecular
transport recursively takes `4` and `16` root-relative substeps.

Two coupled hydro/transport root steps must preserve the complete periodic
composite conserved integral within `3e-10`. Restriction of every child must
equal its covered parent state within `5e-13`. Every cell on every level must
retain a valid positive thermodynamic state, nonnegative species densities,
and mass-fraction closure within `3e-10`.

A separate chemistry-enabled `R-T-H-T-R` step exercises chemistry on all three
levels and repeats the synchronization, positivity, and closure gates. The
complete Debug and Release serial suites remain active. Main integration also
runs the MPI-enabled Debug and Release suites for the existing distributed
uniform-grid paths.

## Qualification boundary

This milestone qualifies static, strictly nested, single-patch-per-level
reactive advancement at arbitrary depth. The runnable solution-driven AMR
application and its output remain two-level. Dynamic multilevel regridding,
multiple patches, physical-boundary refinement, MPI patch ownership, load
balancing, embedded boundaries, and characteristic PPM/WENO AMR reconstruction
remain future integration work.
