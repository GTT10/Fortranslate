# PeleF 0.225.0 validation record

## Scope

This milestone adds `pelef_reactive_2d_selected`, a configure-time selected
mechanism front end for the existing serial single-level regular-grid 2D
reacting-flow application. It supports that application's periodic and
physical domain boundaries, PCM and characteristic PLM/PPM reconstruction,
optional CTU, native chemistry, and molecular transport for normalized
schema-1 bundles containing 2--32 species.

Fixed and selected front ends call one mechanism-independent application
driver. The selected 2D runtime has a private Fortran module directory, links
the selected 1D core, and contains neither committed generated mechanism. The
selected 3D runtime now links this selected 2D target instead of compiling a
second copy of its regular 2D dependencies.

## Startup and configuration evidence

The ordinary fixed parser rejects `chemistry_model = "selected"` unless the
configured selected front end opts in. Shared startup validation checks bundle
structure, molecular-mass balance, transport ordering, a finite common NASA7
interval, and exact species-name composition resolution before output.

The 2D configuration has bounded 32-species composition and prescribed-wall
flux records. Resolution against the loaded bundle rejects nonzero flux slots
beyond its actual species count. Unit and application gates also reject
duplicate or unknown names, nonfinite composition tails, unsafe composition
waves, selected input sent to the fixed executable, overlapping hotspots above
the common thermo range, and initial isothermal reflected ghost temperatures
below that range. All application-level rejection gates prohibit a CSV
artifact.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in
one serial single-level regular-grid 2D application, including its established
domain physical-boundary controls. It is not selected AMR/EB/MPI dispatch,
runtime YAML/JSON loading, CVODE-backed CFD chemistry, mechanisms above 32
species, thread-safety or performance evidence, detailed-fuel validation,
external PeleC field parity, or experiment validation. The repository license
remains an explicit owner decision and release blocker.
