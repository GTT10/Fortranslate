# PeleF 0.240.0 validation record

## Scope

This milestone qualifies rank-local sparse storage and characteristic-PLM
hydrodynamics for the existing static, periodic, two-level 3D AMR hierarchy.
It replaces the public MPI application's replicated numerical fields while
preserving the serial arithmetic and schema-2 persistence contract.

## Ownership and communication contract

Coarse cells use deterministic uneven x slabs. Fine x planes are assigned to
the owner of their parent coarse plane, and a valid rank may therefore own no
fine cells. Each hierarchy stores only local conserved state and temperature.
The coarse operator propagates two periodic ghost planes, including across
one-cell slabs. Active fine ranks exchange internal x ghosts; fine exterior
ghosts use time-interpolated coarse start/end halos and the serial limited
prolongation arithmetic.

Public physics and I/O operations compare ownership arrays, patch layout,
NASA7 species records, floating controls, and textual solver/reconstruction/
limiter metadata before payload-dependent communication. Candidate state,
reflux, average-down, and recovered temperature are published only after
collective acceptance.

## Focused qualification

Final-source GNU/OpenMPI Debug and Release focused sets each pass 26/26 tests.
Each set contains direct one-/two-/four-/eight-rank sparse unit execution,
PCM and characteristic-PLM serial references, one-/two-/four-/eight-rank
public runs, physical/coarse-fine checks, exact output comparison, two-rank
checkpoint-stop, independent four-/eight-rank restart, and exact restart
comparison.

The direct MPI gate additionally checks parent-aligned coverage, four
zero-fine-cell ranks at eight ranks, local storage reduction, previous/next
fine neighbors, both periodic coarse halo planes, CFL and PLM face/state bits,
full reflux/average-down bits, invalid-control rollback, and collective
rejection of rank-dependent valid metadata and gather layouts. A dedicated
negative-state regression also proves that a rank with no fine cells cannot
overwrite a failed local coarse CFL validation and that the collective API
returns a deterministic false status with a zero timestep.

## Qualification boundary

This evidence establishes rank-local memory and exact rank/restart parity for
one static, strictly interior, periodic, inviscid two-level hierarchy under
PCM or characteristic PLM. Root gather/scatter keeps schema 2 rank-neutral
but is compatibility I/O, not scalable I/O. Dynamic topology, AMR chemistry
or molecular transport, physical coarse boundaries, CTU/PPM, 3D EB AMR,
performance scaling, detailed-fuel physical validity, and external PeleC
field parity remain outside this milestone.
