# PeleF 0.216.0 validation record

## Scope

This milestone adds optional molecular transport to the serial, single-level,
exact-axis-plane `pelef_reactive_eb_3d` workflow. The qualified path uses
order-zero StateRedist for both SSPRK2 transport stages and composes the whole
candidate transactionally as `R(dt/2)-T(dt/2)-H(dt)-T(dt/2)-R(dt/2)`.

## Automated evidence

- x-, y-, and z-normal `kappa=0.05` units cover the active-state transport
  bound, aperture-weighted residual, SSPRK2 response, all-component and H/O/N
  conservation, exact covered identity, and species-limiter activation;
- physical-domain and adiabatic slip/impermeable EB transport faces are
  checked as exact zero;
- disabled transport is bitwise identical to the `0.215.0` `R-H-R` wrapper;
- invalid intervals, process dependencies, solver/redistribution selections,
  transport-table extents, output shapes, and late candidate failures retain
  caller state and temperature exactly;
- barodiffusion without species diffusion is rejected consistently by the
  face, regular-grid, EB, configuration, and full-driver APIs;
- public control, transport-only, and coupled cases independently check all
  480 CSV rows, geometry, NASA7 EOS and energy, positivity, closure, raw
  covered rows, physical-volume conserved/elemental totals, resolved transport
  and chemistry response, configuration/operator logs, step schedule,
  transport diagnostics, and complete output hashes.

## Qualification boundary

The transport subset is Newtonian viscosity, Fourier conduction,
mixture-averaged species diffusion, barodiffusion, correction velocity, and
species-enthalpy flux for the frozen seven-species elementary mixture. Only
open interior Cartesian faces carry transport. Physical-domain faces and the
embedded wall have exactly zero transport flux. The hydro boundary remains
zero-gradient, and the public cases stop before boundary exchange enters the
conservation comparison.

This record does not qualify isothermal/no-slip/catalytic or prescribed-flux
3D walls, FluxRedist transport, general or curved geometry, higher-order
face-centroid interpolation, AMR/reflux/regridding, checkpoint/restart, MPI
ownership, configurable mechanisms, external PeleC field parity, or physical
validation. The public step is selected before the first reaction stage; no
general reaction-aware stability claim is made.

## Local qualification results

The final local matrix used GNU Fortran 13.3.0, CMake 3.28.3, Python 3.12.3,
and `/usr/bin` Open MPI 4.1.6. All five rebuilt configurations passed:

- serial Debug: 272/272 tests in 773.65 s;
- serial Release: 272/272 tests in 243.15 s;
- serial Debug with live Cantera references: 275/275 tests in 773.00 s;
- MPI Debug: 287/287 tests in 786.71 s;
- MPI Release: 287/287 tests in 250.71 s.

This is 1,393/1,393 configuration tests. A separate MPI Release two-rank
smoke test also passed with `LD_LIBRARY_PATH` removed. Both Debug and Release
public transport checkers reproduced the signatures and build-mode hashes
listed above.

Fresh Release installs were made in
`/tmp/pelef-0216-serial-Gfdz9A` and `/tmp/pelef-0216-mpi-nQkCAv`.
They contain 17 and 28 executables; every installed file is byte-identical to
its build-tree artifact. The executable-stack audit passed all 17 and all 28
ELFs. All 11 MPI executables have no embedded RPATH/RUNPATH or Intel/oneAPI
reference, and clean-environment `ldd` resolved no Intel/oneAPI dependency.
The interactive shell's external `LD_LIBRARY_PATH` can instead select a
oneAPI `libhwloc` for system OpenMPI; removing that environment override
restores `/lib/x86_64-linux-gnu/libhwloc.so.15` and the smoke test passes.

The project contract passed at version `0.216.0` against upstream PeleC
`bf0e1fd15040`. Python compilation, tracked-diff whitespace checks, focused
Fortran line-width/trailing-whitespace checks, and the final source rebuilds
also passed.
