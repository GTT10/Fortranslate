# PeleF 0.37.0 validation record

## Scope

This milestone permits a one-dimensional multilevel reactive fine patch to
touch an outflow physical boundary. Boundary contact may continue through
successive nested levels. Fine outflow ghosts use constant extrapolation, while
the remaining interior side retains coarse-time and conservative spatial
interpolation.

## Automated evidence

The hierarchy and regrid unit gates accept boundary-touching geometry, verify
conservative endpoint prolongation, and prove that reflux ignores the physical
side while correcting the existing coarse/fine side. Multilevel hierarchy
validation also accepts boundary contact introduced below the root relation.

`regression_amr_multilevel_reactive_1d` adds a fixed three-level WENO7-Z case
whose two child levels share the left outflow boundary. Two hydro steps must
retain composite conservation within `3e-10`, parent/child synchronization
within `5e-13`, positive thermodynamics, and species closure within `3e-10`.

`regression_amr_multilevel_boundary_weno7z_hotspot_run` exercises the public
configuration reader, boundary-directed tagging, two nested patch creations,
recursive WENO7-Z advancement, one-sided reflux, regridding, and composite
output. Its checker requires three ordered levels, ratio-two spacing, complete
coverage within `3e-13`, finite positive states, and species closure within
`3e-10`.

All gates run in the GitHub Actions Debug and Release builds. Main integration
also retains the MPI-enabled Debug and Release suite.

## Qualification boundary

Dynamic physical-boundary refinement is qualified for outflow. A periodic
child can wrap at fine resolution only when it covers the full parent domain;
a one-sided patch crossing the periodic seam is rejected. The hierarchy still
owns one Cartesian patch per level. Multiple patches, MPI patch ownership,
load balancing, embedded boundaries, and accelerators remain future work.
