# PeleF 0.176.0 validation record

## Scope

The public sparse-MPI arbitrary-depth 2D EB application writes a four-level
checkpoint on two ranks, then restarts it independently on four and eight
ranks. The checkpoint and restart processes also use different MPI work
exponents, forcing a new owner map at the process boundary.

## Automated evidence

Implementation commit `3d81e93` is covered by ordinary CI run `33044419637`
and MPI CI run `33044419687`. GNU Fortran Debug and Release retain all 214
serial tests. MPI Debug and Release retain the complete established gate chain
and execute an uninterrupted one-rank reference, a two-rank checkpoint-stop
process, and four- and eight-rank restart processes.

The checker validates checkpoint framing and four-level metadata, requires the
stopped output to precede the exact final time, and keys completed composites
by level, patch, and local indices. Both restarted outputs must have identical
topology and columns and every numeric field must agree with the one-rank
reference within `3e-10 * max(1, abs(reference))`. The new MPI restart step
passes in 19 seconds for Release and 46 seconds for bounds/FPE-checked Debug.
Local Python syntax, physical-input parity, and `git diff --check` also pass.

## Qualification boundary

This milestone qualifies public MPI application restart across changed rank
counts and ownership weights. Fresh startup still creates a temporary
replicated root field before sparse owner conversion; removing that startup
copy remains later work.
