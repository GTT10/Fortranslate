# PeleF 0.123.0 validation record

## Scope

This milestone replaces all-rank numerical broadcasts in direct sparse MPI
reactive EB AMR hydro with packed point-to-point root tile, child-owner bundle,
reflux-correction, and final tile transfers.

## Automated evidence

The qualified 14 by 14 plane-EB root is split into one row tile per available
rank and has two separated ratio-two 10 by 10 children. The independently
computed payload count is two messages per non-root-owner tile, one root bundle
per distinct remote child owner, and two correction messages per remote child.
Each rank's send count and the communicator sum must match at one, two, four,
and eight ranks; the single-rank count must be zero.

The direct sparse hydro transaction must retain each rank's exact stored-value
count and match serial multipatch root and child state and temperature within
`8e-12` field scale. The rollback case places finite negative density on the
final child owner; root and earlier child candidates may execute, but every
local sparse field must remain bitwise unchanged and published advance and
transfer counts must remain zero.

Implementation head `e86f31f` was qualified by ordinary CI run `32918554285`
and MPI CI run `32918554209`. GNU Fortran Release and bounds/FPE-checked Debug
both passed the complete 208-test serial regression. The MPI workflow also
passed the targeted hydro root-traffic gate and all established MPI gates with
OpenMPI at one, two, four, and eight ranks in both configurations.

## Qualification boundary

Hydro root traffic is targeted, but root physics itself remains a level-wide
single-owner operation. Direct sparse transport still broadcasts full root
state, temperature, and flux fields. Root physics decomposition, targeted
transport traffic, public time-loop control, dynamic topology, checkpointing,
and output remain outside this milestone.
