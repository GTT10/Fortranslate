# PeleF 0.162.0 validation record

## Scope

The arbitrary-depth sparse MPI tree now advances chemistry without
materialization. Each owner reacts and recovers temperature for its local
nodes in a private sparse candidate. Relation synchronization proceeds
deepest-first; a child state stays local when ownership matches and otherwise
moves directly once to the parent owner for EB average-down.

Every node reaction and child restriction has a collective acceptance boundary.
The accepted sparse tree and public advance/transfer counts commit only after
the complete candidate validates against the replicated distribution.

## Automated evidence

The physical four-level branching tree advances one `5e-9` second chemistry
interval after owner rotation. Global per-level chemistry counts must equal
`[1, 1, 2, 1]`. The sum of sender restriction counts must equal the exact
number of parent/child pairs with different owners. Explicit materialization
afterward must match every state and temperature value from the complete serial
chemistry transaction exactly.

chemistry interval while all other ranks retain the accepted value. The
one-rank gate supplies a negative interval. Both paths must reject before
mutation with zero chemistry/restriction accounting and exact sparse rollback.
