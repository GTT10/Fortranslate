# PeleF 0.230.0 validation record

## Scope

This milestone adds `pelef_reactive_eb_3d_selected`, a configure-time selected
mechanism front end for the established serial, single-level, exact planar
reactive EB 3D application. Fixed and selected front ends call one
mechanism-independent application driver for geometry construction, CFL
selection, optional `R-T-H-T-R` advancement, StateRedist or FluxRedist,
diagnostics, and dynamic-species CSV output.

The private selected runtime links the selected regular 3D runtime and
privately compiles only the generic planar EB geometry, CFL, wall flux,
redistribution, hydro, transport, driver, checkpoint-support dependency, and
application modules. It does not link `pelef_core` or a fixed mechanism.

## Dispatch and startup contract

Bundle-order mole fractions initialize both regular and cut states. The
bundle-declared `explicit` or `implicit` chemistry policy reaches both masked
chemistry half-steps. Fixed callers omit the optional composition and policy
arguments and retain the prior seven-species behavior.

The selected front end validates the regular and cut initial temperatures
against the common NASA7 interval before output. It rejects checkpoint or
restart requests, input/output aliases, invalid composition fields, unknown
or duplicate names, and chemistry-enabled species outside the qualified
H/O/N/Ar name set. The selected persistence path remains excluded because the
fixed checkpoint schema does not record a selected bundle fingerprint,
composition, or generated integrator policy.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in
the existing serial, single-level, static, exact non-face-aligned planar EB 3D
path for the H2/H fixture, fixed seven-species mechanism, and pinned
full-H2/O2 bundle. It does not qualify selected EB3D checkpoint/restart,
arbitrary element diagnostics, general embedded geometry, EB AMR or MPI EB
3D, runtime mechanism loading, CVODE-backed CFD chemistry, mechanisms above
32 species, detailed fuels, thread safety, performance/scaling, external
PeleC field parity, or experiment validation. The repository license remains
an explicit owner decision and release blocker.
