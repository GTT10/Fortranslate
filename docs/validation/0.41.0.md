# PeleF 0.41.0 validation record

## Scope

This milestone adds the static geometry and conservative field layer for an
arbitrary-depth branching multipatch hierarchy. Every child has explicit
parent ownership, each parent owns a separated child set, and per-relation
prefix offsets provide deterministic flattened level indexing.

## Automated evidence

`unit_amr_patch_tree_1d` constructs four levels containing `1/2/3/2` patches.
The first relation creates two root children. The second gives two children to
the first parent and one to the second. The third refines the first and third
parents while the middle parent has an empty child set. Ratios are two, two,
and three, producing a deepest spacing of `1/192` over a 16-cell unit domain.

The gate checks parent counts, flattened child indices, physical bounds through
a branched parent, and rejection of an invalid parent index. A two-component
linear root field is conservatively prolonged through every branch. The
resulting composite integral matches the root within `5e-12`. Independent
perturbations are then applied to two deepest patches; deepest-to-root
average-down synchronizes every child/parent covered interval and preserves
the perturbed composite integral within `5e-12`.

All gates run with array-bounds checking in the GitHub Actions Debug build and
again in Release. Main integration also retains the MPI-enabled Debug and
Release suite.

## Qualification boundary

This is a static data-structure and conservation milestone. The reactive
arbitrary-depth driver still owns one patch per level. Patch-tree subcycling,
reflux, chemistry and transport, dynamic tag planning, overlap-preserving tree
rebuilds, adjacent boxes, same-level ghost exchange, load balancing, and MPI
patch ownership remain future work.
