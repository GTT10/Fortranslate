# 0.246.0: periodic spray/LES and cell-local stiff chemistry

Numerical parent: merged `5a2c818899f7213dad2fbb3c6808558711aced10` (0.245.0).
This milestone adds an opt-in coupled regular-grid spray application. Feature
scope, equations, reference conventions, reproducible commands and limitations
are defined in [the spray guide](../spray.md), not inferred from test counts.

## Acceptance gates

- Frozen-film analytical drag/heat/diameter-squared tests and terminal mass transfer.
- Correct vapor/carrier binary-diffusion limit; material/source energy alignment.
- Periodic CIC partition, conservative all-phase transfer and global rollback.
- Deviatoric SGS algebra, dissipation, conserved face fluxes, zero-coefficient identity and invalid-step rejection.
- Repeated cell-local native/CVODE chemistry, total-energy preservation and context lifecycle over 125 cells.
- Deterministic truncated mass-CDF diameter quantiles, exact injected mass and size-distribution restart.
- Three-level outer-timestep refinement of coupled temperature/liquid-mass histories.
- Scheduled injection and complete coupled checkpoint with no-overwrite and strict invalid-file rejection.
- Independent Cantera 3.2.0 gas-phase histories/compositions for H2 and FFCM1_Red methanol, including ignition.
- Closed methanol-droplet evaporation to fuel oxidation/net heat release, with all-phase mass/energy/element accounting.
- Nonuniform reacting cone with molecular transport, LES, timed injection and exact checkpoint/restart.
- Importer portability (chemical labels, single-interval NASA7 and classified Lindemann) plus unchanged existing generated H2/O2 provenance.
- Independent Debug/Release and hosted CI; new opt-in tests must not silently register zero cases.

## Evidence boundary

Executed results, exact final commit/tree, compiler and dependency versions,
commands, JUnit files and archive digests are recorded in the implementing PR
and its retained evidence. This record does not predeclare a pending CI run
successful. Development runs belong to their corresponding source snapshots,
not automatically to the final commit. Failed or interrupted runs are excluded.

The Cantera gas-only comparisons are external chemistry checks. The liquid
burn/cone tests are conservation and integration checks, **not experimental
spray validation**. Default-disabled spray preserves previous numerical paths;
old 0.245.0 tests are not reused as 0.246.0 qualification.

## Development findings retained

A first draft incorrectly multiplied PeleF's mixture-averaged diffusivity by a
PelePhysics molecular-weight conversion. An independent water/nitrogen binary
limit exposed the mismatch (6.3021e-5 versus 4.0527e-5 m2/s in the test state).
The feature now evaluates the carrier-normalized harmonic binary coefficient
directly; `spray_film_binary` guards that physical convention. All published
liquid-burn acceptance results must come from the corrected implementation.

The mechanism importer previously could not handle FFCM1_Red's excited-state
label, single-interval atomic NASA7 data and Lindemann falloff. Portability tests
now cover each positive and malformed negative case, without broadening support
to unknown falloff laws or changing physical reaction data. Upstream YAML and
license are hash-pinned in `references/spray_methanol.json`.
