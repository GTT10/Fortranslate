# PeleF 0.76.0 validation record

## Scope

This milestone adds a stationary inviscid reactive slip-wall flux on a 2D
embedded boundary and its volume-normalized cut-cell source contribution.

## Automated evidence

The wall kernel must recover `135000 Pa` from a seven-species conserved state,
apply `-p*n` for an oblique `(0.6, 0.8)` solid-to-fluid normal, and return exact
zero mass, z-momentum, total-energy, and species fluxes. The same test verifies
90-degree rotational covariance, independence from fluid velocity, analytical
integrated forces for vertical and diagonal walls, cut-cell-only support, and
all-zero output after rejected normal or state input.

Implementation commit `610b688` is qualified by branch CI run 32747184530 in
GNU Fortran Debug and Release configurations.

## Qualification boundary

This source is only the embedded-wall term. Cartesian face-fraction flux
divergence, complete cut-cell time integration, redistribution/small-cell
stabilization, viscous/thermal/catalytic walls, AMR, and MPI coupling are not
implemented.
