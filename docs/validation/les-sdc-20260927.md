# Regular LES SDC coupling — 2026-09-27

Implementation `dc7c15ca`, based on `11f7dead`, local main, version 0.246.0.

## Change and API

The opt-in spray/LES runtime now exports `les_sdc_3d_mod:advance_les_sdc_3d`.
It evaluates a force source and a LES source at old/new SDC stage states, with
optional molecular transport in the final family. Existing Smagorinsky, WALE,
Vreman and Dynamic RHS operators supply stresses, heat and species exchange.
Boundary and inlet controls reach both gas and LES operators. Dynamic filter
controls and optional reaction/source-history arguments are forwarded.

The wrapper accumulates old/final LES boundary rates with half-interval weights,
moves that inventory out of the volumetric source ledger and into the boundary
ledger, and reports the maximum stage diffusivity. Private gas, temperature and
reaction history publish with diagnostics only on success. The API does not
export combined LES face fluxes for AMR reflux yet, and has no application input
routing yet. It does not implement LES on EB cut cells.
