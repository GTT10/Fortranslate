# PeleF 0.226.0 validation record

## Scope

This milestone adds `pelef_amr_reactive_1d_selected`, a configure-time selected
mechanism front end for the existing serial reactive 1D AMR application. It
supports solution-driven two-level AMR, arbitrary-depth multilevel AMR, and
dynamic multipatch level one with the application's existing PCM, PLM, PPM,
characteristic PPM, native chemistry, and molecular-transport controls for
normalized schema-1 bundles containing 2--32 species.

Fixed and selected front ends call one mechanism-independent application
driver. The selected AMR runtime has a private Fortran module directory, links
the selected regular-1D runtime, and contains neither committed generated
mechanism. Existing callers retain source-compatible optional composition
and integrator arguments when rebuilt. The changed Fortran module interfaces
are not a binary ABI for linking old objects or archives without recompiling.

## Startup and configuration evidence

The fixed parser continues to reject `chemistry_model = "selected"` unless a
configured selected front end opts in. The selected AMR executable additionally
requires `amr_enabled` and rejects the checkpoint/restart controls that this
application does not implement. Shared startup validation checks bundle
structure, molecular-mass balance, transport ordering, a finite common NASA7
interval, and exact species-name composition resolution before output.
Complete schema-1 bundles must also declare `chemistry_integrator` as
`explicit` or `implicit`. The generated constant reaches every selected
regular 1D/2D/3D and AMR 1D chemistry stage, replacing selected policy
inference from species count while preserving fixed-front-end behavior.

The temperature gate covers the actual initial hotspot extrema and the
constant-pressure entropy-wave range `T0/(1+A)` through `T0/(1-A)`. Regression
cases reject an unknown species, a non-AMR selected input, an entropy wave
outside the common NASA7 interval, all checkpoint/restart controls, a lexical
input/output alias, and selected input sent to the fixed AMR executable, all
without an output artifact.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in
the existing serial reactive 1D AMR application across its two-level,
multilevel, and multipatch modes. It is not selected AMR checkpoint/restart,
selected EB/MPI dispatch, runtime YAML/JSON loading, CVODE-backed CFD
chemistry, mechanisms above 32 species, thread-safety or performance evidence,
detailed-fuel validation, external PeleC field parity, or experiment
validation. The repository license remains an explicit owner decision and
release blocker.
