# PeleF 0.92.0 validation record

## Scope

This milestone adds lifecycle-aware formatted checkpoint/restart to the serial
reactive EB AMR application. Checkpoints preserve an active two-level or
root-only hierarchy, run/regrid cadence, minimum timestep, base density, species
ordering, and the configuration required for compatible continuation.

## Automated evidence

The direct driver gate round-trips an active fine hierarchy and requires exact
coarse/fine conserved state, actual patch bounds, lifecycle flag, time, steps,
regrids, minimum timestep, and base density. EOS-recovered active temperatures
remain within `3e-12` scaled tolerance. A second round trip follows reacting
fine-patch collapse and proves that root-only restart leaves every fine array
unallocated and its geometry and patch metadata invalid. A stream truncated
after the valid magic header is rejected without publishing any state or
geometry output.

The public regression advances a uniform 1200 K elementary H2/O2 hierarchy.
Its checkpoint run completes one reacting fine-level interval, conservatively
removes the untagged patch, writes a root-only checkpoint, and stops before
final time. The restart resumes with the stored counters and matches every
final coarse CSV value from an uninterrupted reference within `3e-10` scaled
tolerance. It also proves reaction progress, species closure, the formatted
end marker, and absence of stale fine output.

Implementation head `be69715` is qualified by
[branch CI run 32833612627](https://github.com/GTT10/Fortranslate/actions/runs/32833612627)
in GNU Fortran Debug and Release configurations. All 168 tests passed in both;
Release completed in 146 seconds and Debug in 452 seconds. The test phases took
103.38 and 425.96 seconds respectively, with bounds, backtrace, and
floating-point exception checks enabled in Debug.

## Qualification boundary

The schema covers one serial root and at most one strictly internal,
ratio-aligned fine rectangle. It is formatted rather than parallel or
asynchronous and requires compatible mesh, EB geometry, physics, redistribution,
and regrid settings. Distributed EB checkpoint I/O, multiple fine patches,
deeper levels, and EB AMR molecular transport remain outside this milestone.
