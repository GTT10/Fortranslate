# PeleF 0.172.0 validation record

## Scope

The serial arbitrary-depth reactive 2D EB tree now writes one composite CSV.
Every parent cell covered by a finer child is omitted, while every remaining
leaf cell appears once with topology identity, EB diagnostics, conserved and
primitive state, recovered temperature, and ordered species mass fractions.
Sparse MPI gathers numerical nodes only to a selected root and invokes that
same writer there.

## Automated evidence

The serial gate writes the qualified four-level branching tree. Its data-row
count must equal the sum of every node's cells minus every child coarse-
rectangle area, and its header must include volume fraction and the first and
last ordered species.

The MPI gate uses the physical sparse tree and the last rank as output root.
The global gather count must equal the number of nodes whose owner differs from
that root. Only the root opens, counts, and deletes the output, and the same
topology-derived composite row count must hold at one, two, four, and eight
ranks.

Qualification commit `a233441` is covered by MPI CI run `33039369822`. GNU
Fortran Debug and Release pass every established MPI gate at one, two, four,
and eight ranks and the complete 208-test serial regression. Local `fparser2`
parsing passes all four touched Fortran sources, and `git diff --check` is
clean.

## Qualification boundary

This milestone closes composite diagnostic output for the serial and sparse
MPI arbitrary-depth numerical EB tree. It does not yet expose that tree through
a runnable arbitrary-depth 2D EB application input lifecycle.
