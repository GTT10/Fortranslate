# PeleF 0.81.0 validation record

## Scope

This milestone turns the complete first-order reactive EB hydro update into an
input-driven serial application with plane/circle geometry, active-cell CFL
selection, final-time integration, volume-weighted diagnostics, and
geometry-aware CSV output.

## Automated evidence

The unit gate builds a circular obstacle with all three cell classes and checks
the uniform-state CFL against `CFL/(c/dx+c/dy)`. Componentwise integrals must
match a direct `sum(kappa*U)*dx*dy` calculation. A complete stationary run must
reach the final time, preserve state and temperature, conserve every component,
retain positive active-cell density and pressure, and keep species closure.
Invalid CFL, geometry without cut cells, and a direct chemistry-enabled call
must be rejected.

The executable regression reads `cases/reactive_eb_circle_2d/uniform.nml`,
advances the 20 by 20 field, and writes 400 CSV rows. The checker requires
regular, cut, and covered cells; positive cut-boundary length; finite bounded
geometry; positive thermodynamic fields; stationary velocity; pressure and
temperature preservation; and species closure.

Implementation commits `2a41eff` and `a3ad17e` are qualified by branch CI runs
`32760575153` and `32761273736` in GNU Fortran Debug and Release
configurations. The full suite contains 146 tests.

## Qualification boundary

This is serial, single-level, piecewise-constant reactive Euler hydro with
zero-gradient outer faces and a stationary adiabatic impermeable slip wall. It
does not include chemistry or molecular transport splitting, higher-order EB
reconstruction, face-centroid interpolation, periodic/inflow boundaries,
thermal/viscous/catalytic or moving walls, AMR, or MPI distribution.
