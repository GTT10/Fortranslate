# PeleF 0.45.0 validation record

## Scope

This milestone adds recursive molecular transport and complete
reaction--transport--hydro--transport--reaction composition to the static
arbitrary-depth reactive multipatch tree.

## Automated evidence

`regression_amr_patch_tree_reactive_1d` initializes a four-level
`1/2/3/2`-patch reactive hotspot with viscosity, Fourier conduction,
mixture-averaged species diffusion, barodiffusion, correction velocity, and
species-enthalpy transport enabled. The all-patch timestep rejects a missing
transport database and includes the cumulative ratio-squared fine limits when
the database is supplied.

Two copies advance through otherwise identical reaction and hydro operators.
Only one enables the two recursive transport half-steps, and their final states
must differ by more than `100 epsilon`. Transport call counts are exactly
`2/16/96/256`; composite mass, momentum, and total energy remain within
`2e-9`; every parent-child restriction agrees within `8e-13`; and all cells
retain positive temperature and pressure, nonnegative species, and species
closure within `3e-10`. A transport-enabled call without its database leaves
state and counters bitwise unchanged.

Branch CI run 32663845496 passed the full GitHub Actions Debug and Release
suite with GNU Fortran, including array-bounds checking in Debug.

## Qualification boundary

This milestone completes reaction, molecular transport, and PCM hydro
composition for static, strictly interior separated patch trees. Dynamic tag
planning, overlap-preserving tree rebuilds, adjacent boxes and same-level
exchange, physical-boundary children, load balancing, and MPI patch ownership
remain future work.
