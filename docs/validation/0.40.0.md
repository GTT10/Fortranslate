# PeleF 0.40.0 validation record

## Scope

This milestone connects the two-level multipatch reactive engine to the public
tag-driven AMR application. It adds runtime selection, disconnected-feature
clustering, periodic regridding, exact old/new fine-overlap transfer, lifecycle
statistics, and ordered exact-coverage composite CSV output.

## Automated evidence

`regression_amr_multipatch_dynamic_1d` starts from a uniform 48-cell periodic
parent with no fine patches. It introduces two deterministic velocity boxes,
creates two separated patches, moves both boxes, verifies nonzero aligned
fine-overlap transfer, removes the boxes, and confirms that the patch set
becomes empty. The gate checks every conserved-component composite integral
within `8e-12` after creation, movement, and removal, and pins the expected
evaluation and accepted-regrid counters. It also verifies that multipatch mode
rejects an arbitrary-depth configuration.

The public `amr_multipatch_entropy_wave` case dynamically clusters separated
entropy-wave tags and advances the resulting patches through the combined
chemistry, molecular-transport, and hydro path. Its output gate requires at
least two separated fine segments, ordered rows, level spacings in ratio two,
domain coverage within `3e-13`, positive density, pressure, and temperature,
and species closure within `3e-10`.

All serial gates run with array-bounds checking in the GitHub Actions Debug
build and again in Release. Main integration also retains the MPI-enabled
Debug and Release suite.

## Qualification boundary

Dynamic multipatch application integration is limited to two levels and
separated patches. Periodic patches may not cross the domain seam. The
arbitrary-depth engine still owns one patch per level. Independent adjacent
boxes, same-level ghost exchange, changed refinement ratios inside a patch
collection, load balancing, and MPI patch ownership remain future work.
