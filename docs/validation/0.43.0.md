# PeleF 0.43.0 validation record

## Scope

This milestone connects reactive states to the arbitrary-depth multipatch tree
and adds transactional recursive PCM hydro subcycling, ghost fill, flux
accumulation, reflux, and average-down.

## Automated evidence

`regression_amr_patch_tree_reactive_1d` constructs a four-level static tree
with `1/2/3/2` patches. Two branches continue to the deepest level while one
level-three patch has no child. All refinement ratios are two and every child
is strictly interior to its parent.

One periodic entropy-wave root interval advances the levels exactly
`1/4/12/16` times. The test compares every conserved composite integral before
and after the step within `3e-10`. It restricts every child independently and
requires every covered parent interval to agree within `5e-13`. Every stored
cell must also recover positive temperature and pressure, positive sound
speed, nonnegative species, and species closure within `3e-10`.

Branch CI run 32661743368 passed the full GitHub Actions Debug and Release
suite with GNU Fortran, including bounds checking in Debug.

## Qualification boundary

This milestone qualifies static, strictly interior, separated patch trees for
reactive PCM hydro. Chemistry and molecular transport composition, dynamic
tag planning, overlap-preserving patch-tree rebuilds, adjacent boxes and
same-level ghost exchange, physical-boundary children, load balancing, and MPI
patch ownership remain future work.
