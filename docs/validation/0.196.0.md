# PeleF 0.196.0 validation record

## Scope

Arbitrary-depth serial and sparse-MPI checkpoints preserve the cumulative
minimum transport limiter theta across independent and changed-rank restart.

## Automated evidence

The direct serial round-trip writes a synthetic theta of `0.625` and requires
exact recovery with topology, fields, time, steps, regrids, and minimum root
timestep. Invalid theta metadata is rejected before replacing the checkpoint,
and a failed read returns neutral theta `1` with an empty tree.

The sparse selected-root round-trip writes the same nonneutral value, reaches
consensus on it, broadcasts it during restart, recomputes ownership, and
requires exact recovery on one, two, four, and eight ranks. Control rejection
must leave an empty distribution/tree, zero clock metadata, and neutral theta.

The public reacting x-upper split-run case requires schema 5 and retains its
serial and two-rank to four-/eight-rank field-parity checks. GNU Fortran Debug
and Release qualification run identifiers are recorded in the pull request
before merge. Python syntax and `git diff --check` are also required.

## Qualification boundary

This change preserves one cumulative diagnostic. It does not add checkpoint
compatibility with older schema versions or persist every internal per-level
physics counter.
