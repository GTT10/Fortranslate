# PeleF 0.199.0 validation record

## Scope

Arbitrary-depth serial and sparse-MPI checkpoints preserve cumulative
successful regrid-evaluation and tagged-cell history across independent and
changed-rank restart.

## Automated evidence

The direct serial gate writes synthetic evaluation and tagged-cell totals and
requires exact recovery. Partial history, fewer evaluations than committed
regrids, insufficient restart depth, and incompatible inputs are rejected;
failed reads publish zero scalar diagnostics.

The selected-root sparse gate repeats exact recovery at one, two, four, and
eight ranks. Multi-rank runs provide a different evaluation count on one rank
and require collective rejection before field gather. Successful restart
broadcasts both values with the clock metadata.

The public serial and sparse reacting restart chains capture application logs.
The checker requires exact regrid-evaluation and cumulative tagged-cell values
between uninterrupted execution and serial continuation or two-rank checkpoint
continuation on four and eight ranks. Existing topology, field, limiter,
conservation, and operator-counter comparisons remain active. GNU Fortran
Debug and Release CI run identifiers are recorded in the pull request.

## Qualification boundary

The tagged-cell diagnostic is an accumulated decision count, not a unique-cell
set or a topology-cost metric. Low-level callers that omit explicit history
receive a compatible baseline derived from the committed regrid count.
