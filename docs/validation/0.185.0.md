# PeleF 0.185.0 validation record

## Scope

The public reactive 2D EB AMR lifecycle carries `pcm` or conservative
limited-linear prolongation through fixed-depth and arbitrary-depth serial or
sparse-MPI initialization, regrid, checkpoint, and restart.

## Automated evidence

All fixed-depth restart regression inputs select linear, covering single/root,
separated sibling-patch, static three-level, and dynamic three-level schemas.
The four-level serial and 1/2/4/8-rank sparse-MPI public cases also select
linear. The cross-rank gate writes with two ranks and restarts with four and
eight ranks under changed ownership weighting. A PCM input is rejected against
that linear schema-4 fingerprint, and the direct two-level unit requires
method-mismatch rollback. The serial and sparse applications also gate every
transport subprocess with the public `transport_enabled` switch; the
hydrodynamic patch-tree cases explicitly disable those subprocesses.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. Version consistency, Python checker syntax, and
`git diff --check` are also required.

## Qualification boundary

The public default remains PCM. EB-aware slopes on cut parents, exact AMReX
interpolation/checkpoint compatibility, older-schema migration, and fixed-depth
MPI distribution are not claimed.
