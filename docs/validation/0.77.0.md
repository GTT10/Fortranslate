# PeleF 0.77.0 validation record

## Scope

This milestone combines open-fraction-weighted Cartesian fluxes with the
reactive embedded-wall pressure contribution in one conservative 2D cut-cell
divergence operator.

## Automated evidence

A uniform stationary seven-species state at `135000 Pa` is evaluated in an
all-fluid domain, an off-grid vertical plane, a diagonal plane, and a circular
embedded boundary. Every active cell must satisfy the discrete pressure
surface balance within `2e-10*p*max(dx,dy)` after multiplying the residual by
fluid volume; covered-cell residuals are exactly zero. Nonfinite flux input and
an undersized face array must return failure with an all-zero output.

The circular gate initially exposed loss of the integrated normal magnitude
when two segment normals were renormalized. Final implementation commit
`e316d39` preserves `integral(n ds)` separately and is qualified by branch CI
run 32749551365 in GNU Fortran Debug and Release configurations.

## Qualification boundary

The operator consumes already constructed Cartesian face fluxes. Neighbor
stencils beside covered cells, time integration, redistribution/small-cell
stabilization, viscous/thermal/catalytic walls, AMR, and MPI coupling are not
implemented.
