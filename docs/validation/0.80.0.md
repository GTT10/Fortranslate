# PeleF 0.80.0 validation record

## Scope

This milestone composes piecewise-constant reactive Riemann fluxes, the
conservative EB wall/open-face divergence, PeleC-default zeroth-order weighted
StateRedist, and transactional general-EOS recovery into one first-order
two-dimensional hydro update.

## Automated evidence

On an all-fluid grid, the generated flux at a deliberately nonuniform interior
face must match a direct HLLC call to `3e-12` relative tolerance. A
zero-gradient domain face must match the equal-state HLLC result. Every face
with zero aperture must remain exactly zero, while every open face of a uniform
stationary state must carry the matching Cartesian pressure flux.

The complete update is then exercised on all-fluid, vertical-plane,
diagonal-plane, and circular embedded-boundary geometries. For a uniform
stationary seven-species state, each active cell's extensive state change must
stay below `dt*2e-10*p*max(dx,dy)`, temperature must recover within `2e-8`, and
covered states must remain exactly unchanged. An unknown Riemann solver must
return zero face fluxes and roll back the full update; a nonfinite state must
also return zero face fluxes. An inconsistent positive-aperture face adjacent
to a covered cell must be rejected with both flux arrays unchanged at zero.

Implementation commits `4972d5b`, `f5ad760`, and `9242e60` are qualified by
branch CI run `32758333650` in GNU Fortran Debug and Release configurations.

## Qualification boundary

This is a piecewise-constant hydro update with nonperiodic zero-gradient outer
faces and stationary slip-wall EB physics. It does not include high-order EB
reconstruction/transverse prediction, face-centroid interpolation, periodic or
inflow boundaries, moving/thermal/viscous/catalytic walls, chemistry or
transport splitting, AMR coupling, or MPI distribution.
