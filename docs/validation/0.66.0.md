# PeleF 0.66.0 validation record

## Scope

This milestone removes the full-field correctness replica from explicit-plan
sparse topology changes. Candidate patches are built on their final owners and
retained fine cells travel directly between old and new patch owners.

## Automated evidence

The four-level topology-changing case builds a `1/3/3/2` patch hierarchy from
a different sparse tree. It reports local counts for cross-owner prolongation
and old/new overlap messages. An independent traversal of both hierarchy
geometries and owner maps reproduces the two communicator sums exactly for 1,
2, 4, and 8 ranks.

Gathering the rebuilt sparse tree matches the serial topology, state,
temperature, narrow ghosts, wide ghosts, time, counters, and overlap accounting
exactly. Composite conservation remains within `2e-9`. The unchanged plan sends
no regrid payload, and the invalid-plan gate preserves exact solution and
distribution rollback while returning zero communication counts.

Branch run 32719919387 passed the complete GNU Fortran Debug/Release MPI suite
with 1, 2, 4, and 8 ranks for implementation commit `2a3552e`.
Branch run 32719919394 passed the complete serial Debug/Release suite for the
same implementation commit.

## Qualification boundary

Explicit-plan sparse regrid now retains globally single-copy fields throughout
the transaction. Replicated compact topology metadata and collective acceptance
remain intentional. Tag-driven plan construction still uses a temporary
all-rank field replica and remains future work.
