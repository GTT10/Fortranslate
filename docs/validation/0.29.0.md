# PeleF 0.29.0 validation record

## Scope

This milestone adds viscosity, Fourier heat conduction, mixture-averaged
species diffusion, barodiffusion, correction velocity, and species-enthalpy
transport to the dynamic two-level reactive AMR application.

## Automated evidence

`regression_amr_reactive_transport_1d` first advances identical AMR hotspot
states with and without Fourier conduction. The conduction-enabled step must
reduce the composite temperature span relative to the inviscid reference.

The same regression then runs transport with PLM hydro and regridding. It
requires more than one coarse step and regrid evaluation, a live fine level,
positive thermodynamic recovery, nonnegative closed species mass fractions,
all-component and per-species periodic conservation within `2e-10`, and
covered coarse/fine synchronization within `5e-13`.

`regression_amr_reactive_hotspot_run` now enables chemistry together with
viscosity, conduction, species diffusion, and barodiffusion. Its existing CSV
checker continues to require ordered exact domain coverage, positivity,
species closure, a resolved hotspot, and both coarse and fine output.

The complete Debug and Release serial suites remain the branch and main
acceptance gates. The MPI-enabled suite remains active to guard all existing
1/2/4/8-rank uniform-grid functionality.

## Qualification boundary

This is a serial, one-dimensional, two-level, single-patch AMR qualification
using the existing dilute ideal-gas transport model. It is not a claim of
Soret or Dufour transport, multicomponent Stefan--Maxwell diffusion,
PelePhysics polynomial-transport parity, boundary-touching refinement,
multiple patches, arbitrary levels, distributed AMR, or embedded-boundary
diffusion.
