# PeleF 0.142.0 validation record

## Scope

This milestone bounds EB flux-register storage and repeated sparse MPI
transport reflux-correction traffic by fine-patch support. A register now
stores its globally indexed correction only on the patch rectangle expanded by
one coarse cell, which contains every coarse/fine flux-mismatch location.
Reflux scans that support instead of the complete root.

For a remote sparse transport child, the root physics owner sends and receives
only the patch rectangle expanded by two coarse cells. The second cell covers
every cardinal or diagonal recipient of a cut-cell mismatch. The child starts
from the uncorrected root candidate, overwrites that rectangle with the latest
cumulative values, performs the established reactive reflux transaction, and
returns the same rectangle. Returned regions merge in deterministic child
order.

## Automated evidence

The EB flux-register unit gate requires the stored lower and upper bounds to
match the patch-plus-one-cell support and requires fewer stored cells than the
qualification root. It repeats coarse/fine aperture cancellation, cut-cell
extensive conservation, fine-covered redistribution, reactive temperature
recovery, register reset, nonfinite accumulation rollback, and nonphysical
reflux rollback.

The sparse MPI gates retain exact message counts, owner work counts, field and
limiter parity, scheduled regridding, public time loops, and late-failure
rollback at one, two, four, and eight ranks. Qualification head `243a769` is
covered by ordinary CI run `32977341986` and MPI CI run `32977342016`. GNU
Fortran Debug and Release builds pass. OpenMPI one-, two-, four-, and
eight-rank gates pass in Release and bounds/FPE-checked Debug configurations,
and both workflows pass the complete 208-test serial regression.

## Qualification boundary

Each distinct child owner still receives one complete root start/end state,
temperature, and x/y-flux input bundle per transport Euler stage. This change
removes repeated full-root correction round trips but does not yet replace that
compatibility input with compact exterior and interface-flux data. Hydro keeps
its existing correction route and is unchanged by this milestone.
