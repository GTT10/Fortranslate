# PeleF 0.42.0 validation record

## Scope

This milestone adds parent-owned flux registers and transactional
deepest-to-root synchronization to the arbitrary-depth multipatch tree.

## Automated evidence

`unit_amr_patch_tree_1d` reuses the four-level `1/2/3/2`-patch hierarchy. It
checks that the deepest register relation contains one child register for the
first parent, an allocated empty array for the middle parent, and one child
register for the third parent.

Independent coarse and fine boundary fluxes are accumulated for the two
deepest patches. Matching finite-volume updates are applied to their parent and
fine fields, producing a nonzero composite mismatch. Tree synchronization
refluxes both parent-owned child sets, averages them down, and continues through
the two ancestor relations. The final composite integral returns to zero
within `5e-12`, every covered interval is synchronized, and every nested
register is reset.

All gates run with array-bounds checking in the GitHub Actions Debug build and
again in Release. Main integration also retains the MPI-enabled Debug and
Release suite.

## Qualification boundary

This milestone provides the tree-wide synchronization operation, not the
reactive routine that fills its registers. Recursive hydro/transport
subcycling, chemistry composition, dynamic tag planning, overlap-preserving
tree rebuilds, adjacent boxes, same-level exchange, load balancing, and MPI
patch ownership remain future work.
