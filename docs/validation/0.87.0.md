# PeleF 0.87.0 validation record

## Scope

This milestone composes PCM prolongation, coarse-time fine-patch boundary
states, ratio subcycling, EB hydrodynamic level advances, re-reflux, and
reactive average-down for one static serial two-level rectangle.

## Automated evidence

The new unit gate constructs matching coarse and ratio-two fine versions of a
diagonal embedded boundary. A uniform H2/O2/N2 state is injected into the fine
patch, recovers the same temperature, and restricts back to the original
coarse state. A proportional accepted coarse state is sampled at one-quarter
time; every open fine-patch boundary receives the analytical interpolated
state, while an out-of-range interpolation time is rejected.

The complete gate advances one coarse characteristic-PLM/HLLC step and two fine
half steps. The synchronized result preserves the uniform state, temperature,
covered cells, and every coarse/fine composite conserved integral to roundoff.
A second case raises the entire fine state by one percent, drives a real
coarse/fine Riemann mismatch, and verifies that subcycling plus re-reflux still
preserves composite mass, total energy, and every species inventory while the
interface evolves. Momentum is excluded because the embedded slip wall exerts
a pressure force. An unknown Riemann solver exercises whole-hierarchy rollback.

## Qualification boundary

The qualified fine rectangle is static, aligned, and strictly internal. Its
coarse exterior data is piecewise constant in space and interpolated in time.
This milestone does not include AMR chemistry or molecular transport,
automatic timestep selection, physical-boundary patch contact, dynamic
regridding, multiple patches, deeper levels, or MPI ownership.
