# PeleF 0.49.0 validation record

## Scope

This milestone adds the first MPI distribution bridge for the one-dimensional
AMR patch tree: collective hierarchy consensus, deterministic exclusive patch
owners, owner-authoritative field synchronization, and cross-rank adjacent
sibling halos.

## Automated evidence

`pelef_mpi_amr_patch_1d` builds one root patch and eight fine patches with four
adjacent sibling faces. The owner schedule accounts for all nine patches and
all 152 represented cells exactly once. With 2, 4, and 8 ranks, at least one
adjacent face crosses owners.

Every non-owner patch interior is poisoned before communication. Each owner
encodes its level, patch, variable, and cell in the authoritative values. The
halo exchange reconstructs the nearest four layers on both sides of every
adjacent face exactly, and full-patch synchronization then reconstructs every
encoded interior on every rank. A separately valid hierarchy changed on only
the last rank is rejected collectively without entering a mismatched patch
communication schedule.

The MPI workflow executes this gate with 1, 2, 4, and 8 ranks in both GNU
Fortran Release and bounds-checked Debug builds. The pre-existing serial and
uniform-grid MPI regression suites remain enabled in the same workflows.

Branch runs 32694402208 (complete serial Debug/Release suite) and 32694402175
(complete MPI Debug/Release suite) passed for implementation commit `a11b790`.

## Qualification boundary

The bridge keeps all patch fields replicated and qualifies ownership metadata,
authority, and adjacent halo communication only. It does not yet execute the
reactive patch-tree recursion on owners alone, exchange shared interface fluxes
between owners, store only rank-local patches, or migrate patch state after a
regrid.
