# PeleF 0.238.0 validation record

## Scope

This milestone qualifies configure-time selected-mechanism execution and rank
parity for the established sparse MPI reactive EB patch-tree 2D lifecycle.
Fixed and selected executables share one mechanism-independent application
driver. Selected MPI EB checkpoint/restart remains intentionally excluded.

## Execution contract

The selected call carries the generated bundle SHA-256, explicit/implicit
integrator, mechanism tables, and finite nonnegative normalized bundle-order
composition. Every rank must agree on the complete context before root-state
initialization. The selected composition reaches root and boundary
construction, and the integrator reaches both chemistry half-steps on every
active level. Invalid or rank-dependent policies fail without changing the
sparse candidate.

The pinned full-H2/O2 case contains ten species and 29 reactions and uses the
implicit integrator. It advances a 12-by-12 planar-EB root to `1.0e-12 s`,
activates levels 0 through 3 through solution-driven dynamic regridding, and
performs one committed coarse step. Chemistry level advances are `2 2 2 2`
and hydro level advances are `1 2 4 8`.

Fixed one-rank and selected one-, two-, and four-rank composite CSV files are
byte-identical:

## Focused failure and compatibility gates

Direct sparse MPI EB policy tests pass on one, two, and four ranks. A separate
two-rank process proves selected composition context mismatch is rejected
before output. Executable-level gates reject selected checkpoint cadence,
checkpoint path, restart path, fixed/selected model mismatch in both
directions, and lexical input/output aliasing. Rejected processes create
neither composite output nor checkpoint.

The final focused set added by this milestone passes 18/18 tests: three direct
policy/no-mutation tests, twelve executable execution/parity/failure tests,
two fixed schema-8 checkpoint tests, and one rank-context mismatch test. The
executable set includes a two-species fixture-bundle run and an independent
CSV validity gate, so both generated `explicit` and pinned full-H2/O2
`implicit` policies execute through the shared lifecycle.

## Clean Release qualification

A fresh tests-disabled GNU 13.3/OpenMPI Release tree built all 627 steps and
installed 40 executables. All 40 installed ELF files are byte-identical to
their build-tree counterparts, have non-executable stacks, contain no RPATH or
RUNPATH, resolve every runtime dependency, use OpenMPI ABI 40, and contain no
oneAPI or `libmpi.so.12` contamination.

The installed fixed one-rank and selected one-, two-, and four-rank runs
reproduce the exact composite CSV SHA-256 above. Installed failure gates reject
checkpoint, restart, model mismatch in both directions, and input/output alias
without publishing forbidden output. The installed fixed schema-8 checkpoint
and stopped CSV reproduce their frozen Release hashes. Commands and artifact
hashes are frozen in
`docs/validation/evidence/0.238.0-clean-release-install-audit.txt` and
`docs/validation/evidence/0.238.0-installed-selected-sparse-mpi-eb-patch-tree-2d.txt`.

## Qualification boundary

This evidence establishes deterministic configure-time selected sparse MPI
reactive EB patch-tree 2D execution across one, two, and four ranks. It does
not establish selected MPI EB persistence; fixed-depth three-level or
multipatch MPI execution; runtime mechanism loading; crash-atomic or scalable
I/O; payload authentication; CFD CVODE; thread safety; performance;
detailed-fuel physical validity; or external PeleC field parity.
