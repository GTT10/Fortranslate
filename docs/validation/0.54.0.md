# PeleF 0.54.0 validation record

## Scope

This milestone establishes rank-local reactive MPI AMR patch payloads, exact
replicated/sparse transitions, and exact same-hierarchy owner-map migration.

## Automated evidence

The four-level MPI AMR gate scatters an owner-authoritative replicated tree
into sparse rank-local containers. Every rank's patch and cell counts equal
its distribution metadata. Across the communicator, every patch and cell is
present exactly once, and the sum of allocated state, temperature, and ghost
values equals one replicated tree rather than one tree per rank.

Gather is tested with every replicated field and bookkeeping value poisoned.
Owner data restores all six patch arrays, time, steps, hydro and transport
counters, and regrid statistics exactly. On multi-rank runs, the gate rotates
every patch owner, migrates each payload, rechecks unique storage, and gathers
the exact original solution from the new owners.

Branch run 32704441775 passed the complete GNU Fortran Debug/Release MPI suite
with 1, 2, 4, and 8 ranks for implementation commit `57e9584`.
Branch run 32704441790 passed the complete serial Debug/Release suite for the
same implementation commit.

## Qualification boundary

Hierarchy and owner descriptors remain replicated. Same-hierarchy migration
temporarily broadcasts one patch at a time, though only the new owner retains
it. The qualified physics operators still consume replicated trees. Direct
sparse physics, point-to-point communication, and topology-changing regrid
migration remain future work.
