# PeleF 0.243.0 validation record

## Scope

This milestone closes context-bound checkpoint/stop/restart for the existing
configure-time selected, static, strictly interior, periodic, two-level 3D
reactive AMR hierarchy in serial and rank-local sparse MPI execution. It also
hardens MPI selected-context validation against rank-local malformed
third-body-efficiency shapes. Fixed checkpoint calls retain schema 2 and their
established bytes.

## Selected schema and transaction contract

Selected calls require schema 3. The file binds bundle SHA-256, generated
integrator, normalized bundle-order composition, the complete ordered reaction
records, chemistry tolerances, ordered NASA7 records, numerical and topology
fingerprints, original composite baseline, clock and reflux history, and both
levels. Fixed and selected readers reject the other schema.

The reader validates private candidates through recovered temperatures,
coarse/fine synchronization, terminal marker, strict end-of-stream, and a
successful close before publishing any target. Incomplete selected context is
rejected before file creation. MPI validates the complete selected context on
all ranks before root I/O; the checkpoint stores no rank count or owner map.
