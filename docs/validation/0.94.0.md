# PeleF 0.94.0 validation record

## Scope

This milestone connects the qualified two-level reactive EB patch-set kernel
to the public serial application. Input can select a tag-driven multipatch
lifecycle with set-wide CFL selection, initial and periodic topology changes,
transactional chemistry/hydrodynamics, and deterministic per-child output.

## Automated evidence

The public-driver gate initializes a 14 by 14 plane-EB root with two separated
temperature hotspots. Disconnected tags must create two valid 10 by 10
ratio-two children. The case advances one accepted chemistry/hydrodynamics
interval, exercises a periodic regrid, checks the minimum root/all-child CFL
limit, and requires finite active thermodynamics, species closure, a cut cell,
and composite mass and total-energy conservation.

The installed application writes one synchronized root CSV and two child CSVs
named with `_patch0001` and `_patch0002`. Its checker verifies exact row counts,
finite positive state and thermodynamics, species closure, common accepted
time, deterministic child ordering and x separation, hotspot temperatures,
physical centers, and regular, cut, and covered EB classes. Configuration gates
also preserve the default single-patch path and reject unsupported multipatch
checkpoint/restart controls before initialization.

Implementation head `d2edf5f` is qualified by
[branch CI run 32846251136](https://github.com/GTT10/Fortranslate/actions/runs/32846251136)
in GNU Fortran Debug and Release configurations. The focused three-test public
application gate passed before the complete regression in each configuration.
All 171 tests passed in Release and in bounds-, backtrace-, and floating-point-
exception-checked Debug builds.

## Qualification boundary

The public lifecycle covers one serial EB root and a deterministic set of
separated, ratio-aligned fine rectangles at one finer level. The existing
single-patch path retains formatted checkpoint/restart. Multipatch
checkpoint/restart, EB molecular transport, deeper levels, physical-side fine
patches, and distributed ownership remain outside this milestone.
