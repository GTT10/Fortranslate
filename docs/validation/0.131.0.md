# PeleF 0.131.0 validation record

## Scope

This milestone connects root-only sparse MPI reactive EB AMR materialization
to the existing formatted multipatch checkpoint and root/child CSV writers.
Only the selected writer allocates the complete hierarchy or touches files.

## Automated evidence

The checkpoint gate writes an exclusively owned two-child hierarchy through
the sparse adapter, then reads it with the established serial multipatch
reader. Conserved root and child fields must match exactly; recovered
temperatures, topology, time, step and regrid counts, minimum timestep, and
base density must also match the source hierarchy and metadata.

The CSV gate requires one nonempty root file and one nonempty `_patchNNNN` file
per child. Both successful adapters check sender-local and communicator-summed
gather counts against the independent remote-entity formula. Checkpoint and CSV
paths below a nonexistent directory must reject on every rank and publish zero
traffic.

Qualification head `aa96313` is covered by ordinary CI run `32939522500` and
MPI CI run `32939522548`. GNU Fortran Release and bounds/FPE-checked Debug passed
the complete 208-test serial regression. The MPI workflow also passed all
established gates at one, two, four, and eight ranks in both configurations.

## Qualification boundary

The formatted checkpoint remains serial-compatible and the CSV files remain
ordinary per-level files. Direct root-only checkpoint read and redistribution
into a new sparse owner map, atomic multi-file publication, parallel file
formats, arbitrary-depth dynamic EB topology, and decomposition of the
level-wide root physics kernel remain separate work.
