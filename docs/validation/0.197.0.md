# PeleF 0.197.0 validation record

## Scope

Arbitrary-depth serial and sparse-MPI checkpoints preserve the original
composite-integral baseline across independent and changed-rank restart.

## Automated evidence

The direct serial round trip writes a synthetic finite vector distinct from
the checkpoint state's current integral and requires exact recovery. Vectors
with the wrong number of components or a nonfinite value are rejected before
file replacement, and a failed read leaves the optional result unallocated.

The sparse selected-root gate repeats the exact round trip at one, two, four,
and eight ranks. Multi-rank runs also supply a different first component on
one rank and require collective rejection before any field gather or file
write. Successful restart broadcasts the baseline before recomputing owners.

The public reacting x-upper chain requires schema 6. Its one-rank
uninterrupted reference is compared with continuations of a two-rank
checkpoint on four and eight ranks. Identity-keyed fields, cumulative minimum
transport theta, and final conservation error must all agree. GNU Fortran
Debug and Release qualification run identifiers are recorded in the pull
request before merge. Python syntax and `git diff --check` are also required.

## Qualification boundary

This change preserves the existing application diagnostic baseline. It does
not add compatibility with older schema versions, external source-term
ledgers, or checkpoint persistence for internal per-level operator counters.
