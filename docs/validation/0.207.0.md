# PeleF 0.207.0 validation record

## Scope

This milestone introduces a serial, static, two-level general-EOS reactive 3D
hydrodynamic AMR path. One strictly interior rectangular patch advances with
integer-ratio subcycling, linearly time-interpolated coarse boundary states,
SSPRK2 time-averaged face fluxes, six-face reflux, and conservative
average-down.

## Automated evidence

- `unit_amr_hierarchy_3d` checks patch geometry, PCM prolongation, restriction,
  composite integration, average-down, and invalid-patch rejection;
- `unit_amr_reactive_3d_config` rejects unsupported boundary-touching,
  nonperiodic, chemistry, transport, unit-ratio, and duplicate-output inputs;
- `unit_reactive_euler_3d_dimensional_reduction` proves the flux-returning
  SSPRK2 API is exactly state/temperature equivalent to the established path
  and retains transactional rejection;
- `regression_amr_reactive_3d` checks uniform invariance, nonuniform composite
  conservation, active reflux, physicality, closure, synchronization, and
  whole-hierarchy rollback;
- `regression_amr_reactive_3d_run` and `_check` exercise the public full-H2O2
  namelist/application/coarse-and-fine-CSV path.

## Numerical signatures

The focused nonuniform elementary-H2/O2 regression reported composite
all-component conservation error `9.7144514654701197e-16`, exact covered-cell
average-down, maximum reflux correction `4.7989796138498150e1` in conserved
component units, and maximum species-closure error
`2.2204460492503131e-16`.

The public 8^3 coarse plus 8^3 ratio-two fine full-H2O2 case reached
`t=1.0e-6 s` in eight coarse and sixteen fine steps. It reproduced each
covered coarse component from its eight children exactly. The independent
checker reported primitive/conserved relationship error `2.498e-16`, closure
error `3.331e-16`, and a resolved fine density span `3.822e-2 kg/m^3`.

## Qualification boundary

This record qualifies serial, periodic, inviscid, PCM, static, single-patch,
strictly interior two-level 3D AMR hydrodynamics. It does not qualify chemistry
or molecular transport across levels, high-order reconstruction/prolongation,
dynamic regridding, boundary-touching refinement, restart, MPI decomposition,
EB, LES, particles/spray, scalable output, accelerators, external physical
validation, or whole-application PeleC parity.
