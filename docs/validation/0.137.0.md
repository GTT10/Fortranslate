# PeleF 0.137.0 validation record

## Scope

This milestone removes the selected-rank input gather from direct sparse MPI
2D EB AMR root hydro. Each root tile owner constructs a bounded EB band from
its local rows and targeted remote halo fragments, advances that band, and
routes only owned inputs, results, and face rows into the established
child/reflux transaction.

## Automated evidence

For every target tile, the test derives the exact source tiles intersecting
its six-row halo and counts one point-to-point payload per remote source. It
also counts the result route to the root owner, distinct child bundles,
per-child correction round trips, and final sparse row scatter. Local and
communicator totals must equal those formulas exactly.

Each tile owner must report one committed root advance and the exact number of
cells in its bounded halo band. Above one rank, the total must remain below the
work needed to advance the complete root independently on every rank.
Materialized root state and temperature, every child, reflux, and final
average-down must match the serial multipatch reference at one, two, four, and
eight ranks. The same owner accounting is exercised through sparse full
physics and the public time loop. A late child failure must preserve every
sparse allocation bitwise and publish zero advances, work, and transfers.

Qualification head `a27148a` is covered by ordinary CI run `32958110041` and
MPI CI run `32958110057`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows preserve the complete 208-test
serial regression.

## Qualification boundary

After tile-local root computation, the root owner still assembles a complete
temporary start/result/flux bundle for existing fine-child exterior
interpolation, deterministic reflux, and final sparse scatter. Sparse root
transport and timestep selection still use selected-root gathers. Distributed
coarse/fine interface data and elimination of the post-compute compatibility
bundle remain separate work.
