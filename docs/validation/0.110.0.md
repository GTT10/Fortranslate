# PeleF 0.110.0 validation record

## Scope

This milestone establishes the first MPI ownership boundary for the
two-dimensional reactive EB AMR hierarchy. It assigns unique owners to
nonoverlapping root tiles and fine sibling patches, supports three
subcycle-weighted work models, and synchronizes owner-authoritative reactive
payloads transactionally while retaining replicated descriptors and fields.

## Automated evidence

The MPI executable independently constructs a 14 by 14 plane-EB root and two
separated ratio-two 10 by 10 children on every rank. Collective metadata
checks require identical root extent, child bounds, refinement ratios, fine
dimensions, and EB geometry summaries. The root is partitioned into
`min(14, nranks)` contiguous y-tiles, every entity has exactly one owner, and
every rank in the qualified set owns at least one root tile.

The parabolic work model requires exact 64-bit accounting of 196 root cells
plus `100 * 2^2` work for each child, for a total of 996. Owners publish
distinct scaled reactive states while nonowners retain stale finite replicas;
the synchronized root tiles and child states and temperatures must match the
owner payload bitwise on every rank. An out-of-range owner must leave all
outputs unchanged, rank-dependent work exponents must reject collectively,
and exponent three must reject on every rank.

Implementation head `b9ae344` is qualified by serial CI run 32894263717 and
MPI CI run 32894263707. The MPI workflow used Ubuntu 24.04 with OpenMPI and
ran the new executable at one, two, four, and eight ranks in GNU Fortran
Release and bounds-, backtrace-, and floating-point-exception-checked Debug
configurations. All established MPI gates and the complete 208-test serial
regression also passed in both MPI configurations. The ordinary Release and
Debug CI configurations independently passed all 208 tests.

## Qualification boundary

This is an owner-authoritative replicated bridge. The serial EB geometry,
patch-set topology, and complete field payloads still exist on every rank.
Direct owner-only EB hydrodynamics, chemistry, and molecular transport;
rank-local sparse storage; point-to-point halo and coarse/fine traffic;
distributed flux registers; topology migration; parallel checkpoint I/O; and
a public distributed EB AMR time loop remain outside this milestone.
