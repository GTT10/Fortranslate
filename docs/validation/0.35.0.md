# PeleF 0.35.0 validation record

## Scope

This milestone adds PeleC-style WENO5-JS and WENO5-Z edge reconstruction to
the one-dimensional multilevel reactive AMR characteristic-PPM path. The
hybrid switch changes only the primitive five-point edge reconstruction and
reuses the qualified PPM characteristic projection, recursive SSPRK3 update,
coarse-time ghost interpolation, flux registers, and reflux synchronization.

## Automated evidence

`unit_weno_reconstruction` checks constant and linear reproduction for both
schemes and compares a nonsymmetric five-value stencil against fixed PeleC
`Source/WENO.H` formula values within `3e-14`.

`regression_amr_multilevel_reactive_1d` advances both WENO5-JS and WENO5-Z for
two steps on a fixed three-level hierarchy. Each path must conserve the
composite state within `3e-10`, synchronize every covered parent/child region
within `5e-13`, retain positive thermodynamics, and close species within
`3e-10`.

`regression_amr_multilevel_weno5z_hotspot_run` exercises the public
namelist-driven application with solution-driven regridding and three active
levels. Its paired checker requires ordered exact domain coverage, three
ratio-two spacings, finite positive density, pressure, and temperature, and
species closure within `3e-10`.

All gates run in the GitHub Actions Debug and Release builds. Main integration
also retains the MPI-enabled Debug and Release suite for the distributed
uniform-grid paths.

## Qualification boundary

The WENO formulas are used as an optional edge-reconstruction replacement
inside characteristic PPM; this is not a separate complete WENO finite-volume
solver. The qualified slice is one-dimensional and uses one Cartesian patch
per AMR level. WENO3-Z, WENO7-Z, two-dimensional WENO, physical-boundary
refinement, multiple patches, MPI patch ownership, load balancing, embedded
boundaries, and accelerators remain future work.
