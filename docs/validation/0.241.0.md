# PeleF 0.241.0 validation record

## Scope

This milestone qualifies fixed elementary and full-H2/O2 cell-local chemistry
for the existing static, strictly interior, periodic, two-level 3D AMR
hierarchy in serial and rank-local sparse MPI execution. It does not add
transport, selected mechanisms, dynamic topology, physical coarse boundaries,
or chemistry restart.

## Source and split contract

A source phase advances private coarse and fine candidates, averages fine
conserved state onto covered coarse cells, and recovers the synchronized
coarse temperature before publishing either level. The complete step is a
transactional `R(dt/2)-H(dt)-R(dt/2)` composition. Chemistry-disabled calls
use the established hydro path directly.

Sparse MPI ranks advance only their local coarse slab and parent-owned fine
planes. A rank may own no fine cells but remains in reaction, integrator,
control, and success consensus. The complete ordered reaction records are
compared before source execution. Candidate hierarchy and reflux are unchanged
after any collective rejection.

Chemistry-enabled checkpoint or restart is rejected because schema 2 records
neither the reaction set nor the source integrator and tolerances.

- serial hierarchy activity, exact Euler invariance, H/O/N conservation,

  eight ranks;
- rank-dependent reaction and chemistry-enable rejection plus collective
  coarse-source rejection on a zero-fine rank;

## Clean Release installation

A sanitized GNU/OpenMPI Release configuration with tests disabled builds all
`629/629` Ninja steps and installs 40 executables. All 40 installed ELF files
are byte-identical to their build-tree counterparts, have non-executable
stacks, no RPATH/RUNPATH, no unresolved dependency, and no Intel MPI or

Using only those installed executables, the serial inert/reacting pair passes
the strict chemistry checker, and the reacting coarse/fine files are byte
identical at one, two, four, and eight MPI ranks. The installed two-rank
chemistry-disabled characteristic-PLM checkpoint also resumes independently
at four and eight ranks to the unchanged `0.240.0` final bytes. The complete
audit is recorded in
[`evidence/0.241.0-clean-release-install-audit.txt`](evidence/0.241.0-clean-release-install-audit.txt).

## Qualification boundary

This is conservation, transactional-failure, deterministic rank-parity, and
short-time structural evidence for the committed fixed H2/O2 mechanisms. It
is not ignition evidence, external PeleC field parity, detailed-fuel physical
validation, chemistry performance or thread-safety qualification, scalable
I/O, or a claim for dynamic AMR, transport, selected mechanisms, or 3D EB AMR.
