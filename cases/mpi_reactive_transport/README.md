A smooth periodic full H2/O2 mixture is decomposed without state replication across MPI ranks and advanced with the existing general-EOS molecular transport operator. The distributed SSPRK2 path exchanges conserved-state and temperature halos, evaluates viscosity, thermal conduction, mixture-averaged species diffusion, barodiffusion, and enthalpy transport on rank-local faces, and enforces 1/2/4-rank field parity together with periodic conservation and species-closure gates.
