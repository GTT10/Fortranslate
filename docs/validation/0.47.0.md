# PeleF 0.47.0 validation record

## Scope

This milestone adds automatic per-parent tagging and disconnected-feature
clustering to arbitrary-depth reactive patch-tree rebuilds.

## Automated evidence

`regression_amr_patch_tree_reactive_1d` starts from a root-only reactive state
and places two separated momentum features in the interior. The planner uses
normalized-gradient tagging, parent-local clustering, four-cell buffers, and a
minimum eight-cell width. It produces three relations with exact `1/2/2/2`
patch counts. The second and third relations each retain one child owned by
each preceding branch.

The public tag-driven regrid creates the four-level tree transactionally. The
old root has no fine overlap to transfer, every composite conserved component
remains within `3e-10`, and every parent-child relation remains synchronized
within `5e-13`. Replanning the unchanged state is a no-op, while an invalid tag
component leaves state and counters unchanged.

Branch CI run 32666081629 passed the complete GitHub Actions Debug and Release
suite with GNU Fortran, including array-bounds checking in Debug.

## Qualification boundary

The automatic planner uses one configured refinement ratio at all generated
relations and creates strictly interior patches. Adjacent-patch same-level
exchange, physical-boundary children, load balancing, and MPI patch ownership
remain future work.
