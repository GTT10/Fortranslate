# PeleF 0.195.0 validation record

## Scope

The public arbitrary-depth outflow-boundary cases execute elementary chemistry,
full dilute mixture transport, and recursively subcycled hydrodynamics as one
transactional `R-T-H-T-R` lifecycle in serial and sparse MPI.

## Automated evidence

The fresh four-level x-upper input enables elementary chemistry, viscosity,
Fourier conduction, mixture-averaged species diffusion, and barodiffusion. Its
existing composite checker requires exact physical-side contact, refinement
spacing, EB classes, positivity, finiteness, and species closure. Sparse runs
at one, two, four, and eight ranks must retain complete serial field parity.

The checkpoint-stop and restart inputs use identical chemistry, tolerances,
transport, and mesh controls. Schema 4 preserves their fingerprint, and
independent serial plus cross-rank sparse continuations must match uninterrupted
references while retaining exact boundary contact at all four levels. The
sparse chain writes on two ranks and restarts on four and eight ranks under a
changed ownership weight.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. Namelist consistency, version consistency, and
`git diff --check` are also required.

## Qualification boundary

This gate uses the elementary H2/O2 mechanism and existing adaptive implicit
reactor. It does not establish arbitrary Cantera/CHEMKIN mechanism parsing,
CVODE parity, or complete PelePhysics chemistry parity.
