# PeleF 0.151.0 validation record

## Scope

Sparse hydro retains each root tile's computed x-flux rows and uniquely owned
y-faces on the tile owner. The tile-to-root result now contains only stage-
start and stage-end state and temperature, so the root physics owner allocates
no complete hydro x/y flux field.

For each child, intersecting tile owners route their coarse interface-flux
fragments directly to the child owner. The receiver assembles globally indexed
x/y rectangles, verifies complete finite coverage, and accumulates the coarse
register. The root owner separately sends the established four-edge start/end
context and current patch-plus-two corrected state and temperature. Child-local
subcycling, reflux, ordered corrected-support return, and final root scatter
retain their established behavior.

## Automated evidence

The MPI application derives exact point-to-point traffic from finite-band halo
messages, remote tile state results, remote final scatters, remote child state
context and corrected-support messages, and one direct flux message for every
remote tile/child interface intersection. The combined compact state-context
and interface-flux value count must remain positive and strictly smaller than
the former complete root bundle.

Qualification head `08c370a` is covered by ordinary CI run `33001711377` and
MPI CI run `33001711400`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank full-physics gates pass in Release and bounds/
FPE-checked Debug configurations, and both workflows pass the complete 208-test
serial regression.

## Qualification boundary

The root physics owner still assembles complete hydro stage-start and stage-end
state and temperature, extracts child contexts, merges ordered returned
corrections, and scatters final corrected rows. Direct hydro state/support
routing between root tile owners and child owners remains the next ownership
boundary. Transport is unchanged. This milestone does not claim a measured
speedup.
