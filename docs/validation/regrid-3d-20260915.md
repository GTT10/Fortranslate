# Serial temperature-driven 3D AMR regridding

Parent: `414e5bf`. The serial 3D AMR application now moves/resizes its interior
fine patch at synchronized coarse steps using temperature tags. Regridding
restricts the old fine solution, preserves overlapping fine cells exactly,
prolongs newly refined cells conservatively, and commits both levels only
after EOS and composite conservation checks. Limited-linear transfer uses
species-consistent density slopes and a common positivity factor per parent.
See the [AMR guide](../../cases/amr_reactive_3d/README.md) for inputs and limits.

AMR validation now checks resolved per-face boundaries, closing a bypass in
which the global periodic default could hide an unsupported physical face.
Dynamic MPI requests and legacy checkpoint read/write requests are rejected
explicitly until distributed ownership and dynamic persistence are implemented.

## Focused evidence

GNU Fortran 13.3.0 Debug, `build/port-spray-debug`:

```sh
cmake --build build/port-spray-debug --parallel 8 --target \
  test_amr_regrid_3d pelef_amr_reactive_3d test_amr_reactive_3d_checkpoint
ctest --test-dir build/port-spray-debug --output-on-failure \
  -R '^(unit_amr_regrid_3d|amr_dynamic_hotspot_3d|unit_amr_reactive_3d_checkpoint)$'
```

Three distinct tests passed: conservative remap/linear prolongation/exact
overlap/shrink/tagging/rejection (0.08 s), moving-hotspot application (35.16 s),
and existing static checkpoint contracts (0.11 s). The application regridded
at step 0 to `(2:5,3:6,3:6)` and at step 4 to `(2:6,3:6,3:6)`; composite
conservation error was `2.776e-17`, elemental error `2.543e-15`.

The selected FFCM1_Red Release application also completed a shorter 0.2-us
smoke with one regrid and composite residual `1.665e-16`. Input/output/log
are in `build/port-spray-cvode/regrid-run/`. Both application cases disable
chemistry and transport; this is regrid integration evidence, not additional
chemistry/transport or physical validation.

An attempted rebuild of historical `build/mpi-debug` linked conflicting
`libmpi.so.40` and `libmpi.so.12`, so it was not used for runtime evidence.
A fresh `build/port-regrid-mpi` was configured in an empty environment with
`PATH=/usr/bin:/bin`, GNU Fortran and `/usr/bin/mpifort`, MPI enabled, tests
disabled. The executable links OpenMPI `.so.40` only. A two-rank dynamic
request was rejected collectively with the intended diagnostic. Its logs are
retained there as `configure.log`, `build.log`, and `dynamic-rejection.log`.

Serial build/test logs use prefix `regrid-`; selected build log is
`build/port-spray-cvode/regrid-build.log`. Provenance, project contract and
whitespace checks passed. No Python source changed and no broad matrix ran.

Dynamic restart/MPI, removal of the last fine level, multipatch/multilevel
AMR and physical/EB boundaries remain open. This does not complete the project.
