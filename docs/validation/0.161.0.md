## Scope

The arbitrary-depth sparse MPI tree now selects its combined hyperbolic and
explicit-transport timestep without materialization. Every rank evaluates only
owned active nodes, converts each local limit through the cumulative refinement
product to a root interval, and participates in a communicator minimum.

Collective preflight validates the replicated distribution, owner-only field
layout, species count, CFL values, and enabled transport terms. Ranks without
active nodes contribute a neutral value. Public timestep and evaluation counts
remain zero if preflight or the global result rejects.
