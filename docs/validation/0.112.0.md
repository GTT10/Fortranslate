# PeleF 0.112.0 validation record

## Scope

This milestone executes two-level sibling-patch reactive EB hydrodynamics on
exclusive MPI physics owners. One owner advances the complete weighted-
StateRedist root level, each child owner performs its fine subcycles and
flux-register reflux, and the root owner commits the final average-down. The
caller sees no mutation until the complete collective transaction succeeds.

## Automated evidence

The MPI executable constructs a 14 by 14 plane-EB root and two separated
ratio-two 10 by 10 children, then gives the children different finite reactive
states. The serial multipatch EB hydro path supplies the reference. The MPI
path must reproduce its root and child state and temperature fields within
`8e-12` of the field scales and produce a measurable update.

The root physics owner must record one level advance. Each child owner must
record its two fine substeps, giving an exact communicator total of five. The
child owner also accumulates the coarse and fine time-integrated fluxes and
refluxes the current authoritative root before publishing both corrected
fields. The root owner completes one set-wide fine-to-root average-down.

For the rollback gate, the final child owner receives a finite but
EOS-invalid density field. Root and earlier-child candidate work occurs first,
but the failed fine advance must reject communicator-wide. Every rank must
retain its original root and child fields bitwise and report zero committed
advances.

Implementation head `e5e2854` is qualified by ordinary CI run 32898453431 and
MPI CI run 32898453445. The MPI workflow used Ubuntu 24.04 with OpenMPI and ran
the executable at one, two, four, and eight ranks in GNU Fortran Release and
bounds-, backtrace-, and floating-point-exception-checked Debug
configurations. All established MPI gates and the complete 208-test serial
regression passed in both MPI configurations. The ordinary Release and Debug
CI configurations independently passed all 208 tests.

## Qualification boundary

Reactive chemistry and hydrodynamics now execute on owners, while EB geometry,
patch topology, and complete field payloads remain replicated. The root is one
physics entity because weighted StateRedist still owns level-wide overlapping
neighborhoods. Decomposed root StateRedist, owner-only molecular transport,
sparse rank-local storage, point-to-point halo and coarse/fine traffic,
topology migration, parallel checkpoint I/O, and a public distributed EB AMR
time loop remain outside this milestone.
