# PeleF 0.99.0 validation record

## Scope

This milestone adds transactional three-level reactive EB hydrodynamics with
recursive subcycling, one flux register per nested interface, and
deepest-to-root synchronization. The finest coarse/fine interface is required
to lie entirely in regular fluid.

## Automated evidence

The gate builds an 8 by 8 plane-EB root, a ratio-two 12 by 12 middle level,
and a nested ratio-two 10 by 10 finest level. The finest rectangle remains two
middle cells from the middle boundary and has unit open-area fraction on every
interface face. One root interval executes two middle substeps and four
finest substeps through independent inner and outer EB flux registers.

Distinct conservative scalings on the root, middle, and finest levels exercise
both interfaces. The result preserves composite mass, total energy, and all
seven species, retains finite positive EOS temperatures on every level, and is
already synchronized when the deepest-first transaction is repeated. An
unknown solver leaves all states and temperatures unchanged. A deliberately
fractional finest boundary face is rejected before advancement and likewise
leaves the complete hierarchy unchanged.

Implementation head `7ae210e` is qualified by
[branch CI run 32861953936](https://github.com/GTT10/Fortranslate/actions/runs/32861953936)
in GNU Fortran Release and bounds-, backtrace-, and
floating-point-exception-checked Debug configurations. The focused
multipatch/multilevel gate and eleven-test public application gate passed
before the complete regression in each configuration. All 180 tests passed in
Release and Debug.

## Qualification boundary

Root and middle may contain regular, cut, and covered cells, but every finest
coarse/fine interface face must be fully open. The implementation rejects an
EB-cut nested interface because the current two-level register lacks the
required multilevel geometric correction. The hierarchy is static, serial,
aligned, and exactly three levels deep. Chemistry splitting, dynamic hierarchy
ownership, checkpoint/restart, public output, molecular transport, arbitrary
depth, and MPI distribution remain outside this milestone.
