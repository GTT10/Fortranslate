# PeleF 0.28.0 validation record

## Scope

This milestone adds limited primitive-variable PLM and SSPRK2 time advancement
to the dynamic two-level reactive AMR application.

## Automated evidence

`regression_amr_reactive_plm` transports a smooth constant-pressure thermal
contact on a dynamically refined hierarchy. It executes matching PCM and PLM
runs, constructs the exactly translated coarse/fine reference samples, and
requires PLM's composite density error to be at least 15 percent lower than
PCM's. Both paths must retain mass, momentum, and energy within `2e-10`.

The reacting-hotspot application now runs with `amr_reconstruction = "plm"`, so
its positivity, species closure, exact composite coverage, coarse/fine
synchronization, chemistry, regrid, and reflux gates exercise the higher-order
path. The complete serial and MPI-enabled regression suites remain active.

## Qualification boundary

This PLM path is component-limited in primitive variables and uses SSPRK2. It is
not characteristic tracing, PPM, WENO, a multidimensional AMR method, or an AMR
molecular-transport qualification.
