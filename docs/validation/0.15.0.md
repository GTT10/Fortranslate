# PeleF 0.15.0 validation record

Base: PeleF 0.14.0 reactive general-EOS 2D CTU branch.

## New subsystem

- x/y time-traced characteristic PPM normal prediction;
- PeleC five-point reconstruction and `u-c`, `u`, `u+c` profile integration;
- optional one-dimensional PeleC shock flattening in both directions;
- optional bounded density/species contact steepening in both directions;
- normal-predictor coupling to the existing full-state CTU correction;
- exact diagonal density and H2/N2 composition-wave regressions;
- x-normal and y-normal dimensional reductions;
- cell-level flattening/steepening signatures;
- periodic two-dimensional material-contact sharpening;
- characteristic-PPM reacting-hotspot application regression;
- oblique pressure-ratio-three shock positivity and flattening regression.

## Scope qualification

This record validates coordinate-direction normal characteristic prediction
followed by the already qualified conservative CTU transverse correction. It
is not evidence of complete PeleC multidimensional PPM transverse/corner
tracing. The solver remains uniform-grid, periodic, inviscid, serial, and uses
the seven-species/four-reaction chemistry subset.

The final gates are the complete local Debug/Release suites and GitHub Actions
Debug/Release suites with Cantera 3.2.
