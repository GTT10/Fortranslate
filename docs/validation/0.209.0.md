# PeleF 0.209.0 validation record

## Scope

This milestone distributes the qualified static, single-patch, two-level 3D
AMR hydro arithmetic over deterministic coarse and fine x slabs. Hierarchy
storage remains replicated. The public application adds selected-root
initialization, checkpoint/restart, and CSV output without storing an MPI owner
map.

## Automated evidence

- `mpi_amr_reactive_3d_np1`, `np2`, `np4`, and `np8` compare the distributed
  CFL, one complete AMR step, both states and temperatures, and reflux against
  the serial kernel bit for bit;
- the same MPI unit gate rejects inconsistent roots, array extents, NASA7
  coefficients, and solvers transactionally;
- `regression_mpi_amr_reactive_3d_np1/np2/np4/np8` run the public full-H2O2
  hierarchy to its requested final time;
- `regression_mpi_amr_reactive_3d_check` independently checks physicality,
  species relationships, and covered-parent synchronization;
- `regression_mpi_amr_reactive_3d_exact` requires both level CSV streams from
  every MPI rank count to equal the serial streams byte for byte;
- a two-rank checkpoint at coarse step four is resumed independently by four
  and eight ranks, and `regression_mpi_amr_reactive_3d_restart_exact` requires
  both continuations to equal the uninterrupted serial result byte for byte.

## Qualification boundary

This record qualifies deterministic distributed arithmetic and selected-root
same-schema restart for the periodic, inviscid, PCM, static, strictly interior,
single-patch, two-level 3D AMR hydro case. It does not qualify rank-local
persistent fields, halo exchange, distributed/scalable I/O, performance
scaling, chemistry or molecular transport across AMR levels, high-order hydro
or prolongation, regridding, physical coarse boundaries, 3D EB, schema
migration, cross-toolchain bit identity, or whole-application PeleC parity.

qualification is recorded after the final milestone audit.
