# PeleF 0.140.0 validation record

## Scope

This milestone removes the unconditional selected-owner input gather from both
direct sparse MPI 2D EB AMR molecular-transport Euler stages. Each root tile
owner now assembles the state and geometry needed for its target band, runs the
existing transport-flux and StateRedist kernels, and returns deterministic
owned result and flux rows to the root physics owner.

Interior targets use the qualified six-row guard. A target that touches a
periodic y boundary temporarily assembles the complete root band so that the
serial transport kernel preserves the physical periodic wrap instead of
wrapping a clipped band onto an unrelated interior row.

## Automated evidence

The direct sparse transport gate checks the exact halo, result, child-bundle,
correction, and final-scatter transfer counts. It separately checks the exact
number of target-band cells advanced and requires two root-tile Euler advances
per complete SSPRK2 transport step. A late child failure must leave every
sparse field bitwise unchanged and publish zero transport work and traffic.

The gate matches the serial multipatch root and child state and temperature
fields at one, two, four, and eight ranks. State and temperature retain their
established `2e-11` scaled tolerances and the transport limiter minimum retains
its `2e-13` scaled tolerance. On the qualification mesh, work may equal the
replicated-root baseline at one and two ranks, while ranks above two must
advance fewer root transport cells.

Qualification head `9b39bbb` is covered by ordinary CI run `32964837457` and
MPI CI run `32964837434`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

Target tiles are processed in a deterministic sequential loop, so this change
does not claim concurrent wall-time speedup. Periodic y-edge targets still use
a complete temporary root band. The root physics owner also still receives one
post-compute level-wide bundle per stage for child exterior data and reflux,
and child corrections still make their established round trip. Cyclic finite-
halo geometry and a distributed coarse/fine interface remain separate work.
