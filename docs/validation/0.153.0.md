# PeleF 0.153.0 validation record

## Scope

The reactive 2D EB patch tree now selects one stable hyperbolic interval across
arbitrary depth and branching. The established active-cell CFL calculation is
shared below the runnable driver and AMR layers. Every node containing fluid is
evaluated on its own geometry, then its local interval is multiplied by the
cumulative product of ancestor refinement ratios before entering the root-time
minimum.

Fully covered nodes impose no constraint, while an entirely inactive tree,
invalid species layout, nonfinite or out-of-range CFL, failed active-cell state
conversion, or cumulative-scale overflow returns a zero timestep. Selection is
read-only for topology, conserved state, and temperature.

## Qualification boundary

This milestone selects the hyperbolic CFL interval only. It does not advance
arbitrary-depth 2D EB hydrodynamics, chemistry, or molecular transport, own a
public time loop, build dynamic tag plans, write checkpoints, or distribute the
new numerical tree across MPI owners. Those remain separate transactions.
