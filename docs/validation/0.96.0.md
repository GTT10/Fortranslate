# PeleF 0.96.0 validation record

## Scope

This milestone permits the public serial reactive EB AMR application's
configured static single patch to coincide with an outflow physical boundary.
The physical side uses the evolving fine boundary state as a zero-gradient
exterior state, while the remaining sides preserve coarse-time interpolation,
flux accumulation, reflux, and average-down.

## Automated evidence

The input-driven case uses a 12 by 12 plane-EB root and a ratio-two patch over
root indices `i=1:6`, `j=2:10`, producing a 12 by 18 fine mesh whose lower
x coordinate is exactly the global boundary. The public executable advances a
uniform seven-species state to `1e-7` with characteristic PLM, HLLC, and
second-order StateRedist.

The output checker requires exact root and fine row counts and cell-center
coordinates, the requested final time, finite positive density and pressure,
temperature and pressure stationarity, negligible velocity drift, species
closure, and regular, cut, and covered EB classes on both levels. The case is
included in the focused application gate alongside the existing single- and
multipatch lifecycle tests.

Implementation head `bf2eb88` is qualified by
[branch CI run 32851537633](https://github.com/GTT10/Fortranslate/actions/runs/32851537633)
in GNU Fortran Release and bounds-, backtrace-, and
floating-point-exception-checked Debug configurations. The focused nine-test
gate passed before the complete regression in each configuration. All 177
tests passed in Release and Debug.

## Qualification boundary

The qualified path is a configured static single rectangle on an outflow side.
The dynamic single- and multipatch planners still produce strictly internal
rectangles, and multipatch hydro still rejects physical-side children. Inflow,
wall, periodic, and mixed physical boundary refinement, EB molecular
transport, deeper EB levels, distributed ownership, and checkpoint parity for
a physical-side patch remain outside this milestone.
