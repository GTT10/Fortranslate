# PeleF 0.192.0 validation record

## Scope

The public arbitrary-depth outflow-boundary topology survives checkpoint,
independent restart, and sparse-MPI ownership redistribution.

## Automated evidence

The serial uninterrupted, checkpoint-stop, and restarted processes use a
four-level x-upper hotspot. The checker requires schema 4, a complete terminal
marker, limited-linear prolongation identity, four populated levels, exact
x-upper contact at every level, correct stop/final times, identical composite
topology, and numeric field parity.

The sparse workflow writes the same checkpoint with two ranks, rejects an
incompatible fingerprint with four ranks, and restarts successfully with four
and eight ranks under a changed ownership weight. Both restarted outputs must
match the uninterrupted one-rank reference.

GNU Fortran Debug and Release qualification run identifiers are recorded in
the pull request before merge. Python syntax, version consistency, and
`git diff --check` are also required.

## Qualification boundary

Checkpoint schema 4 remains current. Non-outflow physical children and
periodic-seam topology remain outside the EB application contract.
