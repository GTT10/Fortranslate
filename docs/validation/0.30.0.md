# PeleF 0.30.0 validation record

## Scope

This milestone generalizes the one-dimensional AMR hierarchy, transfer,
subcycling, flux-register synchronization, and composite integration primitives
from one adjacent pair to arbitrary nested depth.

## Automated evidence

`unit_amr_multilevel_hierarchy_1d` constructs four levels with refinement
ratios `2`, `3`, and `2`. It verifies the resulting level cell counts
`16/24/54/92`, cumulative spacings, physical bounds, and contiguous level
numbering. It also checks a valid root-only hierarchy and rejects a
boundary-touching patch introduced at an interior depth.

The test recursively prolongs a two-component linear field, restricts every
child back to its parent, and requires the multilevel composite integral to
match the root integral. Root-relative subcycle counts must be `1/2/6/12`, and
each count multiplied by its level step must reproduce the root interval.

Finally, the test manufactures different coarse and fine interface fluxes at
all three interfaces simultaneously. Deepest-to-root reflux and average-down
must drive the nonzero composite mismatch to roundoff, synchronize every
covered parent region, and reset every flux register.

The complete Debug and Release serial suites remain active. Main integration
also runs the MPI-enabled Debug and Release suites to protect the existing
uniform-grid distributed paths.

## Qualification boundary

This milestone qualifies arbitrary-depth, strictly nested, single-patch
hierarchy primitives. The runnable reactive AMR application remains two-level.
Recursive reactive hydro/chemistry/transport advancement, dynamic multilevel
regridding, multiple patches, physical-boundary refinement, MPI patch ownership,
and load balancing remain future integration work.
