# PeleF 0.59.0 validation record

## Scope

This milestone adds transactional explicit-plan topology changes to sparse MPI
reactive AMR storage, including rebuilt ownership, overlap transfer, no-op
handling, conservation, and rollback.

## Automated evidence

An identical four-level plan reports no change and zero transferred cells,
keeps the original owner distribution and payloads, and increments only the
regrid-evaluation counter.

A changed plan grows the level patch counts from `[1, 2, 3, 2]` to
`[1, 3, 3, 2]`. The sparse and serial paths report the same positive overlap
count, and gathering the rebuilt owners reproduces every serial field, ghost,
counter, and statistic exactly. The global sparse payload count equals one
replicated tree, while composite conserved integrals remain within `2e-9`.

The 4/8-rank cases move common patch indices to newly balanced owners. The
1/2-rank cases permit coincidentally unchanged owners while still validating
the rebuilt distribution. An invalid parent reference rejects collectively,
reports no change or transferred cells, and restores the complete sparse
solution and old distribution exactly.

Branch run 32711511475 passed the complete GNU Fortran Debug/Release MPI suite
with 1, 2, 4, and 8 ranks for implementation commit `690638c`.
Branch run 32711511445 passed the complete serial Debug/Release suite for the
same implementation commit.

## Qualification boundary

Persistent output is rank-local and globally single-copy. The transition uses
a temporary all-rank reactive replica and collective owner synchronization.
Direct sparse tag planning, point-to-point overlap transfer, and removal of the
temporary replica remain future work.
