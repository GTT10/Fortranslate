## Scope

owners while retaining the owner-authoritative replicated bridge. It covers
collective failure handling, parent/child subcycling, cross-owner adjacent
siblings, shared time-integrated fluxes, reflux, average-down, and rollback.

## Qualification boundary

The finite-volume patch kernel executes on owners alone, but patch storage,
parent/child synchronization, and shared-flux/reflux work remain replicated.
This is not sparse, stage-synchronous distributed RK. Owner-only molecular
transport, rank-local patch allocation, regrid migration, and scalable
point-to-point schedules remain future integration work.
