# PeleF 0.174.0 validation record

## Scope

The public serial arbitrary-depth reactive 2D EB application now has a
checkpoint-stop/restart round-trip gate. A four-level temperature-tagged plane
EB case runs uninterrupted, stops after its first scheduled post-regrid
checkpoint, and resumes in a separate process.

## Automated evidence

The checker requires the patch-tree checkpoint magic, schema one, seven
species, four stored levels, and the final completion marker. It requires the
stopped composite time to lie strictly between zero and `3e-9` seconds and the
reference and restarted outputs to reach exactly `3e-9` seconds.

Completed outputs are keyed by level, patch, and local cell indices. Their key
sets and columns must match, and every numeric field must agree within
`3e-10 * max(1, abs(reference))`. Qualification commit `fc5e27a` is covered by
CI run `33042407655`: GNU Fortran Debug and Release build the application and
pass the complete 214-test suite. The new Release reference, checkpoint-stop,
restart, and comparison tests take 5.04, 2.59, 2.57, and 0.18 seconds.

Local `fparser2` parsing passes the modified driver, Python syntax parsing
passes the checker, normalized namelist comparison proves the three physical
inputs differ only in output and lifecycle controls, and `git diff --check` is
clean.

## Qualification boundary

This milestone qualifies same-input serial application restart across a
four-level dynamic EB tree. A public sparse-MPI application and explicit
compatibility fingerprints for changed restart controls remain later work.
