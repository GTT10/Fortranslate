# PeleF 0.33.0 validation record

## Scope

This milestone preserves aligned old fine data when a tag-driven multilevel
hierarchy changes its patch bounds while retaining conservative reconstruction
and deepest-to-root synchronization.

## Automated evidence

`regression_amr_multilevel_regrid_1d` constructs three levels, perturbs a valid
uncovered root cell, and forces the nested hierarchy to change. It records the
old hierarchy, intersects the old and new deepest patches in physical space,
and requires every conserved component in that complete overlap to be bitwise
identical after regridding.

The solution reports a positive number of transferred overlap cells. After all
copies, deepest-to-root average-down must retain the already qualified composite
integral within `5e-13`. The existing dynamic-simulation, exact-coverage output,
positivity, species-closure, and Debug/Release suite gates remain active. Main
integration also runs MPI-enabled Debug and Release suites for the existing
distributed uniform-grid paths.

## Qualification boundary

Direct overlap retention requires equal old/new level spacing and aligned cell
boundaries. A spacing change falls back to conservative prolongation. General
cross-resolution remapping, multiple patches per level, physical-boundary
refinement, MPI patch ownership, load balancing, embedded boundaries, and
characteristic PPM/WENO AMR reconstruction remain future work.
