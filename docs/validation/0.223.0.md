# PeleF 0.223.0 validation record

## Scope

This milestone adds the first configure-time selected-mechanism CFD
application: `pelef_reactive_1d_selected`. It loads a normalized schema-1
bundle's NASA7, elementary/third-body/Troe reaction, and primitive gas
transport arrays and reuses the existing serial regular-grid 1D conservative
hydro, native chemistry, and molecular-transport algorithms.

The selected runtime is compiled separately from `pelef_core`; therefore a
bundle may use the same generated Fortran module and symbol names as the
committed full-H2/O2 mechanism without a compile- or link-time collision. The
ordinary fixed application retains its previous behavior and rejects the new
`selected` chemistry model.

## Configuration and startup evidence

The regular 1D namelist accepts at most 32 exact species names and matching
mole fractions. Validation rejects duplicate or unknown names, nonfinite or
negative active fractions, nonblank/nonzero unused tails, unsafe composition
wave endpoints, nonfinite thermodynamic controls, and a zero total. Finite
near-maximum fractions normalize without overflow. The selected application
also validates reaction structure and molecular-mass balance, primitive
transport records, the common NASA7 temperature interval, and the requested
hotspot range before creating output.

AMR and checkpoint/restart controls are rejected explicitly because this is a
regular serial 1D application. Portable lexical input/output aliases are also
rejected. A negative selected case naming an unknown species and a fixed-app
case requesting `chemistry_model = "selected"` both terminate at startup and
leave no CSV artifact.

## Numerical parity

The independent two-species H2/H fixture deliberately lists its initial
composition in reverse bundle order and runs chemistry plus molecular
transport to `1.0e-7 s`. It takes two accepted steps, changes the H2 mass
fraction from `8/9` to `8.8902049577744113e-1`, reaches
`1002.5860947748847 K`, remains spatially uniform, and reports zero invariant
conservation error. Repeated output is byte-identical with SHA-256
`fd7b7eb87ba71058ef7b2f6d88c1c23cad8e76808f30c41b0a79574c79cf24a4`.

For the pinned ten-species, 29-reaction full-H2/O2 bundle, the fixed and
selected regular-1D applications take six steps to `2.0e-6 s` and produce
byte-identical CSV with SHA-256
`61185992c242d5f54a015148740dcc3d0e3ab58ec021422bef10c7d5152783b9`.
The independent checker observes minimum density
`2.5488127000524102e-1 kg/m^3`, minimum pressure
`1.0133454175789822e5 Pa`, minimum temperature
`1000.1004227201691 K`, maximum mass-fraction closure error
`2.2204460492503131e-16`, zero spatial-uniformity error, and zero reported
invariant conservation error.

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in one
serial regular-grid 1D application. It is not runtime YAML/JSON loading,
CVODE-backed CFD chemistry, 2D/3D/AMR/EB/MPI dispatch, mechanisms above 32
species, a thread-safety or performance result, detailed-fuel validation,
external PeleC field parity, or experiment validation. The repository license
remains an explicit owner decision and release blocker.
