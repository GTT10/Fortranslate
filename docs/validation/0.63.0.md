# PeleF 0.63.0 validation record

## Scope

This milestone replaces child-interior broadcasts used by sparse chemistry
average-down and hydro/transport synchronization with direct child-owner to
parent-owner transfers.

## Automated evidence

The six-adjacent-child case independently derives every child whose owner
differs from the root parent owner. Sparse chemistry reports one direct
interior transfer per such child, and the communicator sum matches that count
for 1, 2, 4, and 8 ranks. Same-owner pairs copy locally; the 1-rank case reports
zero direct transfers.

The same transfer helper is exercised by recursive sparse hydro and molecular
transport during flux-register synchronization. Their existing owner-only call
counts, cross-owner field parity within `5e-13`, composite conservation within
`2e-9`, and transactional rollback gates remain unchanged.

with 1, 2, 4, and 8 ranks for implementation commit `b5bd551`.
Branch run 32715517195 passed the complete serial Debug/Release suite for the

states and fluxes, parent-to-child ghost fill, sibling flux reconciliation,
