# PeleF 0.177.0 validation record

## Scope

Fresh public sparse-MPI arbitrary-depth 2D EB startup initializes numerical
root state and temperature on the sole root-node owner, then transfers both
allocations directly into sparse storage. Non-owners never allocate either
numerical root field.

## Automated evidence

Implementation commit `1208843` is covered by ordinary CI run `33045764932`
and MPI CI run `33045764883`. GNU Fortran Debug and Release retain all 214
serial tests. MPI Debug and Release retain the complete established gate chain,
including fresh public application runs at one, two, four, and eight ranks and
the independent cross-rank checkpoint/restart processes.

The public driver collectively requires exactly one initializer rank. The new
sparse initializer requires unallocated inputs on non-owners, checks the owner
state width, geometry shape, finiteness, and positive temperature, moves both
allocations into the sparse node, and validates the committed sparse tree. The
driver then requires both source allocatables to be unallocated before initial
recursive regridding. Identity-keyed four-level output parity remains bounded
by `3e-10 * max(1, abs(one-rank reference))`. The fresh application parity
step passes in 17 seconds for Release and 49 seconds for bounds/FPE-checked
Debug. `git diff --check` and version consistency also pass.

## Qualification boundary

This milestone removes replicated numerical root initialization from the
public sparse-MPI application. Replicated geometry and relation metadata remain
intentional; explicit application/checkpoint compatibility fingerprints remain
later work.
