# PeleF 0.84.0 validation record

## Scope

This milestone adds fluid-volume centroids and selectable second-order linear
reconstruction to the serial weighted reactive EB StateRedist path. The public
API retains order 0 by default; committed reactive EB cases select order 2.

## Automated evidence

The geometry unit gate checks exact zero regular/covered centroid offsets, the
analytical normalized `+0.35` x-offset of a vertical-plane cut cell with volume
fraction `0.30`, finite bounds, and invalid-centroid rejection.

The redistribution unit gate uses two overlapping diagonal small-cell
neighborhoods. At every active fluid centroid, order 2 reproduces an affine
scalar field to roundoff while order 0 changes it measurably. Smooth and
discontinuous inputs retain their volume-weighted integral, the recipient
limiter keeps the discontinuous output in the active input range, and invalid
order 1 preserves the direct zero-output and reactive rollback contracts.
Uniform reactive circle and chemistry cases exercise the order-2 configuration
through Riemann fluxes, EB divergence, StateRedist, EOS recovery, and optional
Strang chemistry.

Implementation commits `47a53bd` and `f843cba` are qualified by branch CI in
GNU Fortran Debug and Release configurations. The full suite contains 150
tests. [Branch CI run 32771937117](https://github.com/GTT10/Fortranslate/actions/runs/32771937117)
passed all 150 tests in both configurations.

## Qualification boundary

This covers serial, single-level, nonperiodic StateRedist with order 0 or 2,
active 3-by-3 and grown 5-by-5 slope stencils, centroid and recipient limiting,
and EOS-validated transactions. It does not include order 4, physical or
periodic ghost neighborhoods, multilevel redistribution, EB coarse/fine flux
synchronization, molecular transport, or MPI ownership.
