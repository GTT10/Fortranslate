# PeleF 0.93.0 validation record

## Scope

This milestone adds a qualified two-level reactive EB multipatch kernel.
Disconnected root tags produce an ordered set of separated fine rectangles;
set-wide transactions support conservative topology changes, subcycled
hydrodynamics with per-child reflux, and active-cell Strang chemistry.

## Automated evidence

Planner tests cover two disconnected components, deterministic ordering, empty
tags, configurable gap joining, redistribution-adjacent coalescence, and
physical-boundary rejection. A plane-EB hierarchy with two separated ratio-two
fine patches verifies PCM creation, set-wide composite integration and
average-down, exact old/new overlap retention across a moved patch, exact
retention of an unchanged patch, PCM values in newly exposed cells,
conservative removal, and transactional NaN rejection.

The time-advance gate uses two 10 by 10 fine patches over a 14 by 14 root. It
requires root-once hydro, refinement-ratio child subcycling, per-child reflux,
post-step synchronization, and composite mass, total-energy, and species
conservation. The chemistry branch loads the elementary H2/O2 mechanism,
requires a measurable species change while retaining mass and energy, and
proves final average-down synchronization. An invalid solver after the first
reaction half-step must leave every root and child state and temperature
bitwise equal to its input.

Implementation head `d716993` is qualified by
[branch CI run 32842740287](https://github.com/GTT10/Fortranslate/actions/runs/32842740287)
in GNU Fortran Debug and Release configurations. The dedicated multipatch gate
passed before the complete 169-test regression in both configurations. All 169
tests passed in Release and in bounds-, backtrace-, and floating-point-
exception-checked Debug builds.

## Qualification boundary

The kernel covers one serial EB root and an ordered set of separated,
ratio-aligned fine rectangles at one finer level. The public EB AMR
application, CSV output, and formatted checkpoint schema still represent at
most one fine rectangle. EB molecular transport, deeper levels, physical-side
fine patches, and MPI ownership remain outside this milestone.
