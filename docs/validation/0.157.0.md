# PeleF 0.157.0 validation record

## Scope

The arbitrary-depth reactive 2D EB patch tree now exposes one transactional
full-physics step. A private candidate receives chemistry for half an
interval, recursive SSPRK2 molecular transport for half an interval,
recursive hydrodynamics for the full interval, a second transport half, and
the final chemistry half (`R-T-H-T-R`). Deepest-first synchronization and
hierarchy validation precede commit.

State, temperature, the minimum transport limiter theta, and optional
per-level chemistry, transport, and hydrodynamics counts remain private until
the complete composition succeeds. Failure after any valid prefix preserves
the input tree exactly, returns theta one, and publishes zero counts.

state and temperature and requires chemistry counts `[2, 2, 2]`, transport
Euler counts `[4, 8, 16]`, and hydrodynamics counts `[1, 2, 4]`. A failure
injected at hydrodynamics after valid chemistry and transport prefixes proves

## Qualification boundary

This milestone provides one complete arbitrary-depth EB patch-tree physics
transaction. It does not yet add a public adaptive multi-step time loop,
dynamic tagging and topology rebuild orchestration, checkpoint I/O, or MPI
ownership and migration for the arbitrary-depth numerical tree.
