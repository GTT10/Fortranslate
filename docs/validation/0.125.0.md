# PeleF 0.125.0 validation record

## Scope

This milestone adds owner-local hydro and molecular-transport timestep
selection for sparse MPI reactive EB AMR storage.

## Automated evidence

The serial reference takes the root and both ratio-two fine-child EB
hyperbolic CFL limits, the enabled viscous/thermal/species-diffusion limits,
and scales each fine result back to a coarse interval. The sparse selector must
match within 64 machine epsilons at one, two, four, and eight OpenMPI ranks.

The 14 by 14 root is split into one row tile per available rank. The expected
payload count is one send per tile not owned by the root physics owner. Local
send counts and their communicator sum must match exactly; the one-rank count
must be zero. A finite negative density on the final child must reject
collectively after any candidate root gather, preserve every sparse field
bitwise, and publish zero dt and zero transfers.

Implementation head `ce725bc` was qualified by ordinary CI run `32922778436`
and MPI CI run `32922778393`. GNU Fortran Release and bounds/FPE-checked Debug
both passed the complete 208-test serial regression. The MPI workflow also
passed the sparse timestep parity, traffic, rejection, and all established MPI
gates at one, two, four, and eight ranks in both configurations.

## Qualification boundary

The selector returns one stable coarse interval but does not yet loop to a
target time or own step counters. A public sparse time loop, dynamic topology,
checkpointing, and output remain outside this milestone.
