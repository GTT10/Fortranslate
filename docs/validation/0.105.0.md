# PeleF 0.105.0 validation record

## Scope

This milestone adds transactional checkpoint/restart of the committed finest
topology and regrid cadence to the public dynamic three-level reactive EB AMR
lifecycle without changing any established checkpoint schema.

## Automated evidence

The public case constructs a 12 by 12 root, a fixed ratio-two 20 by 20 middle
rectangle, and an 8 by 8 finest seed. EB-aware initialization regrids that seed
to a deterministic 22 by 28 rectangle. An uninterrupted run advances to
`2e-7`; a split run writes after its first accepted interval, reports at least
one committed regrid, and stops strictly before final time.

The checker requires the distinct dynamic three-level magic, schema and end
marker. It verifies exact stored regrid controls, a non-seed finest rectangle
whose dimensions are 22 by 28, and a positive stored regrid count. Restart
must emit 144 root, 400 middle, and 616 finest rows. Every final CSV field on
all three levels must agree with the uninterrupted result within a `3e-10`
scale-aware tolerance. Existing static three-level, single-patch, and
patch-set restart regressions remain in the complete suite.

Implementation head `cde01d3` is qualified by branch CI run 32877171143 in
GNU Fortran Release and bounds-, backtrace-, and
floating-point-exception-checked Debug configurations. The focused dynamic
reference, checkpoint-stop, restart, and comparison gates passed before the
complete regression in each configuration. All 193 tests passed in Release
and Debug.

## Qualification boundary

The root and middle topology remain fixed and the finest patch remains active
and unique. The checkpoint is serial and formatted and requires compatible
mechanism, EB, physics, and regrid controls. Dynamic parent levels, finest
removal or siblings, molecular transport, arbitrary-depth EB recursion,
parallel checkpoint I/O, and MPI-distributed state remain outside this
milestone.
