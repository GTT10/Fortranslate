## Implementation

[Cantera's Tsang approximation](https://cantera.org/3.2/reference/kinetics/rate-constants.html)
uses Fcenter=A+B*T with the remaining Troe broadening expressions unchanged.
The runtime reuses those expressions and their analytic concentration
pressure derivative via an optional center argument. B defaults to zero;
nonfinite coefficients and centers that cannot be positive are rejected in
input, and a nonpositive evaluated center rejects the runtime rate.

Reaction kinds 7/8 distinguish Tsang falloff and Tsang chemically activated
rates. Their two coefficients are stored separately, emitted by the generator,
compared in MPI mechanism metadata and written/read in AMR/EB checkpoint
contexts only for those kinds. Existing non-Tsang checkpoint record layouts
and non-Tsang generated source remain unchanged.
