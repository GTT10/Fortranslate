# PeleF 0.215.0 validation record

## Scope

This milestone adds optional masked cell-local elementary chemistry to the
serial, single-level, exact-axis-plane `pelef_reactive_eb_3d` workflow. The
operator split is transactional `R(dt/2)-H(dt)-R(dt/2)`, with the existing
StateRedist/FluxRedist hydro selection and exact covered-cell preservation.

## Automated evidence

- the 3D chemistry wrapper accepts x-, y-, and z-oriented active masks by
  passing each z slice to the qualified 2D cell-local reactor;
- a disabled regular cell and every covered cell remain bitwise identical,
  while an invalid mask shape and a failure on a later z plane roll the whole
  state and temperature back exactly;
- the EB split preserves inert StateRedist arithmetic, changes active species,
  conserves mass, energy, tangential momentum, and H/O/N totals, and preserves
  covered storage;
- invalid solver and chemistry-tolerance requests reject without publishing a
  candidate;
- the public inert case is byte-identical to the existing 0.214 StateRedist
  output, while the reacting case independently passes geometry, EOS,
  local total-energy, positivity, closure, active-species, raw covered-row,
  fluid-invariant, elemental, step-schedule, and full-field hash checks.

## Qualification boundary

This record qualifies a serial, single-level, inviscid, first-order, PCM
exact-axis-plane workflow with the frozen seven-species elementary H2/O2/N2
mechanism, active-cell chemistry, and StateRedist public case. Covered cells
and masked-off active cells retain exact caller storage. The wall-normal
momentum remains a physical embedded-wall exchange rather than a conserved
fluid quantity.

It does not qualify configurable or production-stiff mechanisms, molecular
transport, higher-order EB reconstruction, FluxRedist chemistry as a public
case, general geometry, AMR/reflux/regridding, checkpoint/restart, MPI
ownership, scalable I/O, or external physical validation.

The application chooses the hydro timestep from the state before the first
reaction half step. The frozen public case demonstrates a stable low-feedback
coupling regression; this record does not establish general reaction-aware
timestep stability.
