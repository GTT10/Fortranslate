# Three-dimensional PPM corner transport fluxes — 2026-09-25

Implementation `c05f555`, base `e7d2b1c`.
`compute_reactive_ppm_ctu_fluxes_3d` extends the periodic normal
predictor with the twelve-solve CTU ordering: three normal solves, six
single-transverse dt/3 corrections and solves, then three final solves using
both complementary transverse flux differences at dt/2. It exposes the minimum
positivity correction factor. Normal predictor states/temperatures are retained
only when requested; original normal-flux callers remain supported. Final fluxes
publish only after all stages succeed and share one value on each periodic seam.

The corrections reuse PeleF's existing conservative EOS-recovery and positivity
bisection from the 2D reactive solver. This differs from PeleC's separate
pressure-work correction in `pc_transdo`/`pc_transdd`. External pressure/state
parity is not established. The new API has no forcing source and does not yet
connect a production conservative time update, physical/AMR halos, MPI or
application selection. Full reference multidimensional PPM remains open.
