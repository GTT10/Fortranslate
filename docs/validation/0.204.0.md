# PeleF 0.204.0 validation record

## Scope

This milestone adds a serial, single-level, uniform-grid, periodic,
general-EOS multispecies three-dimensional Euler application. It advances the
existing NASA7 reactive state with PCM face states, selectable
Rusanov/HLLC/PeleC-style directional fluxes, a summed multidimensional CFL
limit, per-stage temperature recovery, and transactional SSPRK2 integration.
Chemistry and molecular transport are disabled.

## Automated evidence

- `unit_reactive_euler_3d_dimensional_reduction` validates the strict
  configuration/model contract, requires exact x/y/z whole-step agreement
  with an independent 1D general-EOS SSPRK2 reference for Rusanov, HLLC, and
  PeleC-style fluxes, and verifies invalid-solver rollback of both state and
  temperature;
- `regression_reactive_entropy_wave_3d` advances an elementary seven-species
  diagonal entropy wave on 6^3, 12^3, and 24^3 grids and checks convergence,
  positivity, species closure, and all twelve conserved integrals;
- `regression_reactive_entropy_wave_3d_run` exercises the public
  `pelef_reactive_3d` full-H2O2 namelist;
- `regression_reactive_entropy_wave_3d_check` independently checks the
  1728-row CSV schema, x-fastest order, exact density wave, ideal-mixture EOS,
  momentum and species-density identities, composition, closure, and
  analytical mass, momentum, and species totals;
- `quality_no_executable_stack` includes the new shipped application.

## Numerical signatures

With GNU Fortran 13.3.0 Debug checks enabled, the elementary-thermo density L1
errors were `4.6267198275855778e-3`, `2.6294336544068798e-3`, and
`1.4029586847219102e-3` on 6^3, 12^3, and 24^3 grids. The observed orders were
`0.81523764336650295` and `0.90627957122633540`. The largest relative
all-component conservation error was `2.1371793224034263e-15`; the maximum
species-closure error was `2.2204460492503131e-16`.

All nine Rusanov/HLLC/PeleC-style by x/y/z dimensional-reduction comparisons
had zero reported state and recovered-temperature difference.

The public 12^3 full-H2O2-thermo case completed 12 steps at `t=1.0e-6 s`.
Its density L1 error was `4.6251476586166651e-3`, maximum relative change over
all fifteen conserved components was `1.2490009027033011e-15`, and maximum
species-closure error was `1.1102230246251565e-16`. The independent CSV check
reported an analytical conserved-integral error of `6.776e-21`.

## Qualification boundary

The word `reactive` describes the state layout and thermodynamic closure in
this milestone. No chemical source term is enabled, so this record does not
qualify 3D chemistry or Strang splitting. It also does not qualify molecular
transport, high-order 3D reconstruction, AMR, restart, MPI decomposition, EB,
LES, particles/spray, scalable output, accelerators, or whole-application
PeleC parity.
