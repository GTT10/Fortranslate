# PeleF 0.159.0 validation record

## Scope

The arbitrary-depth reactive 2D EB patch tree now has a deterministic MPI
ownership descriptor. Every runtime level/patch pair records one owner,
allocated-cell count, and optional cumulative-subcycle-weighted work count.
Exact per-rank cell, node, and work totals are validated against the map.

The first owner-authoritative publication operation keeps field allocation
replicated. It broadcasts each owner's state and temperature into one private
candidate and commits only after collective topology/input consensus and final
tree validation. A rank-local invalid candidate or inconsistent weighting
control rejects collectively with zero publication accounting.

## Automated evidence

A regular four-level branching topology has patch counts `[1, 1, 2, 1]`, five
total nodes, 352 allocated cells, and 6016 work units when cumulative subcycle
weighting uses exponent two. Each owner writes a distinct node value; after
publication every rank requires the exact complete tree, and the sum of local
owner-publication counts is five.

One rank then supplies an invalid temperature. All ranks must reject while
retaining their exact pre-call local candidate and publishing zero counts. A
second negative gate supplies inconsistent subcycle exponents across multiple
ranks, or an out-of-range exponent at one rank, and requires collective
initialization rejection.

Qualification commit `20adbc1` is covered by MPI CI run `33021211699`. GNU
Fortran Debug and Release builds pass. The new ownership executable passes at
OpenMPI one, two, four, and eight ranks in Release and bounds/FPE-checked Debug
configurations. The workflow also passes all established MPI gates and the
complete 208-test serial regression. Local `fparser2` parsing passes all 206
Fortran sources.

## Qualification boundary

This milestone establishes owner metadata and replicated owner publication.
It does not yet remove nonowner field allocation, migrate fields directly
between owners, reduce timesteps from sparse nodes, or route recursive physics
on owners.
