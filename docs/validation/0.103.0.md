# PeleF 0.103.0 validation record

## Scope

This milestone adds transactional checkpoint/restart to the public static
three-level reactive EB AMR lifecycle without changing the established
single-patch or multipatch checkpoint schemas.

## Automated evidence

The public restart case uses an 8 by 8 root, a ratio-two 12 by 12 middle
rectangle, and a nested ratio-two 16 by 16 finest rectangle whose interface is
crossed by a plane embedded boundary. Chemistry is enabled on all active cells.
An uninterrupted run advances to `4e-7`; a split run writes a dedicated
three-level checkpoint after its first accepted interval, stops strictly
before final time, and restarts from that stream.

The checker requires the dedicated magic header and terminal marker, verifies
64 root, 144 middle, and 256 finest output rows, and compares every final CSV
field from the restarted run with the uninterrupted result within a `3e-10`
scale-aware tolerance. The complete suite retains the older single-patch and
patch-set restart regressions.

Implementation head `c8bdda0` is qualified by branch CI run 32871385166 in
GNU Fortran Release and bounds-, backtrace-, and
floating-point-exception-checked Debug configurations. The focused reference,
checkpoint-stop, restart, and comparison gates passed before the complete
regression in each configuration. All 187 tests passed in Release and Debug.

## Qualification boundary

The hierarchy remains static, serial, aligned, and exactly three levels deep.
Restart requires an identical nested topology and physics signature. Dynamic
three-level regridding, molecular transport, arbitrary-depth EB recursion,
parallel checkpoint I/O, and MPI-distributed state remain outside this
milestone.
