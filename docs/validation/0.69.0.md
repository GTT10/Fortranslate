# PeleF 0.69.0 validation record

## Scope

This milestone adds a prescribed species-conversion flux to reactive 2D
slip/no-slip walls. Inputs are wall-to-gas species mass fluxes, must sum to
zero, and leave the impermeable total-mass and momentum wall contract intact.
The matching NASA7 species-enthalpy flux is included in total energy.

## Automated evidence

`unit_reactive_boundary_2d` verifies lower/upper coordinate orientation in
both x and y, exact species-flux closure, nonzero species enthalpy transport,
unbalanced-vector rejection, and rejection when species transport is disabled.

`regression_reactive_physical_boundaries_2d` advances a uniform reactor with
lower-wall H2 production and O2 consumption. The integrated species inventory
changes must match the time-integrated prescribed flux within `2e-6` relative
error while total mass, cellwise species closure, and positive temperature are
retained.

`regression_reactive_prescribed_species_wall_2d_run` reads the committed
namelist through `pelef_reactive_2d` and completes the same wall-conversion
configuration through the public application path.

Branch run 32726881431 passed all 138 GNU Fortran tests in Debug and Release
for implementation commit `20d80fc` before the final x-direction symmetry and
documentation-only follow-up.

## Qualification boundary

This is a conservative boundary transport interface for future catalytic-wall
models. It prescribes fluxes supplied by the user; it does not solve a surface
mechanism, coverage equations, wall heat release, porous injection, or
embedded-boundary geometry.
