# PeleF 0.38.0 validation record

## Scope

This milestone adds separated one-dimensional fine patches over one parent
level. It qualifies conservative patch-set primitives, disconnected-tag
planning, overlap-preserving patch-set regridding, and fixed two-level reactive
WENO hydro. The main dynamic application remains one patch per level.

## Automated evidence

`unit_amr_multipatch_1d` verifies boundary-contact and empty sets, rejects
adjacent boxes, checks aggregate coverage, and proves set-wide conservative
prolongation, average-down, flux-register reset, reflux, and composite
integration. It also moves and repartitions two patches, checks exact aligned
fine overlap from both old patches, and removes the complete set without
changing the composite integral.

`unit_amr_regrid_1d` separates disconnected tags into two buffered plans,
coalesces candidates whose expanded bounds become adjacent, retains small
configured tag gaps inside one patch, and represents an empty tag set.

`regression_amr_multipatch_reactive_1d` advances a periodic entropy wave on a
64-cell parent and two separated ratio-two patches. Characteristic PPM with
hybrid WENO7-Z advances the parent for two steps and each patch for four total
fine substeps. The gate requires both patch interiors to change, composite
conservation within `3e-10`, synchronization of both covered regions within
`5e-13`, positive thermodynamics, and species closure within `3e-10`.

All gates run with array-bounds checking in the GitHub Actions Debug build and
again in Release. Main integration also retains the MPI-enabled Debug and
Release suite.

## Qualification boundary

Patches are ordered and separated by at least one uncovered parent cell.
Touching candidates are coalesced; independent same-level ghost exchange is
not implemented. The reactive path is fixed two-level hydro. Dynamic reactive
patch-set rebuilds, chemistry, molecular transport, arbitrary-depth patch
trees, output, load balancing, and MPI ownership remain future work.
