# PeleF 0.136.0 validation record

## Scope

This milestone decomposes the replicated MPI-owner 2D EB AMR root hydro
advance over the established y-tile owners. It replaces one selected-rank
complete-root update and four result broadcasts with bounded-halo tile kernels
and collective assembly, while retaining the qualified child-owner subcycling,
reflux, and average-down transaction.

## Automated evidence

Each root tile owner extracts an exact EB geometry/state band with at most six
guard rows on each side, invokes the established reactive EB level kernel, and
publishes only its owned state, temperature, x-face rows, and uniquely assigned
y-faces. Tests require one committed root advance per tile owner and compare
the complete assembled hierarchy with the serial multipatch reference at one,
two, four, and eight ranks.

An independent computed-cell counter must equal the exact sum of all local
halo-band sizes. Above one rank, that total must remain below the work required
to advance the complete root independently on every rank. The same tile-owner
accounting and field parity are required inside the complete reaction-
transport-hydro split. A late child failure must leave the hierarchy unchanged
and publish zero advances and zero root work.

Qualification head `291b0b3` is covered by MPI CI run `32956175459`. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations. Both configurations also pass the complete 208-test
serial regression.

## Qualification boundary

The replicated owner path still has complete root inputs on every rank and
assembles complete root outputs for the existing child/reflux interface. The
sparse path still gathers root tiles to one selected physics owner. Direct
sparse halo exchange, sparse tile-result routing, and owner-tiled transport
remain separate work.
