# Prescribed reservoir inflow in regular 3D

Parent: `f6177cf`. The new `inflow` face accepts independent temperature,
pressure and velocity per face. One named inflow composition is shared by
inlet faces; omission uses the initial mixture. Fixed and selected mechanisms
resolve inlet species names against their loaded mechanism. See the
[boundary guide](../../cases/reactive_boundaries_3d/README.md).

Reservoir conserved states are fixed during hydro and both transport
half-steps. Their convective/diffusive exchanges enter the existing surface
ledger. Ghost corners use documented z/y/x inlet precedence followed by wall
reflection. Timestep selection includes both inlet acoustic/advection speeds
and inlet molecular diffusivity, in addition to the evolving interior state.
This is a prescribed ghost-state inlet, not a characteristic boundary or an
exact prescribed numerical mass-flow rate.

## Focused verification

GNU Fortran 13.3.0 Debug, `build/port-spray-debug`:

```sh
cmake --build build/port-spray-debug --parallel 8 --target \
  pelef_reactive_3d test_reactive_boundaries_3d test_reactive_boundary_transport_3d
ctest --test-dir build/port-spray-debug --output-on-failure \
  -R '^(unit_reactive_(boundaries_3d|boundary_transport_3d)|reactive_boundary_3d_inflow)$'
```

Three tests passed in 7.26 s. Coverage includes inward mass/momentum and surface
budgets on all six faces, missing-reservoir rollback, invalid inlet temperature,
existing hydro/transport wall behavior, and an application combining an inlet
composition different from the initial mixture with molecular transport.

The existing FFCM1_Red Release configuration built and ran
`pelef_reactive_3d_selected`. `build/port-spray-cvode/inflow-run/` retains its
input/output/log: initial CH3OH/O2/N2 mole fractions 0.05/0.20/0.75, inlet
H2/O2/N2 mole fractions 0.20/0.20/0.60, with other values from the committed
inflow case. The normalized boundary-accounted Euler residual was `5.275e-17`.
Chemistry is disabled in these application smokes.

Build/test logs use the `inflow-` prefix in the two build directories.
Mechanism provenance, project contract and whitespace checks passed. No Python
source changed; no broad matrix or external physical benchmark was run.

Characteristic boundaries, moving/isothermal walls, general 3D AMR/EB and
particle boundary coupling remain open. This does not complete the project.
