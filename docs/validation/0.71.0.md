# PeleF 0.71.0 validation record

## Scope

This milestone adds a distributed stable-timestep calculation for globally
single-copy sparse MPI AMR fields. Each rank evaluates only its owned reactive
patch payloads, converts level limits to the root-step scale, and participates
in one communicator-wide minimum reduction.

## Automated evidence

`pelef_mpi_amr_patch_1d` compares the sparse hydro-only and transport-enabled
limits with the serial four-level patch-tree result. Hyperbolic limits receive
cumulative `r` scaling and molecular-transport limits receive cumulative
`r^2` scaling before reduction.

The same executable verifies collective rejection and a cleared zero timestep
for a nonphysical root-owner state and for enabled transport without transport
data. A root-only hierarchy verifies that ranks with no local patch contribute
a neutral minimum-reduction value rather than rejecting a valid calculation.

MPI branch run 32731867786 passed the complete GNU Fortran Debug and Release
suites, including all 1/2/4/8-rank sparse AMR gates, for implementation commit
`5046bd5`. Normal branch run 32731867756 also passed the complete Debug and
Release suites for the same commit.

## Qualification boundary

The routine selects a stable root interval from the current sparse hierarchy.
It does not clip against a stop time, advance fields, choose regrid cadence,
write distributed output, or manage checkpoints and restart.
