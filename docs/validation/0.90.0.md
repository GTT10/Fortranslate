# PeleF 0.90.0 validation record

## Scope

This milestone adds an optional lifecycle for the serial reactive EB AMR fine
patch: conservative removal on empty temperature tags, released fine storage,
root-only timestep and hydrodynamic dispatch, PCM re-creation when tags return,
and lifecycle-aware diagnostics and output.

## Automated evidence

The driver gate starts from a uniform two-level hierarchy with initial regrid
evaluation disabled. It requires two accepted intervals: the first produces an
empty tag plan, one committed degrid, an inactive fine level, deallocated state
and temperature, and invalidated geometry and patch metadata; the second uses
the root-only CFL and hydrodynamic path. It then tags the root directly,
re-creates a valid fine patch by PCM, verifies the composite integral, removes
the tag, collapses the new patch again, and recovers the same root integral.

The direct regrid gate independently proves that collapsing an EB hierarchy
preserves every volume-weighted conserved component and recovers finite positive
temperatures on active parents. The application regression reads the new policy
controls, removes its uniform fine patch, continues through the root-only path,
writes a stationary 12 by 12 coarse CSV, and proves that no fine CSV was written.

Implementation head `583238f` is qualified by
[branch CI run 32827188204](https://github.com/GTT10/Fortranslate/actions/runs/32827188204)
in GNU Fortran Debug and Release configurations. All 161 tests passed in both;
Release completed in 181 seconds and Debug in 452 seconds. The test phases took
135 and 422 seconds respectively, with bounds, backtrace, and floating-point
exception checks enabled in Debug.

## Qualification boundary

The lifecycle covers one serial, ratio-aligned, strictly internal fine rectangle
over one root level. Removal is opt-in, so existing inputs retain an untagged
patch. Multiple patches, deeper levels, EB AMR chemistry and molecular
transport, checkpoint/restart, and distributed EB ownership remain outside this
milestone.
