# PeleF 0.160.0 validation record

## Scope

The arbitrary-depth reactive 2D EB patch tree now has a sparse numerical
representation. Topology and ownership metadata remain replicated, while
conserved state and temperature allocate only on the owner of each runtime
node. Exact local node and allocated-cell totals are checked against the
distribution.

An explicit materialization operation reconstructs a complete replicated tree
from owner fields. A distribution change allocates one private owner-only
candidate, copies unchanged nodes locally, and sends changed nodes directly
from old owner to new owner. The accepted sparse tree commits only after
collective descriptor consensus and complete candidate validation.

## Automated evidence

The four-level branching topology has patch counts `[1, 1, 2, 1]`, five nodes,
and 352 allocated cells. At every tested rank count, sparse initialization must
match the distribution's exact local node and cell totals. Materialization must
reproduce every accepted state and temperature value with five total owner
publications.

For two, four, and eight ranks, rotating every node owner by one requires five
direct transfers; at one rank it requires zero. A second materialization must
retain exact field parity. Rank zero then supplies an out-of-range owner in a
new distribution while all other ranks retain the valid map. Migration must
reject collectively with zero transfers and preserve the exact accepted sparse
tree on every rank.

## Qualification boundary

This milestone removes nonowner persistent field allocation and adds direct
owner migration. It does not yet reduce timesteps from sparse nodes or route
recursive physics on owners.
