topology from owner-local temperature fields. It reduces compact per-parent
tag plans, rebuilds caller-defined EB geometry collectively, assigns the
candidate tree deterministically, and migrates retained fields directly
between old and new owners without materializing a complete numerical tree.

and owner map. Rank-dependent valid criteria on multiple ranks and invalid
