# PeleF 0.144.0 validation record

## Scope

This milestone runs sparse reactive transport reflux on the fine-child owner.
The EB reflux kernel accepts coarse state and temperature arrays with explicit
global lower bounds and any rectangle containing the fine patch expanded by
two coarse cells. Complete-root entrypoints remain wrappers over the same
support kernel.

The root physics owner sends each child its four-edge start/end exterior
context, compact patch-plus-one flux register, and latest patch-plus-two coarse
support. The child performs ratio subcycling, accumulates fine interface flux,
refluxes locally, retains corrected fine state, and returns only corrected
coarse support for deterministic root-owner merge.

## Automated evidence

The reactive flux-register unit gate executes reflux once through the complete
root wrapper and once through a strictly smaller globally indexed support. It
requires bitwise-identical coarse state and temperature on that support,
bitwise-identical complete fine state and temperature, and successful register
reset. The established nonphysical rollback gate remains active.

For every qualification child, the MPI application requires the combined
exterior/register/support value count to be positive and strictly smaller than
the former complete root state, temperature, and x/y-flux bundle. A remote
child uses exactly two messages per Euler stage: context/support from root to
child and corrected support from child to root. Exact owner work, transfer
counts, limiter minima, serial root/child field parity, public-clock accounting,
scheduled regridding, and late-failure rollback remain required.

Qualification head `71b8135` is covered by ordinary CI run `32987126603` and
MPI CI run `32987126686`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank gates pass in Release and bounds/FPE-checked
Debug configurations, and both workflows pass the complete 208-test serial
regression.

## Qualification boundary

The owner-tiled root Euler stages still assemble one complete temporary root
start/end/temperature/x-y-flux result on the root physics owner. That owner
also initializes the coarse register, sends the compact child context, merges
corrected supports in child order, and scatters final root rows. Hydro is
unchanged. This milestone qualifies storage, numerical parity, traffic, and
rollback behavior; it does not claim a measured speedup.
