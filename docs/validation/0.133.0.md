# PeleF 0.133.0 validation record

## Scope

This milestone separates replicated sparse MPI reactive EB AMR restart
topology from child conserved and temperature fields. It adds direct
geometry-only topology construction, compatibility extraction, validation,
root-to-owner scatter, and root-only checkpoint read APIs.

## Automated evidence

The MPI gate constructs the ordered two-child descriptor directly from fine EB
geometries and the regrid-plan collection before initializing numerical child
fields. Direct root scatter and formatted checkpoint restart use only that
descriptor on non-root ranks. Every owner-local root tile and child field must
match the original sparse payload bitwise, retain its exact stored-value count,
and satisfy the independent one-send-per-remotely-owned-entity formula.

The checkpoint gate also requires exact time, step, regrid, minimum-timestep,
and base-density metadata. A descriptor with an invalid EB volume fraction must
return an empty sparse set and zero traffic collectively before point-to-point
transfer. A missing checkpoint retains the established empty-state,
zero-metadata, zero-traffic rollback.

Qualification head `358f539` is covered by ordinary CI run `32944726871` and
MPI CI run `32944726896`. GNU Fortran Release and bounds/FPE-checked Debug passed
the complete 208-test serial regression. The MPI workflow also passed all
established gates at one, two, four, and eight ranks in both configurations.

## Qualification boundary

EB geometry arrays and compact patch boxes remain replicated intentionally.
The writer/gather and physics/regrid compatibility boundaries still accept full
patch-set templates. Checkpoint-driven topology reconstruction, geometry-only
migration of those remaining boundaries, arbitrary-depth dynamic EB topology,
and decomposition of the level-wide root physics kernel remain separate work.
