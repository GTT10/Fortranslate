# PeleF 0.61.0 validation record

## Scope

This milestone replaces broadcast-based same-hierarchy sparse AMR owner
migration with one packed point-to-point message per changed patch.

## Automated evidence

The migration gate rotates every patch owner when more than one rank is active.
The global direct-transfer count equals the changed-owner patch count: zero for
the 1-rank no-op and every sparse patch for 2, 4, and 8 ranks.

Each payload packs and reconstructs state, temperature, narrow ghost fields,
and four-layer wide ghost fields. The migrated local patch and cell counts match
the new distribution, the global value count remains exactly one replicated
tree, and gathering the new owners reproduces the original reactive solution
exactly.

with 1, 2, 4, and 8 ranks for implementation commit `cd99dd1`.
Branch run 32713339782 passed the complete serial Debug/Release suite for the

## Qualification boundary

Same-hierarchy owner payloads now travel directly between their two relevant
ranks. Transfers remain ordered and use a collective acceptance boundary after
each patch. Physics stages, halo exchange, topology-changing overlap transfer,
and temporary regrid replicas remain future point-to-point work.
