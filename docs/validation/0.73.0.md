# PeleF 0.73.0 validation record

## Scope

This milestone adds checkpoint/restart to the public sparse MPI AMR reactive
driver. The checkpoint preserves the arbitrary-depth patch tree, interior
state and temperature fields, physical time, step and regrid counters, overlap
accounting, and level-advance accounting without preserving MPI ownership.

## Automated evidence

The serial patch-tree regression writes and reloads a four-level branching
solution after a recursive hydro step. It requires the reconstructed tree and
all counters to match and limits maximum state/temperature round-trip error to
`5e-10` absolute.

The public split-run gate executes an uninterrupted one-rank reference to
`5e-7`, writes a three-level checkpoint from two ranks after an intermediate
coarse step, then resumes that same file on four and eight ranks. The checker
requires the checkpoint time to be strictly intermediate and compares every
final composite CSV value with the uninterrupted reference at `5e-13`
relative tolerance.

Implementation commit `810fa99` is qualified by branch CI runs 32739453372
and 32739453427 in GNU Fortran Debug and Release configurations.

## Qualification boundary

Scheduled output gathers a complete patch tree and rank zero writes one
formatted file. The format validates schema, mechanism layout, root geometry,
and hierarchy depth; split-run parity assumes unchanged physical/numerical
operator settings. Parallel checkpoint I/O, atomic generation directories,
asynchronous writes, AMReX plotfiles, and node-failure recovery are not
implemented.
