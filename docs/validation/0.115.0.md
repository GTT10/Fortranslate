# PeleF 0.115.0 validation record

## Scope

This milestone adds rank-local sparse numerical storage for the MPI reactive
EB AMR root tiles and sibling children, together with an explicit replicated
materialization boundary.

## Automated evidence

The one-, two-, four-, and eight-rank executable starts from owner-distinct
root-tile and child states while nonowners retain stale finite replicas.
Scatter must allocate `state` and `temperature` only on each entity owner.
Local stored-value counts must match the distribution exactly, and their
communicator sum must equal all 196 root plus 200 child cells multiplied by the
reactive state-plus-temperature width.

Materialization broadcasts the sparse owner payloads and must match the
established owner-authoritative synchronizer bitwise for every root and child
field. Deallocating one rank-zero-owned root state makes the sparse object
invalid; collective materialization must reject and preserve all supplied
fallback root and child fields bitwise.

Implementation head `54c7f0c` is qualified by ordinary CI run 32904048534 and
MPI CI run 32904048574. The MPI workflow used Ubuntu 24.04 with OpenMPI and ran
the executable at one, two, four, and eight ranks in GNU Fortran Release and
bounds-, backtrace-, and floating-point-exception-checked Debug
configurations. The sparse-storage gate, all established MPI gates, and the
complete 208-test serial regression passed in both MPI configurations. The
ordinary Release and Debug CI configurations independently passed all 208
tests.

## Qualification boundary

Geometry, topology, and ownership metadata remain replicated, and current
physics operators still use complete temporary fields. Direct sparse physics,
point-to-point data flow, owner migration, dynamic topology, parallel
checkpoint/output, and a public MPI EB AMR time loop remain outside this
milestone.
