# PeleF 0.245.0 focused validation record

## Scope

This focused increment persists mixture molecular-transport context for the
existing fixed and configure-time selected, static, strictly interior,
periodic, two-level Cartesian 3D AMR hierarchy in serial and rank-local sparse
MPI execution. The `0.244.0` transport stepping, six-face limiter/reflux,
average-down, and transactional `R-T-H-T-R` scope is retained.

## Schema and persistence contract

Transport-disabled compatibility remains isolated from transport-enabled
restart:

| Call mode | Transport disabled | Transport enabled |
|---|---:|---:|
| Fixed | schema 2, unchanged | schema 4 |
| Selected | schema 3, unchanged | schema 5 |

Fixed schema 4 is used for the public `full_h2o2` case with
`chemistry_enabled=.false.` and `transport_enabled=.true.`. Selected schema 5
requires `thermo_model='selected'`, `chemistry_enabled=.true.`, and
`transport_enabled=.true.` together with the complete selected mechanism
context. Fixed/selected and transport-enabled/transport-disabled cross-schema
reads are rejected without fallback.

Schemas 4 and 5 bind the complete ordered `gas_transport_species` database,
parameter convention, transport operator identity, all transport controls,
and cumulative transport diagnostics. Checkpoints are written only at
`POST_ACCEPTED_COARSE_STEP`, after the committed
`R(dt/2)-T(dt/2)-H(dt)-T(dt/2)-R(dt/2)` update. Reads validate private level,
temperature, clock, baseline, reflux, and transport-diagnostic candidates
through the terminal marker, strict EOF, and close before publication; failed
reads leave caller-owned targets unchanged.

MPI validates the complete context on all ranks before payload communication
or root I/O. Root-formatted files contain no communicator size or ownership
map, and restored metadata is broadcast before current-rank ownership is
scattered. Serial and changed-rank MPI continuation therefore use the same
checkpoint contract exactly, including ranks with no fine planes. Formatted
`status='replace'` remains an application-level replacement; this record does
not claim crash-atomic replacement, durable commit, payload authentication, or
scalable/distributed I/O.

## Qualification boundary

This is focused transport-persistence, transactional, and deterministic
changed-rank evidence for one static two-level hierarchy. The 0.245 full
configuration matrix and clean installed Release qualification are not
included or claimed here; the `0.244.0` matrix and install evidence remain
historical in [`validation/0.244.0.md`](0.244.0.md). Dynamic topology,
boundary-touching refinement, physical coarse boundaries, 3D EB AMR,
scalable I/O, crash-atomic replacement, payload authentication,
performance/scaling, detailed-fuel physical validation, ignition, and external
PeleC field parity remain outside this record.
