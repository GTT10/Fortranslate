# PeleF 0.170.0 validation record

## Scope

The serial arbitrary-depth reactive 2D EB tree now has a distinct versioned,
self-describing formatted checkpoint. It stores ordered topology, complete EB
geometry metrics, conserved fields, temperatures, species identity, and
lifecycle metadata, then reconstructs and validates a private restart
candidate before publication.

## Automated evidence

The qualified four-level branching tree is written after a shifted-topology
rebuild with retained physical overlap. Reading the file must reproduce the
same ordered parent/child topology, state fields, recovered temperatures,
time, step count, regrid count, and minimum timestep within formatted
roundoff.

Reading with a three-level ceiling must reject the four-level file with an
empty tree and zero metadata. Exchanging the first two species must also
reject. Inconsistent time and step metadata must be rejected by the writer
before it opens the existing checkpoint path.

Qualification commit `0d1b7c8` is covered by ordinary CI run `33036896072`.
GNU Fortran Debug and Release pass the dedicated EB multilevel gate and the
complete 208-test serial regression. Local `fparser2` parsing passes the two
changed Fortran sources, and `git diff --check` is clean.

## Qualification boundary

This milestone establishes the serial storage format for complete
arbitrary-depth branching EB trees. Sparse MPI root-only checkpoint I/O,
rank-neutral restart redistribution, and composite output remain future
lifecycle work.
