# PeleF 0.79.0 validation record

## Scope

This milestone adds PeleC-default zeroth-order weighted StateRedist and an
EOS-validated transactional reactive advance on one nonperiodic Cartesian
level.

## Automated evidence

A vertical embedded wall produces a cut cell with volume fraction `0.05` and
one regular merge neighbor. With a provisional cut-cell state equal to the
negative of the uniform reference state, the weighted result must be exactly
`7/11` of the reference in the cut cell and `101/110` in the receiver. Every
reactive conserved component must retain its volume-weighted integral to
`5e-13` relative tolerance.

A diagonal plane produces three volume-fraction `0.05` cells. Two of their
three-neighbor merge neighborhoods share a cut recipient with volume fraction
`0.45 + sqrt(0.1)` and total neighborhood count `nrs = 3`. The two neighborhood
states and the shared-cell result must match the analytical `alpha`, `nrs`, and
neighborhood-volume expressions to `5e-13`; the full field must conserve to
`8e-13`. A uniform active state must be unchanged and covered cells must remain
exactly zero.

The reactive advance must recover an EOS-valid positive state from a raw
negative small-cell provisional density. A stronger nonphysical update must
leave state and temperature unchanged. Invalid target volume fractions and
nonfinite provisional states must return an all-zero redistribution result.

Implementation commits `9bebbd0` and `4da99d7` are qualified by branch CI run
`32755547562` in GNU Fortran Debug and Release configurations.

## Qualification boundary

This is zeroth-order StateRedist with in-domain, nonperiodic two-dimensional
neighborhoods. It does not yet include higher-order slopes and limiters,
periodic or physical ghost-cell neighborhoods, multilevel redistribution, EB
flux generation, AMR coupling, or MPI distribution.
