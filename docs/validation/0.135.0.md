## Scope

This milestone adds reactive conserved-state and temperature storage to the
arbitrary-depth 2D EB patch tree. It also adds parent-first PCM initialization,
deepest-first synchronization, a composite conserved-vector integral, and
transactional numerical migration through a whole-tree topology rebuild.

## Automated evidence

The established EB multilevel unit initializes a three-level tree with two
separated branches and distinct valid reactive states. Deepest-first
synchronization must conserve every state component. The tree is extended to
four levels below one branch; existing same-resolution fields must be retained,
the new child must be initialized from its updated parent, and the complete

fine values under the expected two-fine-cell index shift while newly exposed
cells come from the synchronized parent. The moving rebuild must again conserve
every state component. Repeating the accepted plan is an exact no-op, and an
invalid deepest parent must preserve topology, state, and temperature bitwise.

chemistry, molecular transport, timestep selection, dynamic tagging,
