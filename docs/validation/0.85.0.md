# PeleF 0.85.0 validation record

## Scope

This milestone joins the serial two-dimensional EB geometry and AMR foundations
with one aligned static fine rectangle. It adds EB-volume-weighted restriction,
a single-count composite integral, and a reactive EOS-validated transaction.

## Automated evidence

The new unit gate constructs coarse and ratio-two fine representations of the
same planar EB. It verifies geometry alignment and volume consistency, constant
preservation including the fully covered fallback, affine reproduction at
fluid-volume centroids, unchanged data outside the fine rectangle, and equality
of composite and restricted-coarse integrals to roundoff.

A uniform H2/O2/N2 reactive state checks conserved-state preservation and
active-parent temperature recovery. A deliberately nonphysical active fine
block must roll back both complete output arrays. Nonfinite fine input and a
misaligned patch exercise the generic transaction and hierarchy rejection.

Implementation commit `d3ececb` is qualified by branch CI in GNU Fortran Debug
and Release configurations. The full suite contains 151 tests.
[Branch CI run 32774066221](https://github.com/GTT10/Fortranslate/actions/runs/32774066221)
passed all 151 tests in both configurations; Debug completed in 423.67 seconds
and Release in 115.22 seconds.

## Qualification boundary

This covers one serial, static, aligned rectangular fine patch over a
two-dimensional EB level. It does not include prolongation, ghost fill,
time advancement, subcycling, coarse/fine flux registers or reflux, multiple
patches, dynamic regridding, deeper levels, or MPI ownership.
