# PeleF 0.152.0 validation record

## Scope

Sparse hydro retains stage-start, uncorrected stage-end, and current corrected
state and temperature on each root tile owner beside the owner-local flux
records. Each child owner assembles patch-plus-two start/end/corrected support
directly from intersecting tile owners, extracts its four-edge interpolation
context locally, and receives interface-flux fragments through the established
direct route.

After child-local ratio subcycling and reflux, corrected support returns
directly to every intersecting root tile owner before the next child begins.
Final corrected root rows commit locally. The remote tile-result message,
complete root hydro result allocation, root-owner correction merge, and final
row scatter are absent. Superseded private complete-root bundle, context,
correction, and scatter helpers and their message tags are removed.

## Automated evidence

The MPI application requires the direct patch-plus-two state-support and
interface-flux value count to be positive and strictly smaller than the former
complete root bundle. Exact traffic contains finite-band halo messages plus one
state fragment and one returned correction per remote tile/child support
intersection and one flux message per remote tile/child interface intersection.
There is no post-compute root-result or final-scatter allowance.

MPI CI run `33004330441`. GNU Fortran Debug and Release builds pass. OpenMPI
one-, two-, four-, and eight-rank full-physics gates pass in Release and bounds/
FPE-checked Debug configurations, and both workflows pass the complete 208-test
serial regression.
