# PeleF 0.86.0 validation record

## Scope

This milestone adds open-area coarse/fine flux accumulation and AMReX-style
cut-cell re-reflux to the static serial two-level EB rectangle. Generic and
reactive transactions can update both coarse and fine state arrays.

## Automated evidence

The new unit gate first assigns identical constant vector fluxes to both levels.
One coarse interval and two fine half intervals cancel on all four patch sides
to roundoff, including partially open faces. A fine-only flux then crosses a
known cut coarse/fine interface. The gate verifies nonzero accumulation, the
`kappa`-scaled self correction, transfer to fine children, register reset, and
equality between the raw register integral and the redistributed composite
integral.

Nonfinite fine flux must leave an existing register bitwise unchanged. A small
full-state-proportional H2/O2/N2 correction passes active-cell EOS recovery on
both levels, retains temperature, and preserves covered states. A deliberately
large correction makes an active state nonphysical and must roll back both
state fields, both temperature fields, and the register.

Implementation commit `12abd99` is qualified by
[branch CI run 32776028872](https://github.com/GTT10/Fortranslate/actions/runs/32776028872)
in GNU Fortran Debug and Release configurations. All 152 tests passed in both;
Debug completed in 247.73 seconds and Release in 134.93 seconds.

## Qualification boundary

This covers conservative flux synchronization and reactive recovery for one
serial, static, aligned two-level EB rectangle. It does not include
prolongation, coarse/fine ghost fill, hierarchy time advancement, automatic
substep scheduling, dynamic regridding, multiple patches, deeper levels, or MPI
ownership.
