# PeleF 0.88.0 validation record

## Scope

This milestone adds the public input-driven static two-level reactive EB AMR
hydrodynamic application, hierarchy CFL selection, final-time loop, composite
diagnostics, and coarse/fine CSV output.

## Automated evidence

The unit gate builds an 8 by 8 root with a ratio-two 10 by 10 fine rectangle on
a diagonal embedded boundary. It verifies both cut-cell geometries, patch
validity, two-level CFL selection, one clipped coarse step, stationary state and
temperature on both levels, and the composite conserved integral. Enabling
chemistry is rejected with zero accepted steps and zero elapsed time.

The application regression reads the committed three-group namelist, builds a
12 by 12 root and an 18 by 18 fine rectangle, advances characteristic-PLM/HLLC
hydrodynamics, and writes both level files. The Python checker verifies 144 and
324 ordered rows, physical coordinates, all EB cell classes, finite positive
states, stationary pressure/temperature/velocity, and composition closure.

Implementation commit `d80122a` is qualified by
[branch CI run 32820023117](https://github.com/GTT10/Fortranslate/actions/runs/32820023117)
in GNU Fortran Debug and Release configurations. All 156 tests passed in both;
Release completed in 144 seconds and Debug in 444 seconds.

## Qualification boundary

This is one static, aligned, strictly internal fine rectangle with outflow root
boundaries. The application does not yet compose AMR chemistry or molecular
transport, create solution-driven tags, regrid, support multiple patches or
deeper levels, checkpoint, or distribute EB data with MPI.
