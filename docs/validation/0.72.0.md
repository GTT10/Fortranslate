# PeleF 0.72.0 validation record

## Scope

This milestone adds the public `pelef_mpi_amr_reactive_1d` application. It
reads a reactive namelist and composes sparse ownership, owner-local tagging,
distributed hydro/transport timestep selection, `R-T-H-T-R` advancement,
periodic dynamic regridding, final composite diagnostics, and CSV output.

## Automated evidence

The committed hotspot case enables molecular transport, three AMR levels,
regridding after every coarse step, and parabolic `r^2` work weighting. The
comparison gate requires the output to reach level two (zero based), finish at
the requested time, remain physically ordered and finite, preserve positive
density, pressure, and temperature, and close all species mass fractions.

The same gate runs the public application with 1, 2, 4, and 8 OpenMPI ranks.
It compares every CSV value with the one-rank result at `5e-13` relative
tolerance. The existing MPI patch executable also runs its owner-local tag
tests with the legacy multipatch flag disabled, proving the configuration is
reachable through the public namelist rules.

Implementation commit `4719fe9` is qualified by branch CI runs 32735712263
and 32735712259 in GNU Fortran Debug and Release configurations.

## Qualification boundary

The time loop keeps persistent patch fields globally single-copy. Initial root
construction and final diagnostics/output materialize fields. Checkpoint and
restart, parallel plotfiles, asynchronous I/O, heterogeneous accelerators, and
runtime-measured load balancing are not implemented.
