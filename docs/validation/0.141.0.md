# PeleF 0.141.0 validation record

## Scope

This milestone removes the unconditional complete-root input band for sparse
MPI transport Euler targets that touch a periodic y boundary. A boundary tile
owner assembles two increasing, globally contiguous source-row fragments while
keeping global row one and row `ny` at the temporary geometry's outer ends.
The existing serial transport and StateRedist kernels therefore retain the
physical periodic wrap.

The cyclic band contains the qualified six-row dependency guard plus one
additional row that isolates it from the deliberate internal source-row gap.
If that protected footprint spans the root, the established complete-root
fallback remains. Selected cut-boundary centroid y coordinates are shifted
into compact-band coordinates, and halo assembly splits deterministically at
both source-owner boundaries and the global-row gap.

## Automated evidence

A dedicated 14-by-21 root-only periodic-y EB case checks exact owner advances,
point-to-point halo and result transfers, and computed-band-cell totals. One
and two ranks exercise the complete-root fallback. Four and eight ranks require
finite cyclic boundary bands smaller than the complete root. Materialized root
state and temperature match a serial SSPRK2 transport reference at the
established `2e-11` scaled tolerance, and the redistribution limiter minimum
matches at `2e-13`.

The existing multipatch sparse transport, full `R-T-H-T-R`, public time-loop,
scheduled-regrid, rollback, checkpoint, and rank-count parity gates remain
active. Qualification head `3c97b4b` is covered by ordinary CI run
`32972236836` and MPI CI run `32972236805`. GNU Fortran Debug and Release builds
pass. OpenMPI one-, two-, four-, and eight-rank gates pass in Release and
bounds/FPE-checked Debug configurations, and both workflows pass the complete
208-test serial regression.

## Qualification boundary

Target tiles remain processed in a deterministic sequential loop, so this
change does not claim concurrent wall-time speedup. The root physics owner also
still assembles one complete post-compute bundle per stage for fine-child
exterior data, flux-register accumulation, and reflux. Distributing that
coarse/fine interface and removing the child correction round trips remain
separate work.
