# PeleF 0.114.0 validation record

## Scope

This milestone composes owner-only MPI chemistry, molecular transport, and
hydrodynamics as one transactional `R-T-H-T-R` interval over a two-level
sibling-patch reactive EB hierarchy.

## Automated evidence

The successful gate starts from the qualified uniform reactive state on a 14
by 14 plane-EB root and two separated ratio-two 10 by 10 children. Its MPI
result must match the serial multipatch split transaction within `5e-11` of
the root and child field scales, match the transport limiter minimum within
`3e-13`, and change the hierarchy measurably.

Two chemistry half-steps produce exactly two committed calls per root tile and
child. The middle hydro interval produces one root plus four fine advances.
The two SSPRK2 transport half-steps produce four root Euler stages plus eight
fine Euler stages per child, for a communicator total of twenty.

The rollback gate uses valid chemistry and transport settings followed by an
unknown Riemann solver. Chemistry and the first transport half-step may finish,
but hydro rejection must preserve every caller root and child field bitwise
and leave all three public counters at zero.

Implementation head `aa0c123` is qualified by ordinary CI run 32902762988 and
MPI CI run 32902762978. The MPI workflow used Ubuntu 24.04 with OpenMPI and ran
the executable at one, two, four, and eight ranks in GNU Fortran Release and
bounds-, backtrace-, and floating-point-exception-checked Debug
configurations. The full-physics gate, all established MPI gates, and the
complete 208-test serial regression passed in both MPI configurations. The
ordinary Release and Debug CI configurations independently passed all 208
tests.

## Qualification boundary

The transaction uses replicated complete fields and static two-level sibling
topology. Sparse storage, distributed timestep and clock ownership, dynamic
topology migration, parallel checkpoint/output, arbitrary depth, and
point-to-point EB communication remain outside this milestone.
