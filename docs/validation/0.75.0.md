# PeleF 0.75.0 validation record

## Scope

This milestone adds physical embedded-boundary length, centroid, and
solid-to-fluid unit normal metrics to every 2D cut cell.

## Automated evidence

Vertical and diagonal planes must reproduce analytical total/per-cell lengths,
centroid locations, and normals within `3e-13`. For a circular signed-distance
field, the `40x40` perimeter error must be below `0.30` of the `20x20` error.
Every circular normal must point toward the fluid interior within `0.02`, and
the refined maximum orientation error must improve.

Implementation commit `dbf4868` is qualified by branch CI run 32745622802 in
GNU Fortran Debug and Release configurations.

## Qualification boundary

Metrics follow the fixed-diagonal piecewise-affine geometry contract. No
cut-wall flux, conservative cut-cell divergence, redistribution, small-cell
stabilization, wall thermodynamics, AMR, or MPI coupling is implemented.
