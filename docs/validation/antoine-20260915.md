## Scope

The optional liquid model implements `psat=D*10**(A-B/(T+C))`, following
`Source/Spray/SprayPropertiesPeleMP.H` at PelePhysics
`6e8026fc6ed121c07e32c9d3fe1d1c919bafc64b`. The source was read with `git show`
at that commit, independently of the external checkout's current HEAD.
The file SHA256 is
`c75d5f7acc53c58ce2bf8ea56aadd603bef965bfa54b89ca0b817e7cb2a979dd`.

The runtime computes the logarithmic pressure ratio to avoid overflowing
psat. Positive B/D, finite data, an ordered temperature interval, and a
positive T+C over that interval are required. Out-of-range temperatures and
boiling states are rejected. The existing Clausius path and checkpoint context
are retained when the option is absent. Antoine contexts add the coefficients
and range to the physical input identity; changed inputs reject restart.
Liquid density and heat capacity are still constant. This change supplies
saturation pressure, not a full real-fluid property or boiling model.

The water example uses A=5.40221, B=1838.675 K, C=-31.737 K for 273--303 K,
from [NIST Chemistry WebBook](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7732185&Mask=4&Type=ANTOINE&Plot=on),
Bridgeman and Aldrich data as fitted by NIST. D=100000 Pa converts the tabulated
bar pressure. The example's constant liquid density/cp are not fitted by this work.
