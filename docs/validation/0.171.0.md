# PeleF 0.171.0 validation record

## Scope

The sparse MPI arbitrary-depth reactive 2D EB tree now writes the qualified
self-describing checkpoint through one selected root and restarts without
stored rank or owner metadata. Compact topology and EB geometry are broadcast,
the current communicator recomputes ownership, and numerical fields scatter
directly from the I/O root to their new owners.

## Automated evidence

The physical four-level branching tree is checkpointed with the last rank as
I/O root. The global gather count must equal the number of nodes not owned by
that root. Restart requests a different work exponent, reconstructs a new
distribution, and requires the global scatter count to equal the number of new
owners away from the root.

Materialization occurs only after restart. The resulting topology, conserved
fields, recovered temperatures, time, minimum timestep, step count, and regrid
count match the complete serial source within `8e-12` of field scale. A
rank-dependent maximum depth on multiple ranks, insufficient depth on one
rank, and a rank-local species-order mismatch all reject with empty sparse
outputs, zero lifecycle metadata, and zero transfers.

Qualification commit `0187cca` is covered by MPI CI run `33037989248`. GNU
Fortran Debug and Release pass every established MPI gate at one, two, four,
and eight ranks and the complete 208-test serial regression. Local `fparser2`
parsing passes all four touched Fortran sources, and `git diff --check` is
clean.
