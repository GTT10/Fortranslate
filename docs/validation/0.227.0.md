# PeleF 0.227.0 validation record

## Scope

This milestone adds `pelef_reactive_eb_2d_selected`, a configure-time selected
mechanism front end for the existing serial single-level reactive 2D
embedded-boundary application. It supports plane and circle geometry, PCM and
characteristic PLM, existing FluxRedist/StateRedist controls, native chemistry,
molecular transport, and configured embedded walls for normalized schema-1
bundles containing 2--32 species.

Fixed and selected front ends call one mechanism-independent application
driver. The selected EB runtime has a private Fortran module directory, links
the selected regular-2D runtime, and contains neither committed generated
mechanism. Existing callers retain source-compatible optional composition and
integrator arguments when rebuilt. The changed Fortran module interfaces are
not a binary ABI for linking old objects or archives without recompiling.

## Startup and configuration evidence

The fixed parser continues to reject `chemistry_model = "selected"` unless a
configured selected front end opts in. Shared startup validation checks bundle
structure, molecular-mass balance, transport ordering, a finite common NASA7
interval, and exact species-name composition resolution before output. The
selected front end checks the actual initial hotspot extrema and any
isothermal embedded-wall temperature against that interval.

Regression cases reject an unknown species, an embedded-wall temperature
outside the common interval, a lexical input/output alias, and selected input
sent to the fixed EB executable, all without an output artifact. A driver unit
gate passes an invalid chemistry-integrator policy into an active EB Strang
step and requires exact rollback of both conserved state and temperature.

The independently ordered two-species H2/H plane fixture enables native
explicit chemistry and molecular transport for `1.0e-7 s`. Its 4-by-4 grid
contains 8 regular, 4 cut, and 4 covered cells, retains exact reported
mass-fraction closure, and changes active H2 mass fraction by
`1.3160688855229363e-4`. Repeated output is byte-identical with SHA-256
`c75158b4e8b36361703212ae528a70737d9bcc35ff94e3afebb6c79f4a16f24f`.

The pinned ten-species, 29-reaction full-H2/O2 plane case executes active
implicit chemistry for `2.0e-7 s`. Its 4-by-4 geometry has the same 8/4/4
regular/cut/covered counts, reports exact mass-fraction closure, and changes H2
mass fraction by `7.7955196880682975e-7`. Fixed and selected CSV files are
byte-identical with SHA-256
`4ecd1ea859d3be8c73814a285791195e508c17f631d61e8496357f2e825a09b1`.
An independent three-output gate also compares each active EB cell with the
regular-grid selected reactor, requires covered storage to equal an inert EB
control byte-for-byte, and enforces volume-weighted mass and total-energy
conservation.

The full-H2/O2 transport case uses an 8-by-8 circle, characteristic PLM,
viscosity, conduction, species diffusion, barodiffusion, correction velocity,
species enthalpy flux, and an isothermal moving no-slip embedded wall for
`2.0e-8 s`. It contains 48 regular, 12 cut, and 4 covered cells, retains
mass-fraction closure to `2.22e-16`, and changes H2 spatially by
`1.0935998911998368e-9`. Fixed and selected CSV files are byte-identical with
SHA-256 `80636a3f8c076d9648afccdbaa8bab77e2512318d9f65a75d18a5176fd68ea84`
in Debug and
`21e1607dbdfc2a97de5bb359b28bce2cfef5508b2f531cfafce80ab2404ef6e2`
in the clean installed Release build. The build-type difference is recorded
rather than treated as cross-optimization byte parity. Within each build,
fixed and selected output is exact. A separate transport-off selected control
requires covered storage invariance plus measurable isothermal-wall heating
and moving-no-slip wall momentum transfer.

The dedicated selected-EB Debug CTest selection passes 22 of 22 configuration,

## Qualification boundary

This evidence qualifies configure-time selected chemistry and transport in
the existing serial single-level reactive 2D EB application. It is not
selected EB AMR/3D, checkpoint/restart, MPI dispatch, runtime YAML/JSON loading,
CVODE-backed CFD chemistry, general outer physical-boundary support,
mechanisms above 32 species, thread-safety or performance evidence,
detailed-fuel validation, external PeleC field parity, or experiment
validation. All four outer-domain boundaries remain outflow-only. The
repository license remains an explicit owner decision and release blocker.
