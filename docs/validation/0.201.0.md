# PeleF 0.201.0 validation record

## Scope

This milestone freezes the completion/reference contract and hardens the
existing serial and MPI build boundary. It does not expand the qualified
physical model.

## Automated evidence

- the project-contract gate requires identical CMake, runtime-banner, and
  README versions and a matching validation record;
- the pinned PeleC manifest records the selected PeleC, PelePhysics, AMReX,
  and SUNDIALS commits and is referenced by the roadmap and mapping;
- positive and negative CMake-script tests cover the `mpi_f08` requirement;
- final serial and MPI ELF targets are parsed directly and must have a
  non-executable `PT_GNU_STACK` segment;
- the pre-existing serial CTest suite and 1/2/4/8-rank MPI parity/restart gates
  remain required.

## Local qualification results

The milestone was qualified on GNU Fortran 13.3.0 and GNU/OpenMPI with the
following results:

- Debug: all 214 pre-existing tests passed, followed by all four new quality
  gates after the negative-MPI harness correction;
- Release: 218/218 CTest tests passed;
- Debug with Cantera 3.2.0: 221/221 CTest tests passed, including the
  elementary H2/O2 reactor, detailed H2/O2 reactor, and mixture-transport
  comparisons;
- OpenMPI Debug: all four quality gates, the callback regression, the complete
  1/2/4/8-rank structural suite, fresh field-parity suite, and changed-rank
  restart suite passed;
- OpenMPI Release: all four quality gates passed; halo exchange, AMR ownership,
  2D EB full physics, and arbitrary-depth EB trees passed at one and eight
  ranks; coupled reactive and sparse-AMR fields had zero maximum relative
  difference between one and eight ranks; the branching four-level EB case
  passed its one/two/four/eight-rank field comparator.

The deliberately contaminated Intel-oneAPI/GNU configuration was also checked
and rejected during CMake configuration before any target compilation.

## Qualification boundary

The MPI check proves compiler/wrapper module compatibility as reported by
CMake; it does not certify an MPI vendor or network fabric. The stack check is
active for ELF outputs and skips non-ELF platform binaries. The upstream
manifest freezes comparison provenance but does not yet constitute whole-solver
PeleC co-run parity.
